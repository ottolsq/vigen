# 项目文件模板（01-06）

> 创建项目文件时复制对应模板。`{...}` 为待填占位。文件头部带元信息，便于续作与失效标记。

## 01_方案与剧本.md

```markdown
# {项目名} · 方案与剧本

> 生成日期：{date} · 目标模型：图 {gpt-image-2.5} / 视频 {happyhorse-1.1-i2v} / 语音 {cosyvoice-v3.5-flash}

## 整体方案

| 项 | 值 |
| --- | --- |
| 主题 | {一句话} |
| 总时长 | {15s/30s/60s}（{N} 镜） |
| 风格 | {风格名}（大白话：{一句解释}） |
| 情绪曲线 | {如：安静开场→小波澜→转暖→治愈收尾} |
| 画幅 | {9:16 竖屏 / 16:9 横屏} |

## 叙事脚本

{按时间轴的剧情描述，每镜一段}

## 分镜总览表

| 镜号 | 成片时段 | 生成时长 | 景别/机位 | 运镜 | 画面内容 | 转场 | 台词/字幕 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 0:00-0:05 | 6s | 中景/平视 | 缓慢推近 | {...} | 硬切 | — |
| ... | | | | | | | |

> 运镜说明（大白话）：镜1"缓推"=镜头慢慢凑近，让人感觉要发生什么……

## 校验记录

- [ ] 每镜运镜动词不重复（相同"缓推"不超过2次且不相邻）
- [ ] 无连续 3 个同景别
- [ ] 每镜容量：5s=1动作节拍 / 10s=1动作+1反应 / 15s≤3节拍
- [ ] 高风险运镜已降级（如适用）
```

```markdown
## 一、人物参考图（阶段2）

### {角色名} · 正面锚定图（文生图）

```
{拍摄媒介句}。

natural skin texture, visible pores, realistic and imperfect。
```

## 二、场景参考图（阶段3）

### {场景名}（文生图）

```
{拍摄媒介句}。
{场景描述锚逐字}。{生活痕迹}。
光线：{光线锚逐字}。
前景：{...}；中景：{...}；背景：{...}。
{风格圣经逐字}
```

## 三、情景参考图（阶段4，多图参考：人物图+场景图）

### 镜头{N} · {镜名}（image 1={角色名}锚定图，image 2={场景名}参考图）

```
Use image 1 only for the character's identity and appearance. Use image 2 only for the scene environment and lighting.
{拍摄媒介句}。
{锚定短语逐字}，{在场景中的位置与朝向}。
{蓄力瞬间描述：有势能不锁定方向}。

```

> 蓄力检查：{此镜视频要从什么状态开始动？首帧给足势能了吗？面朝方向留 2/3 空间了吗？}
```
