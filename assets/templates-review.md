# 独立评审门模板（V3.23——文字产出不达标时的第二双眼睛）

> 何时读：按 `references/production-workflow.md` 的阶段验收或局部复审路由。
> 核心纪律：评审子代理只拿**文件和评分卡**，不拿主代理的自评/批次记录/对话；结论必须有 `文件:行` 证据。

## 一、评审子代理任务书（复制给全新子代理）

```text
你是独立评审员。只读下列文件，不读主代理的自评、批次校验记录或对话。
按评分卡逐项判定 PASS / FAIL / 待核验 / NA；FAIL 必须给「文件:行」+ 缺陷及其可见后果；待核验写缺哪份证据，NA 写适用性理由。总体只有适用项均 PASS 才能记 PASS，放行见 production-workflow.md 四节。
禁止"感觉不好/建议优化"式空话；无证据的 FAIL 不采信。

评审文件：
- 交付物：{01 剧本节 / 02 / 03 批 / 04 段 / 05}
- 上游：{01/02/05 相关节、当轮用户裁决或修订记录}
- 最终发送件（04 适用）：{画布节点与实际提示词/参考绑定，或最终可复制稿}
- 规则指针：{screenwriting-craft / consistency / prompt-rules / models 对应节}

返回格式：
- 维度｜结论｜证据（文件:行；画布可附节点 ID）｜缺陷或待核验条件
- 总体：PASS / FAIL / 待核验（分别统计未通过、待核验项）
```

## 二、评分卡（只列检查项 + 规则家的指针，不复制规则全文）

### 剧本（GATE1.5 前，必评）

| 维度 | 检查项 | 规则家 |
| --- | --- | --- |
| 7 大漏洞证据 | 每条有操作程序结果 + 场次证据，不是"通过"打勾 | screenwriting-craft 一 |
| 观众可读的动机与因果 | 只读受影响场的可见/可听内容，不借梗概、自评或原著常识：引用线索，指出人物为什么做关键选择、它改变什么、下一拍如何因此发生；若有意隐去完整动机，仍须能指出支撑当前冲突的线索 | screenwriting-craft 一·四、一·五 |
| 人物选择与兑现 | 在剧本中指认角色原来想做什么、尝试过什么、哪条新信息或阻力迫使策略改变、这一选择留下什么可见代价或关系变化；指出结尾已兑现什么。小故事不必硬加反转，但不能靠旁白、剧情简介或评分卡标签替角色完成转变 | screenwriting-craft 一·五 |
| 钩子/悬念位置 | 钩子前 3 拍、悬念末拍（节拍制项目） | screenwriting-craft 一·五 |
| 情节点覆盖 | 情节点清单完整、可被分镜 100% 覆盖 | SKILL 硬规则 7 |
| 台词行动 | 每句有行动动词/潜台词，不书面化 | screenwriting-craft 一·二 |
| 时长预算 | 估算秒/预算合计/实际时间轴口径正确 | screenwriting-craft 一·八 |
| 三层分离 | Source/Interpretation/Proposal 分栏 | screenwriting-craft 一·七 |
| 压缩账 | 改编原文的删除/合并逐项用户确认 | screenwriting-craft 一·十 |

### 04 批次（验收路由见 production-workflow 三、四节）

| 维度 | 检查项 | 规则家 |
| --- | --- | --- |
| 槽位完整 | 骨架 A/B 槽位齐全、单值 | prompt-rules 二 |
| 锚定逐字 | 角色/服装/道具/风格逐字 | SKILL 硬规则 4 |
| 就地绑定 | 名称后紧跟 `@{{Ref N}}` | SKILL 硬规则 20 |
| 动作密度 | 默认意图级；峰值才展开秒级微操 | prompt-rules 0.13 |
| 模型路线一致 | 用 01/02 已登记的同一路线对读 03 资产矩阵与最终 04：检查段长/画幅、首尾帧与其他参考类型和数量、绑定语法、对白/声音格式及实际输入模式。不能把计划段长当能力；按实际入口判支持，不从模型家族名推断。能力或实际解析未核验则不能记已验证通过 | models 项目路线记录；prompt-rules 一·3、生成路径判定、声音写法分模型 |
| 参考权威与入画覆盖 | 对照 01 入画列表、02 锚定、03 矩阵、04 镜头和端点：必见对象不漏登记、不漏绑；同一对象同一维度只有一张权威参考，冲突时点名降级或裁掉哪张。PLAN 只证明计划映射，不能当作已挂图 | consistency 三；prompt-rules 三·六 |
| 时间账 | 朗读+动作 ≤ 镜头 | A17 |
| 负面冲突 | 同对象/属性正负不并存 | prompt-rules 0.3 |
| 画面可执行 | 对每镜指认观众此刻必须读到的动作或信息。对承载因果的镜头，用机位/画框、焦点、遮挡或反光、光区和停留时长证明线索与反应能被看到；同镜读不全时，给出明确的先后焦点或相邻镜承担者。接触动作顺读支撑→接触→受力变化→释放；核对口型、声音和灯光变化的触发点。只写「清楚可见」不算证据；依赖实图或排演时记待核验 | prompt-rules 0.4、0.7、0.13、三·五；cinematography 视觉连续性 |
| 最终发送件 | 对照本轮新增、修改、删除项检查全文（含场景上下文、出场人物、表演锁、负面与音频，不只看时间块），核对有效参考编号对应的实际图或占位；举证一条已改项，失败时点出仍残留或相冲突的原文 | production-workflow 三 |
| 连续性 | 逐段对读相邻 04 尾帧与下一段开镜，引用两侧原文；阶段 6 写完 06 后再核对剪辑切点，不要求阶段 5 提前产出 06。比对在场人物的站位、朝向、姿态、手部动作/持握、关键道具、门灯和光线。状态不同须有看得见的接位动作，或在切点明确交代省略/时空转换；只对上道具和光、不对人物，不通过。第一段无前段可记 NA | prompt-rules 跨段尾帧互接；SKILL 硬规则 22 |
| 母版事实 | 带 `母版事实标记` 的块逐字 | A19 |
