# 扩展视图方法（场景多视图补全 / 十二宫格分镜）

> **何时读**：同一场景需要多机位覆盖（对话正反打、空间展示）；分镜需要"机位×景别"矩阵素材；产品/角色展示类视频需要多角度。
> 源：社区实战资料（2026-10）。两法均基于 gpt-image 单图/多图参考能力，其他生图模型按同等逻辑迁移。

## 一、场景四视图补全法

以一个场景母版图为基准，生成同一场景的其他机位视图，4 张图构成完整空间（分镜时任选机位都有据可依，防"换机位就换场景"的漂移）。

### 合图一次生成 → 裁切（V3.7 首选，防四视图互相漂移）

四视图不必逐张派生：**在同一张图内按 2×2 排列一次生成四个视图，再裁成四张单张**——同源生成让母版/对向/斜角/俯拍共享同一场景事实，比"从母版逐张派生"更不容易漂（实测：逐张派生时对向视图容易重新设计门窗/家具）。

提示词骨架：

```
在同一张图内按 2×2 排列生成同一场景的四个视图：左上=母版平视、右上=对向回望、左下=45°斜角全景、右下=90°垂直俯拍。
四个视图必须是同一个场景、同一套光线与材质，家具位置与门窗数量一致；每格完整独立，格与格之间留纯白间隔，不画分割线以外的任何文字。
```

- **尺寸按格数反推**：裁后每张短边 ≥1024——2×2 合图至少 **2048×2048 正方形**（宽幅 2048×1152 只有 1024×576/格，不达标）；低于则退回分张派生。
- 裁出的四张单张登记 02，作为该场景的权威视图；**合图本身不喂模型**（多格拼贴每格像素不足+分隔线干扰）。
- 若合图内某格出现"对向视图重新设计了家具/门窗"→ 该格不可用，退回下方逐张派生法（以母版为唯一基准）。
- 与"一张图只回答一个问题"的关系：合图是**生成端手段**，单张是**参考端事实**——裁切后每张仍只回答一个机位问题。

> 下方逐张派生法是退路；能用合图时优先合图。

| 视图 | 生成提示词（单图参考母版） |
| --- | --- |
| 视图1（母版） | 原始场景参考图（03 阶段3 产物） |
| 视图2 对向回望 | `以图片1为场景母版，生成同一场景对向反向平视回望` |
| 视图3 斜角全景 | `以图片1为场景母版，生成同一场景的45°俯视斜角全景` |
| 视图4 垂直俯拍 | `以图片1为场景母版，生成同一场景的90°垂直正俯上帝视角，镜头从正上方垂直向下拍摄` |

要点：
- 母版选**平视中性视角**（最常用的叙事机位），其余视图从它派生
- 生成后 4 张全部存入 assets/，02 场景锚定表的"参考图路径"字段登记全部 4 张
- 分镜表中每个镜头标注使用哪个视图作机位依据；情景图生成时把对应视图作为场景参考图输入
- **条件强制**（V2.0）：场景被 ≥3 镜使用 或 有正反打对话 → 四视图必做（不再是可选项）；单镜头或每镜换场景的项目不需要
- **"生成/登记"与"上传"分开（消除与"零引用不生成"的冲突）**：四视图命中条件后，4 张**全部生成并登记进 02**（这是资产登记，不算浪费——它们是"机位依据"而非"每张都进视频"）；但进 04 时**只上传该段实际用到的视图**（该段机位用母版就传母版、用对向就传对向），没被任何段上传的视图不构成"零引用资产"。判据：**登记=规划，上传=消费；零引用不生成约束的是"上传/消费"层，不是"登记"层**
- **LOCATION MAP 配套**：多角色场景做四视图时，02 场景锚定同步写 LOCATION MAP（各角色/关键道具的固定位置、朝向、相互距离）——四视图锁空间，LOCATION MAP 锁人物站位，两者共同防"换机位就换场景/人物瞬移"

## 二、十二宫格分镜矩阵

一张图生成 3 机位高度 × 4 景别 = 12 格分镜矩阵，作为分镜设计的可视化素材板（也用于快速对比选镜头）：

**完整提示词模板**：
```
以参考图为唯一参考基准，在同一场景下生成12格分镜矩阵，采用3种机位高度×4种景别的固定逻辑。保持主体、环境、服装或产品设计、光线方向、时间、氛围、色调及整体风格与图片1完全一致。不重新设计场景，不新增道具、人物、动作或剧情元素，画面之间仅允许机位高度和取景距离发生变化。按清晰的3行4列排列12个镜头。
三行机位高度分别为：平视中性视角、低角度仰拍、高角度俯拍。
四列景别分别为：远景、中景、特写、超特写。
- 远景：展现主体与环境的空间关系
- 中景：展现姿态肢体语言与空间互动
- 特写：聚焦面部上半身或关键动作区域
- 超特写：突出具有表现力的细节，如眼睛、手部、武器、物体纹理或其他重要局部
平视镜头稳定客观；仰拍镜头增强气场、力量感或紧张感；俯拍镜头营造空间俯瞰感、脆弱感或视觉掌控。
```

机位高度的心理效果（与 cinematography.md 机位角度表互证）：平视=稳定客观；仰拍=气场/力量/紧张；俯拍=俯瞰感/脆弱/掌控。

**用法**：
1. 阶段1 分镜设计时，先生成十二宫格矩阵图作为"镜头素材板"，从中圈选实际用到的机位×景别组合（不是 12 格全用）
2. 圈选结果写入 01 分镜总览表的"景别/机位"列
3. 矩阵图本身存入 assets/ 供人工参考（**不直接作为视频参考图**——12 格拼贴会引入分割线干扰，与拼贴设定卡同理；实际生成情景图时用对应视图/锚定图重新单独生成）

> 与"三层资产架构"的关系：十二宫格属于**人工参考层**（给用户看、辅助分镜决策），不属于视觉锚定层（不喂给视频模型）。

## 三、六格分镜板（storyboard sheet——分镜可视化的人工参考层）

一张 3×2 网格图把一段戏的 6 个关键镜画成故事板，每格四段式固定写法（画廊成品验证）：

```
3×2 grid storyboard. Each panel:
Panel N — {景别}: {画面内容一句}. Info: "PANEL 1 · EXT. ALLEY · NIGHT · WIDE / static / 2s"
```

- 每格 Info 行含：**场景 slug（INT/EXT·地点·日夜）+ 景别 + 镜头运动（pan-L 45°/tilt-up 30°/crane-down）+ 时长 + SFX 注记**
- 可加红铅笔箭头标注运镜方向（人工参考用，不喂模型）
- 用途定位同十二宫格：**人工参考层**——GATE1 前给用户看分镜节奏、圈选镜头；不作为视频参考图（多格拼贴引入分割线干扰）
- 与场景空间写法配套（建筑/大场景图）：`Viewpoint is slightly low and wide, emphasizing vertical scale and shadow` + 人物比例锚 `a few small human figures for scale, but keep the architecture dominant` + 图内尺度标注（`Nave Height 28.5 m`）+ K 值入句（`cove lighting at 3000K`）
