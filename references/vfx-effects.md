# 技能特效提示词（V3.18——法阵/剑气/能量/粒子）

> **何时读**：项目含技能特效、法阵、剑气、能量波、粒子爆发、变身光效；或用户说"技能特效/法阵/剑气/粒子"。
> **可信度**：`[社区方法论]`（来源 other14.md 的 Niagra 实时粒子教程转录，无官方出处）；其中的镜头片段为 `[成品样例]`。**未在你的目标模型上实测**，首次使用按项目小样 A/B，效果不稳按"结构失败→回上游"处理，不在提示词里叠形容词。
> **负面词**：本文件末的失败模式清单**可用作负面词**，但必须先过 knowledge-index 的冲突检查（正向没要求的失败模式才能写；不得正负并存；短而靶向 3-5 条）。

## 一、核心光效结构（三层）

| 层 | 写法 | 作用 |
| --- | --- | --- |
| 自发光 | `emissive`（自发光材质） | 控制亮度与颜色，不让光效靠环境光"照亮" |
| 分层渲染 | 核心层/中层/外晕层分开写 | 保证光效有层次、不糊成一片 |
| 高光锚定 | 高光锚定在纹路/符文中心 | 锁死不跑形；光效中心不漂移 |

**核心句模板**：
```text
{技能名}：emissive 自发光，核心层{颜色#XXXXXX}、中层{颜色}、外晕层{颜色}；高光锚定在{符文/纹路/刃口}中心，光效形状不漂移、不重绘。
```

## 二、按职业/技能形态选型（三类公式）

| 类型 | 光效形态 | 关键句 |
| --- | --- | --- |
| 法师 | 法阵/符文 | `脚下/掌心展开法阵，符文按{环形/六芒/卦象}排列，emissive 自发光；高光锚定符文中心，阵形不跑` |
| 射手 | 弓弦凝聚光点 | `光点从{弓弦/箭簇}向中心凝聚，形成{箭形/线形}光轨；弓弦张力与光点同步` |
| 剑修 | 武器刃部光效 | `光沿着{剑刃/刀锋}边缘流动，刃口最亮、向刀背渐隐；高光锚定刃口，不整把发光` |

> 先选型再写参数；不要三类混在一个技能里（混用=形态不清）。

## 三、动态轨迹（技能有节奏不生硬的关键）

1. **运动模糊采样**：`motion blur sampling`——光轨要有运动模糊采样，不是一根硬边线条。
2. **节奏匹配技能类型**：蓄力慢、释放快、收束短；写清"哪一段慢、哪一段快、哪一段停"。
3. **核心到全局层叠**：核心光效 → 中层扩散 → 外晕/环境残留，按层写，不从外往里写。
4. **保留轨迹投影与力度**：写清光效在{地面/墙面/水面}上的投影方向与衰减；力度靠"光效长度/速度/粒子密度"表达，不写"很猛/很震撼"。
5. **收束声明**：技能结束后光效如何消退（"只剩{百分比}的轮廓线"），防模型收不住。

## 四、失败模式负面清单（可用，先过冲突检查）

> 使用前提：正向段没有要求这些对象/属性；每类只取 3-5 条最可能的失败项，不整库粘贴。

**光源**
- 光源与太阳/月亮/开口矛盾；无开口墙体发光；同场景光源漂移或复制；白天多太阳；夜晚太阳或多月亮
- 细小/不可见光束；平面贴图；双主光；无源激光/舞台灯/霓虹；无源彩虹；耀斑离轴/贴眼；整屏死白或脸部过曝

**风/头发/布料**
- 弱风/静风；只动少量发丝；发根滑动；机械钟摆；水草式头发；破坏性乱流
- 头发/纱帘/植被/粒子方向互相矛盾

**粒子**
- 只生成小粒子；尺寸平均化；连续 0.3 秒无大粒子；硬边实心粒子
- 非剧情需要时出现球体/肥皂泡/雪花/雨滴/火星/萤火虫/纸屑/花瓣
- 粒子无重力、逆风、随机游荡、穿模

**落叶**
- 落叶无枝头来源；室内凭空出现；逆风或失控叶暴

**角色一致性**
- 换脸；发型/服装跳变；手指错误；闪烁；背景融化

## 五、技能特效模板

```text
{技能名}（{职业/形态}）：
核心光效：emissive 自发光；核心层{颜色#XXXXXX}/中层{颜色}/外晕层{颜色}；高光锚定{符文/刃口}中心。
形态：{法阵符文 / 弓弦光点 / 刃部光效}；{具体排列/走向}。
动态轨迹：{蓄力→释放→收束}；{慢/快/停}节奏；motion blur sampling；光轨在{地面/墙面}投影{方向/衰减}。
层叠：核心→中层→外晕/环境残留；结束收束到{百分比/轮廓}。
负面（仅正向未要求项，3-5 条）：{光源矛盾/多太阳/粒子穿模/换脸/换装跳变…}
```

## 六、边界

- 不写"很震撼/电影级/8K"类空话；用 emissive/层/颜色/轨迹/速度/投影这些可执行维度。
- 不把整份失败清单粘进提示词；负面过多会主导生成。
- 本文件不替代 action-combat 的攻防状态机；打斗中的技能特效仍先按 action-combat 交手账排回合，再挂本文件的光效层。
