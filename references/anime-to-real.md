# 2D 转真人（动漫角色 → 写实人像）

> **何时读**：用户提供动漫/二次元角色图，要求转成真人写实形象（漫剧真人化、cosplay 预演、IP 真人化等）。
> 源：社区实战资料（2026-10），经本 skill 规则适配。核心原则：**精准保留原动漫人物的身份特征，但全部转化为真实摄影质感**——不是"画一个像动漫的真人"，而是"这个动漫角色如果是真人会长什么样"。

## 完整提示词模板（五维度）

```
必须精准保留原动漫图片中的人物身份特征、脸部轮廓、五官比例、样貌气质、发型的写实摄影质感。

【人物要求】将动漫人物转化为真实存在的人类形象，脸部必须具有真实的人类骨骼结构、自然面部轮廓、真实但好看的五官比例、真实皮肤质感、自然肤色、细腻的皮肤纹理、真实眼睛反光、真实睫毛和眉毛细节。保留原图人物的脸型特征、五官气质和整体样貌印象，将二次元夸张比例转化为真实人类比例（动漫大眼转为正常人类眼睛大小），呈现真实皮肤质感。

【皮肤要求】皮肤呈现真实摄影级别质感，整体状态偏细腻、嫩、干净、自然、有轻微通透感——细腻、平滑、柔和、富有弹性，保留轻微真实纹理与自然明暗起伏，属于高质量年轻肌肤的真实质感。皮肤纹理清晰但克制。除非原角色本身设定明显年龄较大，默认呈现年轻肌肤状态。

【发型要求】发型完全参考原动漫图的长度、刘海、发丝走向、层次、卷度、蓬松感和颜色，转化为现实中的真实头发质感：真实发丝细节、自然光泽、柔软蓬松感和真实物理垂坠感。

【服装要求】服装严格参考原动漫图的款式、剪裁、颜色、图案材质、装饰细节和穿着方式风格。

【画面风格】极致写实摄影风格，真实世界照片质感，电影级真实光影，高动态范围，真实镜头景深，真实空气感，真实环境反射，细节清晰，专业摄影构图。整体效果像现实世界中真实拍摄的人像照片。

【构图要求】保持原图的画面构图、人物大小、镜头角度、景别、透视关系和主体位置。
```

## 五维度检查清单（生成后逐项核对）

| 维度 | 检查点 |
| --- | --- |
| 身份保留 | 脸型轮廓、五官比例、气质印象与原动漫一致（是同一个人，不是"类似风格的人"） |
| 真实转化 | 眼睛大小正常（无动漫大眼）、皮肤有真实纹理、头发有真实发丝与垂坠感 |
| 服装还原 | 款式/剪裁/颜色/图案/装饰细节与原图一致 |
| 构图还原 | 景别、机位角度、透视、主体位置与原图一致 |
| 质感真实 | 像真实照片，无插画/CG/3D 渲染感 |

## 与核心规则的衔接

- **本模板产出的是 0a 白底三视图/0b 面部特写的输入源**：2D 转真人先生成一张正面写实图，确认后作为锚定图进入三层资产流程（真人图 → 三视图 → 面部特写）
- **锚定短语的来源**：转真人成功后，把"转化后的真实人物描述"（真实五官/发型/服装的写实描述）写成锚定短语存入 02——后续所有镜头用真人锚定短语，不再引用动漫原图
- 原资料的负面清单（禁止动漫风/塑料皮肤/假人感/过度磨皮/眼睛颜色错误/五官变形/手指畸形/服装细节丢失/背景虚假/光线不统一等）按 knowledge-index.md 负面词适配规则处理：gpt-image 转正向表述；H3 并入 ban list；支持负面提示词的模型直接可用
