# 提示词规则（骨架 / 必填槽位 / 校验）

> 写任何图片或视频提示词之前读本文件。核心原则：**完整但不越界**——每个职责维度必须有明确描述（留白=不可预期），但各阶段职责边界之外的描述必须省略（重复=干扰）。
> 视频骨架基于用户提供的优秀成品提示词（风格1 多镜头公式）提炼；模型能力限制查 models.md。各模型"癖好"类主张已停用（_archive-suspended-claims.md，勿读）。

## 一、图片提示词骨架

### 0. 角色视觉锚定资产（阶段2，每角色一组）

**三层分工架构**（AI 识别像素/轮廓/色彩/五官比例/形体结构，不"读懂"图里的文字与分区——给 AI 的图必须信息精准单一，文字约束放提示词，拼贴卡留给人看）：

| 层 | 载体 | 用途 |
| --- | --- | --- |
| 视觉锚定层（给 AI） | 拆分的干净锚定图：白底三视图（主锚，锁全身形体）+ 面部特写锚定图（锁脸）+ 按需 1-2 张细节图（表情板/服装细节） | 所有情景图/视频生成的参考图输入 |
| 文字规则层（给 AI） | 锚定短语逐字段落（02_锚定表），固定粘贴在每条提示词相关位置 | 文本层面约束固定特征 |
| 人工参考层（给自己） | 完整拼贴式设定卡（含分区标注、色卡、文字说明） | 核对生成结果的制作规范手册，**不喂给 AI** |

**为什么拆分而不整卡上传**：分割线/边框/文字标注会被当画面特征学习（杂线色块、表情格小脸串脸）；小格子细节占比太小提取不到有效信息；图中文字 AI 不读取——这些信息必须放提示词（锚定短语机制）。

#### 0a. 白底三视图（主锚，写实人物必做）

```
[媒介句] A character three-view reference sheet, flat even studio lighting.
[锚定描述] {年龄/性别/体型/脸型/发型发色/服饰/标志性特征——固定文字，与锚定短语完全一致}
[版式] three-view reference sheet: front view, side view and back view of the same character standing in a relaxed neutral pose, full body, side by side, evenly spaced, equal height
[一致性强调] same person in all three views, consistent height, hairstyle, outfit and details across views
[背景] 纯白背景，无分割线、无边框、无道具、无文字标注
[质感] natural skin texture, visible pores, realistic and imperfect
```

规则：无分割线/网格/文字；一致性强调句必写；生成后裁出三视图分别存 assets/（{角色}_front/_side/_back.png），整张也存档。

#### 0b. 面部特写锚定图（写实人物必做，锁脸专用）

```
[媒介句] A head-and-shoulders portrait reference photo, medium-format camera, 85mm f/2, flat even studio lighting.
[锚定描述] {锚定短语中的头部要素逐字：年龄/脸型/发型发色/五官特征}
[构图] 正面平视，头部完整居中，表情平静，纯白背景
[质感] natural skin texture, visible pores, realistic and imperfect
```

#### 0c. 按需补充锚（可选，每角色 ≤2 张）

- 表情板：`expression studies sheet, same face: neutral, smiling, sad, angry, front view, plain white background`
- 服装细节图：标志性服饰/配饰的单独特写（花纹复杂的服装）

#### 0d. 道具锚定图（条件必做——见道具判定规则）

**道具判定规则（任一命中即为道具，必须独立生成参考图）**：
1. 同一物品在 ≥2 个镜头出现
2. 被角色触碰后会**改变状态**（雨伞收起→打开、杯盖旋开、信被拆开、灯被点亮）
3. 会**运动/位移**（被推动的银锭、飞出的落石、驶来的卡车）
4. 对剧情有承载作用（定钱、信物、凶器）

```
[媒介句] A product/prop reference photo, {按道具材质选媒介句}, flat even studio lighting.
[道具描述锚] {名称/材质/颜色/尺寸/磨损痕迹/标志性细节——固定文字，即道具锚定短语}
[状态] {当前状态：收起的雨伞/旋紧的杯盖/未拆封的信}
[构图] 纯白背景，道具完整居中，45度角展示主要特征面
[质感] {材质对应的真实质感词：金属反光/布料纤维/木纹}
```

规则：
- **有状态变化的道具，每个状态一张图**（雨伞收起态+打开态各一张；杯盖旋紧态+旋开态）
- 道具锚定短语存入 02 道具锚定节，与角色锚定同等逐字冻结
- 尺寸感写法：与参照物同框标注（"约 22 厘米高"写入描述锚）

#### 选型速查

| 项目类型 | 资产组合 |
| --- | --- |
| 写实人物（有侧/背镜头） | 三视图 + 面部特写（+按需表情板） |
| 写实人物（纯正面镜头） | 面部特写 + 白底正面全身 |
| 产物/动物主角 | 白底正面图（+按需侧/背视图） |
| 命中道具判定规则的物品 | 白底道具图（每状态一张） |
| 任何项目 | 人工参考层拼贴设定卡（自看，不喂 AI） |

### 1. 人物参考图（阶段2，产物/动物主角用；写实人物走骨架 0）

```
[拍摄媒介句] A character reference photo shot on medium-format camera, 85mm f/4, soft even studio lighting.
[主体锚定描述] {锚定短语}
[构图] 正面全身像，自然放松站姿，纯白背景，人物完整居中
[质感] natural skin texture, visible pores, realistic and imperfect, no plastic sheen
```

有侧/背镜头的情景图，参考图除正面锚定图外必须加对应视图；特写/近景镜头加面部特写锚定图。

### 2. 场景参考图（阶段3）

```
[拍摄媒介句] {见 realism.md 媒介句库，按风格选}
[场景全貌] {空间结构/主要道具/材质/生活痕迹：没喝完的杯子、搭着的毛毯——至少 2 处}
[光线] {时段+方向+色温，如"傍晚从左侧窗户斜射入内的暖橙色光"}
[景深层次] {前景：...；中景：...；背景：...}
[视觉张力] {明暗纵深/尺度对比/框中框/过曝欠曝分区——至少 1 法，见 realism.md 张力四法}
[风格圣经后缀] {02_锚定表中的风格圣经，逐字}
```

规则：
- 生活痕迹（lived-in）是去AI味的关键维度——空干净的房间=AI感
- 光线三要素（时段/方向/色温）齐全，将被情景图与视频提示词引用（光线锁定链）
- **场景多视图（条件强制）**：场景被 ≥3 镜使用 或 有正反打对话 → 按 extended-views.md 四视图法生成对向/斜角/俯拍视图，全部登记 02 场景锚定
- **LOCATION MAP（多角色场景必写）**：02 场景锚定内记录空间布局——各角色/关键道具的固定位置、朝向、相互距离（"主舞位于圆心，刘三位于舞台右前侧躺席，距离舞台边缘较近"），防跨镜人物瞬移

### 3. 情景参考图（阶段4，多图参考：人物锚定图+场景锚定图）

```
[参考图用途声明] Use image 1 only for the character's identity and appearance. Use image 2 only for the scene environment and lighting.
[拍摄媒介句] {与场景图同款或同风格}
[主体位置] {锚定短语逐字}，{在场景中的具体位置与朝向——按 LOCATION MAP}
[动作起点] {蓄力瞬间描述：有势能但不锁定方向}
[景别/机位/构图] {如"medium shot, off-center composition, shot through foreground foliage"}
[光线] {与场景图同时段同方向}
[风格圣经后缀] {逐字}
Aspect ratio {画幅}
```

规则：
- **一次多参考图生成，绝不编辑已生成的图换场景**（每次编辑累积伪影）
- **蓄力瞬间五标准**（此图即视频首帧）：①构图完整但不是"最终画面" ②有势能但不锁定方向 ③面朝方向留 2/3 空间（Lead Room）④身份清晰可辨 ⑤与下一镜光线一致或有合理变化路径
- 构图用"偏心+前景遮挡"防证件照感；"portrait" 单独出现会默认头像式构图，必须搭配景别机位词
- **画面需要出现文字时**（招牌/信件/屏幕）：正向写出确切文字内容与载体（`a wooden shop sign with the characters "营业中" carved on it`），不要只写"有文字"；画面不需要文字时正向写"画面保持干净无文字元素"
- **fl2va 项目每镜另生成终点图**：独立新生成（起点图+角色/道具锚定图+场景图作多图参考），起点图用途声明限定 `only for the exact camera position, framing and lighting`；同机位同景别同光线，只有主体到达动作终点；绝不编辑起点图

### 4. 资产引用矩阵（03 文件头必建——防资产浪费）

生成任何提示词之前，先建矩阵：

| 资产 | 引用镜头 | 生成必要性 |
| --- | --- | --- |
| {角色A}三视图 | 镜1/3/5（正侧面机位） | 必生成 |
| {角色A}面部特写 | 镜4（特写） | 必生成 |
| {角色A}_back 裁片 | 无背面镜头 | **不生成** |
| {道具}收起态 | 镜2/6 | 必生成 |
| {道具}打开态 | 无打开镜头 | **不生成** |

规则：零引用的资产**不生成**；矩阵随分镜修改同步更新。先矩阵后提示词。

## 二、视频提示词骨架（统一公式，模型无关）

> 骨架提炼自用户提供的优秀成品提示词（风格1：多镜头连续剪辑长片公式）。**所有视频模型共用此骨架**，模型差异只体现在参数（时长/分辨率/画幅上限查 models.md）与生成方式（i2v 首帧 / t2v 纯文本 / fl2va 首尾帧）。
> 两种粒度：**多镜头段落**（一条提示词生成 15-30s 含多个 HARD CUT 镜头的连续段落）与**单镜头**（一条提示词生成一个 3-8s 镜头，首帧图模式常用）。按项目节奏选择，可混用。

### 骨架 A：多镜头段落公式（风格1，叙事段落/对话戏/连续动作戏）

```
SCENE CONTEXT
{时代/时间/地点/空间。若续接上一段：延续上一条尾帧 {{Ref}} 的情绪与机位逻辑——描述上一尾帧内容（人物姿态/表情余韵/视线方向/光线/镜头高度），声明"本条必须从这个尾帧自然续上，不能突然跳成陌生构图"。整体气氛一句定调。环境声边界（如"无铺外市井声"）}

ACTIVE REFERENCES
@ {{Ref 1}} = {素材名}。锁定{具体锁定什么：脸/发式/体型/服装/气质，或空间布局/窗光/道具}。
@ {{Ref 2}} = ...
{每个上传素材一行用途声明；音频素材标注"{{Ref N}} 音频为角色X的配音"}

CONTINUITY RULE
{道具/状态连续性：不重新凭空"变出"新道具——沿用上一条已在画面中的那件；状态变化的道具写明当前状态与变化动作（"他用手把桌上的那枚银锭缓缓推向刘三"）；人物站位延续}

FORMAT
总时长{X}秒。{风格定调：如古装真人电影感/写实末日电影感}，真实表演，{对白语言}。
不要字幕，不要旁白{按需}。

CAMERA / EDITING
{整体剪辑节奏一句：如"以多镜头连续剪辑完成，节奏稳，不拖沓"。镜头语言的情绪走向：如"从'轻松试探'转向'低声委托'再转向'动心'"}

0.0s–3.0s｜镜头1｜{镜头标题}
{机位/景别/FOV：如"与上一条尾帧几乎同机位、同景别、同方向开场"或"18° FOV，近景"}。
{画面内容：主体+动作三段式（从{起始状态}，{过程：2-3个具体动词+速度/节奏词}，至{明确终点状态}）}。
{台词（如有）：
角色名：
"台词原文"}
{表演注：不是{容易演成的错误方向}，而是{正确心理状态}。核心是{这场戏真正重要的东西}}。

3.0s HARD CUT

3.0s–6.5s｜镜头2｜{标题}
{同上结构}

...

ENDING FRAME
{结尾停在什么画面：具体到"停在刘三手里银锭特写"或"拇指轻蹭银面的动作定住"。这个尾点要明确——它既是本片收束，也是下一条的衔接锚点}

PERFORMANCE LOCK
{每个主要角色一段：核心心理+不要演成什么。如"张磊：成熟、有钱、克制，不要演成坏人摊牌。这场是私下委托，不是威胁"}

AUDIO
{环境声边界（绝对不要X）+保留的具体声源清单（物体+动作+材质=声音："银锭在木桌上轻推的摩擦声"）+关键声音处理（"在X台词时背景进一步安静"）+台词间留白（"允许听到他一口很轻的呼吸"）}
{声音桥（跨镜/跨段衔接）：段尾声音渐弱描述或延续音声明，防硬中断——"环境声在最后1秒渐弱，只留{延续到下一段的声音}"；BGM：无背景音乐（后期统一配）}

LIGHTING
{光线锚逐字+光线连续性声明（完全延续上一场）+光线因果（随动作的自然变化："身体前倾时轻微进入更深阴影区域——是自然调度产生的，不是灯光突然改变"）}

NO
{本条禁止项清单：不要英语/字幕/配乐煽情/夸张表演/新增无关人物/突然换成陌生构图...}
```

**骨架 A 使用规则**：
- 每镜头块=时间区间+机位景别+画面+表演注，**台词写原文并绑定说话人**；无台词镜头靠表演注撑住
- HARD CUT 标注在每个镜头之间；特殊转场（MATCH CUT/披帛扫镜遮满画面）写明触发物与方向
- 镜头时长：对话戏 2-5s/镜，情绪留白镜头（"这1.5秒必须留下，不要剪快"）显式声明
- **表演注写"不是X而是Y"**：给模型排除容易演错的方向（"不是阴狠，不是反派，而是觉得值得一谈"）——这是成品提示词的共同特征
- 时长上限对照 models.md（happyhorse 3-15s / H3 5-15s）；**超过单条上限的剧本拆成多条连续段落**，段间用尾帧续接（SCENE CONTEXT 引用上一条 ENDING FRAME）
- 台词容量：正常语速朗读时长 ≤ 所在镜头时长（中文初始估算约 4字/秒，首集生成后按实测校准）；超长台词拆多镜
- 质感锚定行（V1.1 用户实测保留）：FORMAT 或 LIGHTING 节含一行紧凑质感词——介质质感+主体表面纹理（人物=自然皮肤纹理，物体=对应材质）+自然运动模糊，从风格圣经同族压缩
- 运镜平滑（V1.4 用户实测保留）：运动运镜必带"缓慢匀速平滑"限定+英文锚定词（slow smooth dolly in 等）；镜头动则主体动作放缓，主体动则镜头固定/极慢；特写/人脸优先固定机位

### 骨架 B：单镜头公式（i2v 首帧模式常用）

```
{不变声明：保持人物与背景不变。}
{动作三段式：主体从{起始状态}，{过程：2-3个具体动词+速度曲线}，至{明确终点状态}。}
镜头：{固定机位 / 平滑模板运镜}。
声音：{具体声源（物体+动作+材质）+声音桥（段尾渐弱/延续音）}，无背景音乐。
{质感锚定行：三项。}
{台词（如有）：角色（情绪+发声方式描述）说："台词"}。
画面严禁出现任何字幕/水印/logo。{画面需要文字时改为：画面中{载体}上有"{确切文字}"}
```

规则：
- **首帧已承载的视觉信息（外观/服装/背景）不在正文重复**——信息分工：首帧图管"长什么样"，提示词管"怎么动"；质感锚定不属于外观描述，必写
- 时长与容量：5s=1 动作节拍，10s=1动作+1反应，15s≤3节拍
- 无台词但有表演的镜头：微动作编排 3-4 个按时间顺序（"眨眼一次，视线微微下移，手指轻触杯沿"）

### 骨架选择器

| 场景 | 用哪个 |
| --- | --- |
| 对话戏/多人调度/连续叙事段落（15-30s 含多镜） | 骨架 A |
| 单镜头首帧图生视频（3-8s） | 骨架 B |
| t2v 纯文本生成整段 | 骨架 A（ACTIVE REFERENCES 节省略或改为文字外观锚定） |
| fl2va 首尾帧 | 骨架 B + 起终点图（03 配方） |
| 系列/多集项目 | 骨架 A 为主（尾帧续接机制天然支持集间衔接） |

## 四、校验规则（输出前单次终检，全部通过）

1. **单值规则**：所有速度词/光线词/景别词各只留一个值。矛盾=模型随机选边=不可控
2. **动作终点检查**：每镜自问"最后一帧长什么样"——答不出=重写
3. **容量检查**：5s=1 动作节拍，10s=1动作+1反应，15s≤3节拍；台词正常语速朗读 ≤ 所在镜头时长；**总时长对照 models.md 上限**（happyhorse 3-15s / H3 5-15s），超限拆条+尾帧续接
4. **反空话**：逐词过一遍——能被摄影机/麦克风/测光表/秒表检测到吗？"电影感/史诗感/8K/氛围感/高质量"→改写成景别+运动+光线+色调的具体组合
5. **风险运镜处理**：分镜用了高风险运镜（dolly zoom/360°环绕/长距离跟拍/crash zoom）→ 按 cinematography.md 双方案制处理（主方案保表现力+保底方案防崩坏，GATE1 呈现给用户选，不静默降级）
6. **锚定逐字校验**：锚定短语（角色/场景/道具）和风格圣经在每条提示词中逐字出现（复制粘贴，不是"意思相同"）；质感锚定行与风格圣经同族
7. **正向表述为主**：图片提示词以正向描述为主（要什么写什么）；视频提示词的禁止项集中在 NO 节/约束槽
8. **画幅一致性**：图片提示词画幅槽与 01 一致；视频模型为 H3 时首帧图与 aspect_ratio 同比例
9. **连续性校验（系列/多段项目）**：每条 SCENE CONTEXT 的尾帧描述与上一条 ENDING FRAME 一致；道具状态延续（CONTINUITY RULE）；光线连续（上段结尾的光=下段开头的光）；人物站位符合 LOCATION MAP
10. **表演注检查**：关键情绪镜头有"不是X而是Y"表演注；PERFORMANCE LOCK 覆盖每个主要角色
