## 使用规则

1. **触发才读**：只有项目风格/需求命中上表场景时才读对应文件；未命中不读，省 token
2. **一次一读**：单个项目通常只需 1-3 个扩展文件（如漫剧项目 = expressions + 可能 ugc-realism；武侠动作项目 = action-combat + director-styles 可选）
3. **融入锚定**：扩展文件中的风格内容（导演风格/UGC 质感/电影级参数块）一旦选用，其风格提示词并入 02_锚定表的风格圣经（作为扩展词条），全项目逐字复用——中途不换
4. **表情入库**：expressions.md 选定的表情词条**先按 FACS 引擎物理化改写**，再写入 01 分镜表"画面内容"列与 03/04 的表演描述，跨镜复用同一物理描述防漂移
5. **打斗戏强制**：动作戏项目必读 action-combat.md——武器力学与攻防状态机是打斗不崩的底线，镜头块按"Start State→Intent→Attack→Response→Impact→Recovery→End State"组织

## 负面词适配规则（全扩展库通用）

扩展知识库来自社区实战资料，其中大量使用了**负面提示词**（"不要XX/禁止XX"）。**原则：负面清单原文保留在知识文件中（换用支持负面提示词的模型时可用），使用时按目标模型适配转换**：

| 场景 | 负面词处理 |
| --- | --- |
| 图片提示词（gpt-image 等） | **以正向表述为主**——要什么写什么（"不要塑料感皮肤"→"natural skin texture with visible pores"）；画面需要文字时正向写出确切文字与载体 |
| 视频提示词（骨架 A） | 禁止项集中写进 NO 节——**只放字幕/文字类与音频/BGM 类禁令**（这两类反向描述有效）；画面类禁止项改写为正向概率引导（"坐姿端正像学生上课端坐"） |
| 视频提示词（骨架 B） | 约束槽固定句式（字幕/水印/logo 禁令） |
| 支持负面提示词的工具（即梦/可灵/SD 系/Midjourney --no 等） | 原负面清单直接可用 |

同理，扩展库中的 **"8K/超清/极致"类词是空话**（违反反空话规则）——引用时用具体质感词替换（胶片颗粒/皮肤纹理/材质细节）或电影级参数块（cinema-grade-params.md），原词不照搬。
