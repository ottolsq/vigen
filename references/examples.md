## 示例一：治愈自然类（30s · 单主体无台词 · i2v 主路线）

**输入**："30秒治愈短视频，小猫在雨天窗边睡觉"

**01 方案要点**：治愈柔和风格；情绪曲线 安静→小波澜（闷雷）→转暖→收尾；6 镜（0-3 空镜定场 / 3-8 全景建立 / 8-13 特写沉入 / 13-19 闷雷缩紧 / 19-25 雨歇伸腰 / 25-30 暖光定格）；运镜依次：慢推 / 固定+微动作 / 极缓推 / 固定 / 慢拉 / 固定定格（无重复动词；S1-S6 景别：特写→全景→大特写→中景→中景→特写，无连续3同景别）

**02 锚定表**：
- 角色锚定（无人物，锚动物）：`三个月大的橘白小猫，奶橘色虎斑纹、白色胸口白爪，圆脸短毛，微微鼓起的小肚子`
- 场景锚定：`老宅木质窗台，米白色针织软垫，一盆绿萝，一杯冒热气的红茶`；光线锚：`午后阴雨天，从左侧窗户透入的柔散冷灰光，室内一侧暖橙氛围灯`
- 风格圣经：`soft healing atmosphere, warm pastel tones, gentle diffused daylight, soft focus, airy and clean composition, cozy and calm mood`

**03 情景图示例（镜头4 · 闷雷缩紧）**（多图参考：小猫锚定图+场景图）：
```
Use image 1 only for the cat's identity and appearance. Use image 2 only for the scene environment and lighting.
A candid photograph shot on 35mm film, natural imperfect framing, ambient light.
{锚定短语逐字}，蜷卧在窗台软垫中央，头朝画面右侧，身体微微拱起呈半蜷姿态（尚未完全缩紧，留有继续蜷缩的余地），耳朵尖微微竖起。
medium shot, eye level, off-center composition，前景虚化的绿萝叶片占据画面左下角。
光线：午后阴雨天，从左侧窗户透入的柔散冷灰光，室内一侧暖橙氛围灯。
soft healing atmosphere, warm pastel tones, gentle diffused daylight, soft focus, airy and clean composition, cozy and calm mood
Aspect ratio 16:9
```
> 蓄力检查：半蜷=还有"缩紧"的势能；头朝右+右侧留白2/3=Lead Room；脸不被遮挡 ✓

**04 视频提示词示例（镜头4）**（首帧=上图，生成 7s）：
```
保持小猫与背景不变。
小猫从半蜷姿态，耳朵先轻颤一下、身体缓缓向内收紧、尾巴慢慢收拢环抱自己，至完全蜷成一团、鼻尖埋进前爪、耳朵放松贴伏。
镜头：固定机位。
声音：远处一声低沉闷雷滚过，雨滴密集打在玻璃窗上的沙沙声，小猫轻微的呼噜声，无背景音乐。
柔焦胶片质感，自然毛发纹理，自然运动模糊。
画面严禁出现任何字幕/水印/logo。
```
**自检**：最后一帧=完全蜷缩一团鼻尖埋前爪 ✓；无台词 ✓；动作1个节拍（缩紧+收尾）✓

## 示例二：人物剧情类（60s · 双角色有台词 · 锚定+台词+能量曲线）

**输入**："60秒短剧：深夜便利店，加班到很晚的女孩遇到暖男店员，一句话让她破防"

**01 方案要点**：电影写实风格；三幕（钩子0-5 冷雨夜便利店门口 / 建立5-20 店内暖光 / 升级20-45 对话破防 / 回落收尾45-60）；9 镜；能量曲线：低（门口冷色）→爬坡（店内对话跟拍）→峰值（台词特写慢推）→回落（门口再遇慢拉）

**02 锚定表**：
- 角色A：`26岁女性，清瘦单薄肩，黑色长直发微塌有几缕碎发，眼下淡淡青影，米白风衣内搭灰色高领毛衣，左手无名指戴细银戒，疲惫但不邋遢`
- 角色B：`30岁男性，中等身形圆脸，深棕色短发利落，藏蓝色围裙配白T恤，手腕戴旧电子表，笑起来眼角有细纹`
- 场景锚定：`深夜便利店内部，暖白顶光货架过道，关东煮蒸汽，玻璃门上雨珠`；光线锚：`深夜，店内暖白顶光为主光，玻璃门外冷蓝雨夜为背景对比`
- 风格圣经：`cinematic realism, shot on 35mm film, natural color grading with warm highlights and slightly desaturated shadows, visible film grain, shallow depth of field, realistic natural lighting`
- 音色：A=`[林夏，普通话，疲惫沙哑的青年女声]`；B=`[店员，普通话，温和低沉的青年男声]`

**03/04 台词镜头示例（峰值镜头 · 破防台词）**（情景图蓄力描述：林夏中近景，眼睛微红但没落泪，嘴唇微张欲言又止——蓄力瞬间；构图 medium close-up，eye level，off-center，前景虚化的货架边缘。画幅 Aspect ratio 9:16）：
```
保持人物与背景不变。
林夏从嘴唇微张欲言又止，喉头轻轻滚动一下、眼眶缓缓湿润、嘴角先是勉强上扬再慢慢垮下，至一滴泪沿脸颊滑落、低头用手背快速抹掉。
镜头：镜头缓慢匀速平滑推近（slow smooth dolly in）。
声音：便利店冰柜低鸣，关东煮咕嘟声，极轻的雨声背景，无背景音乐。
真实胶片质感，自然皮肤纹理，自然运动模糊。
画面严禁出现任何字幕/水印/logo。
```
（台词"今天……谢谢你还记得我"走 05 台词表：14字÷约4字/秒≈3.5s ≤ 镜头时长，cosyvoice 或视频模型直出，发声方式描述句绑定情绪——视频端该镜可无台词纯表演，台词后期对轨）

## 示例四：多镜头段落（骨架 A · 对话戏浓缩展示）

**输入**："盛唐算命铺，张磊低声委托刘三劝人休妾，推银锭定钱"（24s 段落，节选前 3 镜）

```
SCENE CONTEXT
盛唐，白日，刘三的府城算命铺内。延续上一条尾帧 {{Mixed 1}} 情绪与机位逻辑——张磊侧脸近景，
嘴角带一点被说中的笑意，正朝门帘方向看去。本条必须从这个尾帧自然续上，不能突然跳成陌生构图。
整体气氛安静、私密、带一点交易感。无铺外府城市井声。

ACTIVE REFERENCES
@ {{Mixed 1}} = 上一条尾帧。作为开场衔接锚点，锁定张磊侧脸方向、笑意余韵、光线、镜头高度。
@ {{Mixed 2}} = 刘三LOOK。锁定脸、发式、体型、蓝灰华贵服装。
@ {{Mixed 3}} = 张磊中年马贩伪装LOOK。锁定脸、发式、深色体面服装。
@ {{Mixed 4}} = 算命铺室内空间。锁定布局、窗光、帘幕、木桌、香炉。

CONTINUITY RULE
不重新凭空"变出"新的银锭——沿用上一条已在桌上的那枚。张磊说"这是定钱"时用手把它缓缓推向刘三。

FORMAT
总时长24秒。古装真人电影感，真实表演，中文对白，半文言但通俗易懂。不要英语，不要字幕，不要旁白。
真实胶片质感，自然皮肤纹理，自然运动模糊。

CAMERA / EDITING
以多镜头连续剪辑完成，节奏稳，不拖沓。镜头语言从"轻松试探"转向"低声委托"再转向"动心"。

0.0s–3.0s｜镜头1｜延续尾帧
与上一条尾帧几乎同机位、同景别开场。张磊保持侧脸近景，目光仍朝门帘方向。
脸上笑意慢慢收住，轻轻把目光收回，准备开口。
表演：不是阴狠，不是反派。而是一个成熟有钱人觉得这算命先生值得一谈，开始说正事。

3.0s HARD CUT

3.0s–6.5s｜镜头2｜张磊发问
中近景，略带桌边前景。张磊看向刘三，语气平稳：
张磊："城里王家肉铺的王大头，你可认得？"
表演：声音压低一点，但不是鬼祟耳语。像在试探。说话清楚、从容、有分寸。

6.5s HARD CUT

6.5s–8.5s｜镜头3｜刘三回答
切刘三中近景。刘三先不急着表态，眼神略停一下，再答：
刘三："听过，不熟。"
表演：谨慎。不是冷淡也不是热络——像做这行的人本能先留余地。

{…后续镜头至 ENDING FRAME：停在刘三拇指轻蹭银面的动作定住…}

AUDIO
只保留室内环境声：极轻空气感，布料摩擦，手指触碰银锭，银锭在木桌上轻推的摩擦声，自然呼吸与对白。
"这是定钱"时背景进一步安静。段尾环境声渐弱，只留银锭轻响延续到下一条。无背景音乐。

LIGHTING
完全延续上一场：柔和侧逆光穿过格窗与帘幕，空气中有微尘与轻烟，光束可见。暖金与青灰平衡。

NO
不要英语，不要字幕，不要配乐煽情，不要夸张表演，不要新增无关人物，不要铺外喧闹声。
```

**要点**：①尾帧续接写在 SCENE CONTEXT（上一条 ENDING FRAME = 本条衔接锚点）②道具连续性写进 CONTINUITY RULE（银锭不凭空变出）③表演注全是"不是X而是Y"④台词绑定说话人+表演分寸⑤AUDIO 含声音桥（段尾渐弱+延续音）防硬中断。

## 示例三：科技概念类（15s · 无人物 · 风格圣经+运镜动机）

**输入**："15秒产品概念视频：一台悬浮的透明智能音箱"

**01 方案要点**：科技概念风格；3 镜（0-3 悬浮定场 / 3-9 唤醒交互 / 9-15 光效收尾）；运镜依次：环绕半弧 / 固定+微动作 / 慢拉+定格（避高风险的360°全环绕，用半弧90-180°+补镜）

**02 锚定表**：
- 主体锚定：`悬浮的透明玻璃圆柱体音箱，内部可见环状发光元件，底座为哑光银色金属圆盘，顶部一圈呼吸灯`
- 场景锚定：`深灰色极简展厅，背景是柔和的渐变幕布，地面有微反光`；光线锚：`无时段，冷白主光从顶部45度，产品边缘轮廓光青蓝色`
- 风格圣经：`futuristic tech concept style, cool blue and silver palette, clean studio environment with soft gradient background, product-hero lighting with rim light, high detail`

**03 情景图示例（镜头1 · 悬浮定场）**（多图参考：音箱白底正面图+场景图）：
```
Use image 1 only for the speaker's identity and design. Use image 2 only for the scene environment and lighting.
A product hero shot in a minimalist showroom, medium shot, slight low angle, off-center composition.
{主体锚定逐字}，悬浮在展厅中央偏左，环状发光元件处于暗态（尚未点亮——留有点亮的势能），顶部呼吸灯极缓明灭。
光线：冷白主光从顶部45度，产品边缘轮廓光青蓝色。
前景：地面微反光；中景：音箱本体；背景：柔和渐变幕布。
futuristic tech concept style, cool blue and silver palette, clean studio environment with soft gradient background, product-hero lighting with rim light, high detail
Aspect ratio 16:9
```
