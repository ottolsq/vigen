# 剧本创作与定稿（阶段1a 专用——剧本没定稿不进分镜）

> **何时读**：阶段1a 剧本创作时必读。本文件解决两个问题：①把用户的创意/大致剧本细化成可拍摄的剧本 ②用"AI 剧本 7 大漏洞清单"自检后交用户定稿（GATE1.5）。
> **为什么剧本必须先定稿**：剧本是全部下游文件（分镜/锚定/图片/视频提示词）的唯一数据源——剧本改一句，下游全部重做。在剧本阶段与用户讨论的每一分钟，都在节省下游返工的十倍成本。
> 源：AI 剧本漏洞分析资料（other6.md，用户提供的社区实战总结，2026-10）。

## 一、AI 剧本 7 大漏洞自检清单（GATE1.5 呈现前逐条过，结果写进 01）

### 漏洞1：小说化——堆砌无法拍摄的心理描写与氛围形容词

- **症状**："他感到前所未有的心碎"、"空气中弥漫着绝望"——无法转化为摄影机画面或演员动作
- **改法（意义与载体分离）** [drama-skills: script-craft.md#4.1/4.2]：作者意图（"她终于意识到父亲一直不相信她"）不是不能写，是要为它找到**载体**——五类可选：
  - **行为选择**：她停止解释，把准备交出的证件收回
  - **证据反应**：父亲先核对陌生人的签名，却把她的证词推到一边
  - **空间动作**：她从父亲身旁移到被质疑者一侧
  - **关系动作**：她把一直替父亲保管的钥匙放下
  - **有意标记的声音**：明确用 `[VO]`，让主观声音成为叙事选择（不是默认旁白）
  - 载体不必把意义解释完——**演员可执行、观众有依据推断即可**
- **弱/强对照例句**（心理词→可表演动作，逐字）：
  - 弱："他很心虚，眼神复杂，内心充满挣扎。"
  - 可执行："他把盖章页翻过去，只递出没有签名的那一面。门外的人伸手时，他仍按着纸角。"（没命名全部情绪，却给了目标、阻力和持物状态）
  - 每个心理/氛围词强制翻译为可见的身体变化或环境细节（联动 emotion-craft.md）："心碎"→"捏着杯子的手指关节发白，视线落在桌面某一点不再移动"；"弥漫着绝望"→"窗帘一整天没拉开，桌上的粥结了皮"
- **痛点写成一场戏** [drama-skills: script-craft.md#4.4]："'他一直被人看不起'不是痛点；'酒席上，反派当众把酒泼在他脸上'才是。"观众看见了被压下去的那一下，后面的回报才有落点——抽象处境要落成一个可见的具体事件
- **用可表演动词**：动作段落优先写人物能做的事（压住/抽回/避开/递出/擦掉/停下/拆开/锁上/挡住/撕下），不为"可见"堆满微表情；动作的价值在于改变空间、物件、注意力或关系
- **自检操作程序**（见第二节自检表漏洞 1 行）：圈出全部心理词，逐个指定五类载体之一，指定不了的删或改写

### 漏洞2：台词书面化——没人话、缺市井气息、缺潜台词

- **症状**：对白太工整、缺角色定位；AI 不理解"言不由衷"——让主角把怨恨、真实身份、下一步计划直接吼出来；台词是信息朗读或情绪宣泄，不是"对对方做一件事"
- **根因**：台词缺"行动维度"。没有议程的台词只能是念信息或吼情绪——下面①-⑤是把台词从"说了什么"升级到"在做什么"的完整机制。

**① 台词议程卡（写对话前，每个主要说话者先填）** [drama-skills: dialogue-craft.md#2]

| 问题 | 角色甲 | 角色乙 |
| --- | --- | --- |
| 此刻想让对方做什么？ | | |
| 最怕对方看见/说出什么？ | | |
| 手里有什么筹码？ | | |
| 哪件事不能公开说？为什么？ | | |
| 先用什么策略？失败后怎样换？ | | |
| 哪条底线受到压力才会越过？ | | |

核心："**两人可以表面谈同一件事，实际争不同结果**"（都在谈"交钥匙"：一人要结束控制，一人要迫使对方承认责任）。先写"这句话想对对方做什么"，再决定字面表达——没有行动目标的句子通常可以压缩或转为动作。

**② 台词是一种行动（同一事实五说）** [drama-skills: dialogue-craft.md#3]

同一个事实可以执行完全不同的动作。事实："门在九点锁。"

- **催促**："你还有三分钟。"
- **推责**："九点以后，钥匙不归我管。"
- **试探**："你是不是以为九点以后没人进得来？"
- **威胁**："九点一到，里面是谁都不重要了。"
- **保护**："九点前走，我就当没见过你。"

判据：**字面信息相近，关系动作完全不同**。写每句台词先答"这句话在对对方做什么"（逼问/遮掩/交换/试探/推责/保护…）——标不出行动且不承担必要信息的句子，删掉或改成动作。

**③ 策略库与"策略必须受阻"** [drama-skills: dialogue-craft.md#3.1/3.2]

按人物目标选策略：要求/命令/请求/交换；试探/诱导/套话/验证；重新命名问题/缩小或扩大责任；先承认一部分以保护更大秘密；借第三人或公共规则施压；假装无所谓/拖延/转移；把选择交还对方；暴露自己愿付的代价；拒绝旧称呼或旧关系位置；用沉默迫使对方继续说。

**策略必须会受阻**——"若一方每句话都成功，对话会变成演讲"。让另一方反制（7 法）：看穿并点破策略／接受字面条件却拒绝隐含关系／提供反证／改变公开范围／把对方的词反过来用／拿走说话所依赖的时间·物件·身份／不给预期反应。**一轮对话中策略受阻后应换策略、付代价或退出——重复同一句要求只会延长时长**（有意的重复只在能改变效果或关系时才用：仪式/创伤/压迫/喜剧）。

**④ 潜台词三层（来自已知差与风险）** [drama-skills: dialogue-craft.md#4]

- **潜台词纪律（保留）**：文戏博弈中角色**不直接说出核心信息**——用指桑骂槐、眼神试探、答非所问、话说一半呈现。检验法：把台词直白化（"我恨你骗了我"），直白版和剧本版意思一样=台词失败；冰山露一角，水下靠表演注承载
- **三层写法**（不要求每句都复杂）：①字面层（实际说了什么）②行动层（想让对方做什么）③**风险层（为什么不能直接说**——说出会暴露秘密/失去体面或关系/现场有第三人/尚未确认对方知道多少/直接要求会显得没筹码/连自己都不愿承认）
  > 例："你把窗户关上吧，外面的人都听得见。"——字面：要求关窗；行动：把对话从公开变私下，夺回解释权；风险：怕某个事实被第三人听见。
- **反向保护**："**若现场没有外人、秘密或权力差，这句就只是生活指令，不自动具有潜台词**"——不为含蓄而含蓄
- **可观察线索**（潜台词不能完全依赖作者事后解释，要给观众推断依据）：角色避开一个具体词／对方触碰或藏起相关物件／称呼改变／先回答旁枝拒绝核心问题／台词与可见证据矛盾／第三人进入后语言突然改变

**⑤ 声音五维与交换说话者测试** [drama-skills: dialogue-craft.md#6/10.5]

"一个总说成语，一个总说网络词"只是表面。更稳定的声音来自人物看世界和处理关系的方式——**五维**：①注意什么（流程/感受/风险/体面/具体物件/长期后果）②怎样证明（举证/引用规则/讲关系/诉诸经验/逼对方表态）③怎样控制距离（直呼名字/用称谓/说"我们"/避免代词/公开或私下说）④怎样隐藏（多解释/反问/开玩笑/沉默/改话题/过度精确）⑤压力下怎样变形（更正式/更短/更礼貌/更粗暴/开始重复或突然坦白）。加关系特异性：同一人物面对上级、家人、陌生人、需要保护的人，语言策略不同。

> 三声音例句（同一事实"原件仍在店里"）：重证据的岑予"房东收到的那页没有骑缝章。原件没出这道门。"／重承诺的岑放"我答应交，不等于已经交。"／重体面的房东"我只确认收到文件，不参与分辨你们家的哪一份算原件。"

**交换说话者测试（修订用）**：暂时互换两人台词——①情节和关系几乎不变=缺目标/证据观/关系风险，补入；②只是词汇不合但行动通用=表面口癖过多、人物策略过少；③交换后明显违背"谁愿付代价、谁能公开、谁回避什么"=声音基础稳。

- **台词指纹（口头禅/语气词/称呼方式）是最后一层微调，不是区分主体**：先用五维区分，再用词汇节奏微调；写进 02 角色锚定（发声方式描述句的剧本层依据）。同一句台词换三个角色说，应该一听就知道是谁——但"一听就知道"靠的是策略与认知差，不是口癖
- **呼吸感（保留）**：允许不完整句、打断、重复、语气词（"你……算了""不是，你听我说"）
- **台词密度（保留）**：不是每镜都有话——沉默镜头（对方不接话、只有动作）是张力来源
- **自检操作程序**（替换主观问句，证据引用见第二节）：①每句台词旁标注它在做什么（行动动词），标不出且不承担必要信息的删掉或改成动作 ②删掉角色名朗读全段，能否凭策略和措辞辨认谁在说 ③互换两人台词，情节关系是否改变（不变=补目标/关系/认知差）

### 漏洞3：桥段同质化——老梗拼凑

- **症状**：提示词稍宽泛就输出被市场淘汰的套路——泼咖啡、扇耳光、掏出全球限量黑卡、撞怀里捡文件、雨中追车
- **改法**：
  - **黑名单自查**：写完剧本逐情节对照黑名单，命中的桥段要么换掉、要么给用户一个"非用不可"的理由（类型片惯例）
  - **反转一次**：每个关键冲突问"最俗的演法是什么"→ 反着来（该扇耳光的地方改成极轻的一句狠话；该泼咖啡改成把咖啡慢慢推过去让对方自己看）
  - ** specificity 优先**：用该剧本独有的细节替代通用桥段（信物是"没寄出的信"就用信做冲突载体，不要另起一个通用道具）
  - **误会四判据**（AI 拖时长的重灾区）[drama-skills: script-craft.md#3.4]：**"误会的失效点几乎总在解除的那一刻"**——最常见失败写法是"误会产生→拖了几场→解释清楚→一切照旧"，这样的误会整段可删。四判据：①**人物有理由不解释**（一句话就能澄清而谁都没理由不说=拖延不是戏；理由可以是保护别人/承认代价太大/没机会开口，但必须写出来）②**观众位置选定**（知道真相=悬念；不知道=惊讶；**选一种贯彻**，摇摆=两种效果都没有）③**误会必须产生行动**（只让人物"心里难过"撑不起场次；要让人做出真相下绝不会做的选择）④**解除时必须有残余**（澄清后关系回不到原点：有人看见了对方压力下的选择/有人欠下道歉/有人失去了本可不失去的东西——没有残余=这条线没兑现）
  - **巧合方向性**：**"把人推进麻烦可以，把人从麻烦里捞出来不可以"**——困境靠巧合解除时，前面所有压力作废；巧合送来的必须是负担不是礼物
  - **反转一句话测试** [drama-skills: reveal-reversal-payoff.md#4]：反转必须能完成一句话——`因为<已建立的事实/选择>，原计划<为何不再成立>，人物现在只能在<新代价A/B>之间行动`。弱反例："陌生人突然出现宣布一切都是梦"——改变信息却没从人物行动长出。常见可用反转：胜利触发对手有准备的程序反制／证据是真的但证明的是另一项责任／被保护者拒绝保护方式／主角的长处暴露新盲区／关系盟友要求兑现此前承诺／规则没失效但人物用规则改变了时间或权限
  - **公平揭示五问** [drama-skills: reveal-reversal-payoff.md#3]：①观众是否见过足够的可解释迹象？②谁在此前能接触事实，谁不能？③证据为何现在出现，而不是作者需要时凭空出现？④新事实排除了什么旧解释？⑤得知后谁必须改变行动？——有效揭示常通过**重新连接旧事实**让观众和人物获得新解释（订书孔方向相反→意识到抽走的是中间一页→"补签"计划失效）
- **黑名单（初版，持续积累）**：泼咖啡/扇耳光/限量黑卡/撞怀捡文件/雨中追车/机场追人/医院走廊狂奔/宴会酒杯碎裂全场安静/失忆车祸/偷听门缝

### 漏洞4：长程记忆衰减——设定前后矛盾

- **症状**：剧集拉长后遗忘前文核心背景——前文是隐姓埋名的普通人，后文突然展现不符合设定的神通；配角姓名/关系/战力自我打脸
- **改法**（本 skill 的结构性防线）：
  - 设定唯一权威 = 02_锚定表（角色能力/关系/外观冻结），剧本写作时逐条对照
  - 系列项目 = 00_剧情状态.md 每集强制更新，新一集剧本先读 00 再动笔
  - **能力/知识边界表**：角色"会什么/不会什么/知道什么/不知道什么"写进 02——角色做出超出边界的行为前先检查（"他此时还不知道信的内容"）
- **自检问法**：每个角色的每个行为，他此刻有能力/有信息做到吗？

### 漏洞5：反派脸谱化降智——为坏而坏

- **症状**：反派没有独立行动逻辑与深层动机，像毫无自控能力的疯子；主角胜利毫无含金量；前 10 集靠强矛盾撑着，后面乏善可陈注水
- **改法**：
  - **反对不是说"不"（7 种反对方式）** [drama-skills: script-craft.md#3.2]：反对方可以——①重新定义问题 ②交换条件 ③拿走行动所需资源 ④质疑证据来源 ⑤让公开代价高于私下妥协 ⑥与第三人结盟 ⑦表面答应但改变执行条件。**"有效反对会迫使焦点人物更换策略，而不是延长同一轮喊话"**——只会说"不"或只会沉默离场的对手是脸谱化的根
  - **反派三问**（反派特化版，写进 01 人物小传）：他要什么（目标独立于主角存在）？他为什么觉得自己是对的（自洽逻辑）？他的手段为什么聪明（让主角难赢）？
  - 反派的每个行动先满足他自己的目标，"针对主角"只是路径交集——不是存在意义
  - 反派可以赢回合：让主角付出真实代价（输一次、失去一样东西），胜利才有含金量
- **自检问法**：把反派当他自己故事的主角，他的行为线成立吗？

### 漏洞6：安全机制消解张力——矛盾总被"理性友好"解决

- **症状**：需要把人物推入绝境、制造你死我活极端矛盾时，AI 不自觉让角色握手言和、讲大道理——直接扼杀戏剧张力
- **改法**：
  - **绝境纪律**：高潮段禁止用"讲道理说服"解决核心冲突——解决方式必须是行动/代价/选择（三选一），大道理最多是失败者的遗言
  - **代价显性化**：每次冲突解决都写明失去了什么（关系/物品/机会/身体）——没有代价的解决=张力泄漏
  - 道德复杂性保留：可以没有纯粹的赢家；用户剧本要求极端冲突时如实呈现（内容合规底线由视频平台审核承担，剧本层面不自我阉割戏剧张力，但血腥/色情的直接描写仍按平台规范做影视化替代——用镜头语言、光影、动作张力传递，见 cinematography.md）
- **自检问法**：高潮的解决方式是"说服"还是"行动"？赢了的人付出了什么？

### 漏洞7：微表情与道具互动缺失——文戏变两人干讲

- **症状**：AI 很少主动设计角色与环境、小道具的互动细节，导致文戏变成两个人干巴巴对着讲
- **改法**：
  - **每场文戏至少 2 处道具互动**：写作时给角色手里/身边安排"活"（转笔、剥橘子、擦杯子、系鞋带、掐灭烟）——道具互动承担情绪外化（说话内容平静，剥橘子的手在抖=潜台词可见化）
  - 道具互动与台词节奏咬合：关键台词落在道具动作的停顿点上（"这是定钱"说出时银锭恰好推到对方面前——风格1 成品的做法）
  - 联动物具判定（prompt-rules.md）：互动道具大概率命中"被触碰改变状态/镜头对焦"→ 入 02 道具锚定
  - 特写镜头的表演描述按 expressions.md FACS 引擎物理化
- **自检问法**：这场文戏里角色的手在干什么？删掉所有台词，观众还能看懂情绪吗？

## 一·四、场景与升级因果（防"两人干讲"与"事件可互换"——冲突场写正文前先过本节）

[drama-skills: script-craft.md#3, episode-design.md#3.4/5.2/5.3]

### 场景发动机工作卡（冲突场景写正文前，8 项先列全）

| # | 项 | 问什么 |
| --- | --- | --- |
| 1 | 场景必要性 | **删掉这场会损失哪项选择/证据/关系变化？**答不出=这场没存在的理由 |
| 2 | 进入状态 | 开场时谁知道什么、谁占上风、什么悬着 |
| 3 | 焦点人物目标 | **可执行化**——"想获得尊重""想弄清人生"太宽；落成"让对方在众人面前承认记录被改过""在门关闭前拿到钥匙""阻止妹妹读出遗嘱附页" |
| 4 | 反对议程 | 对手在这场要什么（见漏洞 5"反对不是说'不'"七式） |
| 5 | 行动场域 | 这场在哪个空间、有哪些可用物件/出口/第三人 |
| 6 | 策略变化 | 焦点人物先用什么策略、受阻后换成什么 |
| 7 | 方向性转向 | **转向测试**：转向前人物准备做什么？转向后为什么不能照做？——答案只是"更生气"=还缺新的事实、筹码、关系或决定。**不以对手无因沉默或离场代替转向** |
| 8 | 退出状态 | 收场时上述哪项被永久改变了 |

> 氛围场/仪式场/蒙太奇/过渡场/后果处理场可以不用冲突组织，但必须靠**知识、关系、压力、节奏或制作状态的必要变化**自证——不要为了满足本卡硬造一个对手。

### 因果升级链（拖沓的核心解药——事件可互换=注水）

不要预填"发生若干次冲突"，写成**选择链**：

```
因为进入状态中的事实 A，人物采取行动 B；
行动 B 触发反制 C；
C 让状态 D 改变，迫使人物放弃旧策略或付出更大代价。
```

**"然后/所以/但是"朗读诊断**：把相邻节拍连起来读——如果只能用"**然后**"（而不是"所以/但是"）连接，检查是否缺了：人物选择、对抗反应、可见后果、下一股压力之一。缺哪个补哪个。

### 升级六问（假升级=更强烈的表演词，真升级=可引用的状态变化）

对比两个相邻冲突，必须能答出**至少一条**：

1. 谁掌握的**筹码**变了？
2. 谁知道的**事实**变了？
3. 哪段**关系的边界**变了？
4. 哪条**退路**消失了？
5. 谁作出了**不可撤回的决定**？
6. 哪个**后果从威胁变成现实**？

> **没有可引用的状态变化，不能只凭更强烈的表演词声称升级**（"更生气、更吵、更危险"不算升级）。

### 【峰】标记衔接

升级链里"结果改变最大"的节拍、情绪爆发/重大反转/打脸拍 = 情节点清单标 **【峰】** 的候选（CT4，见 assets/templates.md 01 情节点清单）——【峰】是强调手段（慢镜/冲击重复/短促推近/定格/闪白）的唯一合法落点，配额与标注见 cinematography.md「峰值与强调手段」节。

## 一·五、钩子与悬念纪律（分集/分段叙事的结构性要求——自检第 8-10 条）

1. **钩子必须在前 3 拍内以具象兑现，且必须在运动中给**：✗ 静物特写"旧皮箱抱在怀里，指节掐白"（静态细节留给第二落点）→ ✓"她抱着旧皮箱在雾里跑"。开场第一个画面就要有"正在发生的事"，不是"值得看的东西"
2. **进场三件套**（每场开场的标准节拍）：运动主体（谁在动）→ 大远景定场（这是哪）→ 关键局部特写（观众该盯什么）——三拍内完成，别用空镜堆氛围开场
3. **每集/每段最后一拍必须是悬念**：一句没说完的话、一声来历不明的响、一个刚出现的影子——收尾拍不给"情绪总结"，给"下一个问题"
4. **上集结尾的悬念，下集开场要"接住但不解开"**：接住=同一空间/同一情绪延续（尾帧续接机制的剧本层）；不解开=不许开场 3 拍内就把上集悬念答案给完，先让它在场
5. **当集兑现（钩子只吊胃口=拖沓——先给再吊）** [drama-skills: episode-design.md#3.6/4.2]：每集/每段在留下新压力之前，先给一个**局部结果**——观众为什么不会觉得这一集只在拖延？兑现四选：看见能力或代价显形／回收部分旧问题／完成一次关系变化／一个不可撤回的选择。**"马上要揭晓"不是回报**。出去压力必须由本集结果产生（"本集的胜利让谁失去东西、从而会怎样反制"）——**不成立的替代品：无来源的新人物踹门、反派重复上一集的威胁**。与第 3 条"末拍悬念"是一给一收的关系：先兑现（给），再钩子（收）；只收不给=空转。单条短视频按"段"理解同一纪律
6. **自检问法**：前 3 拍有没有"正在运动的具体事件"？最后一拍观众会不会想点下一集？上集悬念是接住了还是被无视了？**这一集兑现了什么（指出具体结果），还是只在吊胃口？**出去压力是从本集结果长出来的，还是凭空踹门？
7. **机器认领**：在 01 场次节拍表里把钩子具象那一拍标 `【钩子】`、结尾悬念那一拍标 `【悬念】`——K14 只查位置（前 3 拍 / 末拍），"在运动中给"是写作纪律，门查不了。

## 一·五·五、能演的不说（复述禁令与说明传递——拖沓的直接来源）

[drama-skills: script-craft.md#4.4, dialogue-craft.md#5]

**复述禁令**：

- 画面已经演出来的事，`[VO]`/旁白不再说一遍——"她当众把欠条撕成两半，已经说明她不认这笔账，旁白就不必再补一句'这钱我不会还'"
- 反过来，台词已经说清的事，下一场也不再演一遍
- **两种载体重复时，留演出来的那一个**
- `[VO]` 只承担画面给不出的东西：与画面相反的判断、被隐瞒的打算、跨时间的认知
- **内心独白外化**：大段"我穿越了""我一定要……"换成一个动作加一句台词；让旁人把心里话说出口；让手机屏幕、证件、胎记这类物件在画面里交代身份；必要的回忆只保留当前行动所需的闪回

**说明改传递**（背景介绍不拖沓的写法）：

- **人物不会为了观众重复彼此都熟知的事实**
- **过去事件只说当前动作需要的最小片段**
- **若一句台词只复述观众刚看到的因果，删掉后画面仍完整，就让人物回应结果**
- 弱/强对照例句（逐字）：弱——"我们这家店是母亲二十年前开的，她把合同放在纸柜里。"带议程——"你要真觉得这只是家店，就别拿母亲那把纸柜钥匙。"（不必一次交代所有背景，却把历史、所有权和当下动作绑在一起）

**自检**：逐句台词问"这句话承担的信息画面里已经有了吗？"——有=删；VO 与画面是否说同一件事——是=留画面删 VO。

## 一·六、知识揭示状态 + 单一瞬间（分镜前的两条防泄漏检查）

1. **知识/揭示状态表**（写进 01，与情节点清单配套）：每个关键时点登记"各角色此刻知道什么 / 观众此刻看过什么"——**后续揭示不许泄漏进更早的画面**（角色此时还不知道信的内容，他的表情/走位/台词就不能"演给知道的人看"；观众还没见过凶器，早期镜头背景里就不能出现它）。故事时间序 ≠ 观众接收序，两者都要查
2. **单一瞬间规则**：一个镜头只装一个瞬间，不把连续状态叠进一帧——"倒计时进行中"与"快门已响"是两个瞬间；"雨开始下"与"地面已积满水"是两个瞬间。剧本里"他渐渐…"类渐变描述，分镜时必须拆成两镜或选定其中一态
3. **场内相机 vs 观众视点**：画面里出现的相机/镜子/屏幕是场内物体——人物目光须同时符合"看场内相机"与"观众视线"两条逻辑（自拍镜头里人物看镜头=看场内相机，合法；第三人称镜头里人物盯着"观众"看=穿帮，除非刻意打破第四面墙并登记理由）
4. **自检问法**：这镜里角色/观众有没有看到他们此刻不该知道的东西？这一帧是不是把两个时刻叠在一起了？

## 一·七、故事三层分离（改编/细化用户素材时的忠实纪律）

细化用户创意或改编素材时，产出内容分三层记账（写进 01，防"AI 脑补冒充用户设定"）：

| 层 | 内容 | 纪律 |
| --- | --- | --- |
| **Source Facts**（素材事实） | 用户原文/原设定里显式给出的动作、对白、人物关系、场景 | 忠实保留，不改写不美化；GATE1.5 呈现时标"来自你的原文" |
| **Interpretations**（解读） | skill 对潜台词、动机、关系的推断 | 写明支撑它的原文行为；素材本身有歧义时**保留歧义**并在待决问题里问用户，不选定 |
| **Visual Proposals**(视觉提案) | skill 新增的视觉选择（服化道/场景细节/运镜设计） | 不冒充原作设定；GATE1.5 呈现时标"skill 补全项"，用户可否决 |

反虚构纪律：没读到的部分不许声称读过（"按原著后面的剧情…"=禁止）；不引入用户没提的演员脸/名场面记忆/后续剧情。

## 一·八、节拍流与时长预算（阶段1a 的结构层——分镜前的机器索引）

**节拍 = 一拍一件事或一句台词**，不是情节点。情节点管故事有没有被拍到，节拍管这 2-5 秒具体拍哪一拍。01 的「场次节拍表」是机器索引，不是第二份剧本；台词原文仍以分场剧本为准。

### 节拍写法

1. 一拍只属于一种类型：动作或台词。动作+台词要拆两拍。
2. 动作拍写"谁做了什么"，台词拍写"谁说了什么"；内容摘要 ≤20 字，不复制台词原文。
3. 动作要常见、可生成（挑担上船/搭手卸担/抬头看岸边），不写精确物理交互/微表情/文学比喻。
4. 每拍一个认领镜号；一镜可认领多拍（多行同镜号）；纯转场/空镜写 `—`。
5. 钩子拍标 `【钩子】`，必须落在前 3 拍；结尾悬念拍标 `【悬念】`，必须是末拍。

### 时长预算（先算再排分镜）

- 台词：4 字/秒（含标点）；台词秒数 = `ceil(台词字数 / 4)`
- 动作：2.5 秒/拍；动作秒数 = 动作拍数 × 2.5
- 预计总时长 = 台词秒数 + 动作秒数
- 容差：`|预计 - 目标| ≤ max(目标×15%, 2.5s)`；超出先砍动作拍，不足补冲突不补寒暄
- 参考体量：2 分钟约 35 拍（台词 20 句上下）；3 分钟约 45-55 拍（台词 30 句上下）
- 门：K13 核对节拍认领，K14 核对钩子位置与预算（模板见 assets/templates 01 的「场次节拍表」「时长预算」）

**修改纪律**：改一拍，连读前后各一拍，专查人物位置/道具在手状态/谁在场；改画面，声景三处同步（画面/声景/分镜表）。

## 一·九、竖屏短剧形态（形态 B）覆盖规则

> **何时启用**：项目 `【叙事形态】=竖屏短剧`（字段在 00/01 立项单）。电影化项目**不读本节**，按前八节执行。
>
> **优先级**：本节是**覆盖规则**，只覆盖与竖屏短剧冲突的条目；未覆盖的（7 大漏洞、场景发动机、因果升级、知识揭示、节拍流）照常执行。

### 1. 台词：信息直给，潜台词降级为情绪载体

这是形态 B 与形态 A 最大的分歧，也是上一轮识别的头号冲突。裁决：

| 承载物 | 形态 A 电影化 | 形态 B 竖屏短剧 |
| --- | --- | --- |
| **事实与利害结论**（谁做了什么、钱多少、判几年、谁死谁活） | 可藏进潜台词，观众靠表演推断 | **必须同轮大白话直给**（1~2 句内挑明） |
| **情绪与关系**（不甘、试探、羞辱、护短） | 潜台词主力 | 仍可靠神态/反差动作/潜台词承载 |
| **专业术语/设定词** | 可保留，靠上下文 | **当句翻译成世俗后果**（多少钱/判几年/谁死谁活） |

- 漏洞 2④「潜台词纪律」在形态 B 中**只约束情绪层，不约束信息层**：把台词直白化后信息必须一致，但情绪仍需靠表演与措辞承载。
- **快慢变速**：每场对白交替使用 `3~6 字` 短促快刀句与 `8~16 字` 大白话算账句；全篇匀速 12~15 字长句=念经。
- 单气口上限仍为 25 字（漏洞 2④ / prompt-rules 的台词容量规则不变）。

### 2. 单集节奏：15 秒换挡四拍（标准/漫剧档）

| 挡位 | 必须完成的戏剧动作 | 硬指标 |
| --- | --- | --- |
| 第 1 挡 0~15s 抓人立事 | 强视觉开场 + 报出具体数字/死线/赌注 | 首个内容行是强视觉动作；前 5 句内出现具体数字或死线 |
| 第 2 挡 15~45s 正面交锋 | 反派加码施压 → 主角首轮反制 | 每 2~4 句对白插 1 条 `△` |
| 第 3 挡 45~85s 亮牌翻转 | 亮核心物证/底牌，完成**本集结算** | 必须有结果可视化 `△`；反派从嚣张变恐慌/失面 |
| 第 4 挡 85~110s 余波钩子 | 兑现战果 + 抛下一集更大危机 | 停在未完动作/突发来电/物证露一角，不喊口号总结 |

**防原地踏步**：同集内禁止「第 1 场吵某事，第 2 场换地方继续吵同一件事」；每 15~30 秒筹码、证据或站位必须肉眼可见地变一次。

**长档**：一集两拍（回合 A / 回合 B），≈90 秒处必设【本集中段小钩】（只抬价不爆点）；回合 B 施压与反驳各升一档，禁复读回合 A。

### 3. 集内结算（形态 B 的写后硬门）

每集必须给观众一个可见的「出一口气」：

- 主角有一次可见的**反将**；
- 反派为本次施压付出**可见代价**（当众失面/盘算落空/被架住进退两难）；
- 只堆受辱不给结算 = 直线受辱，情绪出口被堵死。

**信号闭环**：伏笔/异能/玄学信号必须给「信号 → 当场可验证 → 产生作用」三步；禁止拿观众看不懂的暗号判胜负。

### 4. 强画面支撑（可机检的密度下限）

- **每 2~4 句对白之间必须插 1 条实质性 `△` 动作行**；连续纯对白 >6 行即视为干聊断层（当前由人工复核，不进 K16 机检——数 `△` 行与对白行的机检阈值在不同体裁下误伤率高）。
- 每条 `△` 必须命中三大视觉锚点之一：①物理结果与视觉奇观；②身份反差与手头忙活；③物证亮牌与肢体对抗。做到「静音看 `△` 就能看懂谁占上风」。
- **无效微动作黑名单**（不许单独成行）：眼神微动 / 目光微闪 / 微微一怔 / 若有所思 / 嘴角微扬 / 叹了口气 / 把杯子推了半寸。要写就写生理可观测且有物理结果的动作。

### 5. 独白/旁白：配额制

| 档位 | 内心独白 | 旁白/字幕 |
| --- | --- | --- |
| 标准档 | ≤1 处 · 单处 ≤25 字 | ≤1 处 · ≤12 字 |
| 长档 | ≤2 处 · 单处 ≤30 字 | ≤1 处 · ≤12 字 |
| 漫剧档 | ≤1 处 · 单处 ≤20 字 | ≤1 处 · ≤12 字 |

- **前 3 秒禁用**（黄金 3 秒必须是场内冲突）；**断章禁用**（断章必须落在画面/事件上）；**禁连排**（两条独白之间必须隔动作或台词）。
- **标记口径**：形态 B 用中文标记 `内心独白：` / `旁白：`；vigen 既有的 `[VO]` 记法按**内心独白**口径计（更宽松，防误伤）。
- 独白只写「具体的账」（我给他生了五个孩子），不写抽象情绪（五味杂陈），不承担交代设定与前情。
- 机检：K16 检查配额、单处字数、连排、紧贴断章。

### 6. 每集末拍：断章公式

每集最后一个内容拍必须是断章，落在以下之一：

1. 身份掉马前一秒；
2. 物理危机绝命悬停；
3. 反差金句落地（5~11 字生活化短句优先）；
4. 生死/利益绝境二选一；
5. 情绪反差落地（治愈系/成年人情感专用，克制型切黑）。

**不用悬念问句断章**；断章不许抹掉本集应给的回报（先兑现再钩子）。机检：K16 要求【本集断章卡点】非空。

### 7. 形态 B 的 01 必备字段

```text
【本集结算】：主角可见反将 + 反派为本次施压付出的可见代价
【本集中段小钩】：长档必填；≈90 秒处的新信息/新威胁，只抬价不爆点
【本集断章卡点】：画面停格描述（黑屏：下滑立即解锁第N集）
```

### 8. 与形态 A 的分工一句话

**形态 A 让观众「品」，形态 B 让观众「不划走」。** 同一套 7 大漏洞仍然有效——只是形态 B 把「信息必须一秒听懂」提到了与「因果必须成立」同级。

## 二、剧本产出格式（阶段1a → GATE1.5 呈现物）

```
## 剧情梗概（3-5 句）

## 人物表（每人 3 行内）
- {角色名}：{身份/核心欲望/本段弧线（从X到Z）}
- **观众四问（焦点人物必答至少一条，且第一集就能被看见）** [drama-skills: story-craft.md#4]：①他正在承受什么不该由他承受的东西（不公要具体可见——被顶掉的署名、被改的排班、当众被拿走的东西；观众立场来自看见不公，不来自被告知他是好人）②他正在替谁扛（替自己扛=执拗，替一个具体的人扛才有牵引，那个人最好第一集出现过）③他想要的那样东西，观众自己是不是也想要（尊严、被认出来、护住一个人——能代入的欲望比"复仇"这类抽象目标更早生效）④他有什么本事是观众想借来用一次的（不必是金手指：看穿谎言、修好别人修不好的东西、难堪场合仍然体面——决定观众是**同情**他还是**想成为**他）
- 声音五维（漏洞 2 节⑤，先五维后口癖）：{注意什么/怎样证明/怎样控制距离/怎样隐藏/压力下怎样变形}；台词指纹（口头禅/语气词/称呼）只是最后一层微调
- {反派另加}三问答案：要什么/为何自认正确/手段为何聪明

## 分场剧本（按场）
### 第{N}场 · {场景} · {日/夜} · {时长估算}
{场景状态一句：空间/时间/在场人物/接续上一场的状态}
{动作与对白交织的剧本体——对白独立成行标注说话人；关键潜台词用（）标注内心真实意图；
道具互动写进动作行；情绪弧线节点标注}

## 7 大漏洞自检结果（操作程序 + 证据引用——禁止只填"通过"打勾）

> **填法纪律** [drama-skills: script-craft.md#9/12, dialogue-craft.md#10]：每条自检结果栏必须**引用证据**（哪一场哪一句，格式 `场N:「原文」`），并写清执行了哪个**操作程序**（做某个动作看结果，不是回答主观问句）。"通过"两个字不是自检结果。

| 漏洞 | 操作程序（做动作看结果） | 结果（证据引用） |
| --- | --- | --- |
| 1 小说化 | **圈出全部心理词，逐个指定载体**（行为选择/证据反应/空间动作/关系动作/有意标记的声音五类之一）；指定不了的删或改写 | {场N 心理词 X 处→载体清单；如 场3:「他很心虚」→「他把盖章页翻过去只递出没签名的一面」} |
| 2 台词书面化 | **删掉角色名朗读全段**，能否凭策略和措辞辨认谁在说；**每句台词旁标注行动动词**（逼问/遮掩/交换/试探/推责/保护…），标不出且不承担必要信息的句子删掉或改成动作 | {删名朗读可辨/不可辨+不可辨处；行动动词标注覆盖率} |
| 3 桥段同质化 | 逐情节对照黑名单；每个关键冲突答"最俗演法是什么→我反着来了吗"；**误会过四判据**（有理由不解释/观众位置选定/必须产生行动/解除有残余）；**反转过一句话测试**（因为<已建立事实>，原计划<为何不成立>，只能在<A/B>间行动） | {命中桥段清单+处置；四判据与一句话测试的答案} |
| 4 记忆衰减 | 对照 02 锚定表逐项核对设定（发色/伤位/道具状态/称呼）；系列对照 00_剧情状态 | {矛盾清单+已改处，引场号} |
| 5 反派降智 | 把反派当他自己故事的主角走一遍行动线；对手每场反对**指出用的是七式中哪一式**（只会说"不"或沉默离场=不合格） | {反派行动线成立性+各场反对方式} |
| 6 张力消解 | 高潮是否由**行动**解决（不是谈话/理性让步）；冲突场景过转向测试（转向前准备做什么→转向后为什么不能照做——答案只是"更生气"=缺新事实/筹码/关系/决定） | {高潮解决方式+转向测试答案，引场号} |
| 7 道具互动缺失 | 每场文戏数道具互动 ≥2 处；**场景必要性三问**：删掉这场损失哪项选择/证据/关系变化？答不出→处置三选一（合并/让变化真正发生/删去移入冲突） | {各场道具互动数+必要性答案} |
| 8 钩子纪律（分集/分段叙事时） | 前 3 拍有运动中具象事件？末拍是悬念不是情绪总结？上集悬念接住未解开？ | {逐项+引拍号} |
| 9 知识揭示+单一瞬间 | 对照知识揭示状态表查泄漏；逐镜头查两个时刻是否叠进一帧 | {泄漏处/堆叠处清单} |
| 10 三层分离（改编/细化用户素材时） | Source Facts/Interpretations/Visual Proposals 分栏登记；歧义项进待决问题不脑补 | {三栏行数+歧义项数} |
| **11 拖沓检查（新增）** | **快扫一遍全剧本**（用比正常更快的速度扫），记下**需要停下来才想明白的位置**=信息挤在一起；**相邻冲突连读**：只能用"然后"连接（而不是"所以/但是"）→ 答不出升级六问任何一条即合并或重写；扫完自问：情绪上有没有起伏，还是只知道发生了一串事？ | {停顿点清单+相邻节拍"然后/所以/但是"标注+六问答案} |

> **修订遍程序**（自检不止一遍时，**每一遍只解决一种失败**，不混着改）：①因果遍（每个动作旁写"因何发生/改变什么/下一动作为何被迫发生"）②可表演遍（每句台词能转成演员可演的动作或表达）③具体性遍（"资料"究竟是登记页、录音还是钥匙卡？）④声音与潜台词遍（删名朗读+行动动词标注）⑤经济性遍（删四类冗余：复述画面的台词/重复已知信息/无变化的场/只填氛围的段落）⑥扫读遍（即第 11 条）。

## 待用户定稿的问题（如有）
- {模糊点/多种走向的选择/尺度确认}
```

## 三、GATE1.5 剧本确认（硬停点）

1. 聊天中呈现：剧情梗概 + 人物表 + 分场剧本全文 + 7 大漏洞自检结果 + 待决问题
2. **明确告知用户**："剧本确认后进入分镜与锚定（GATE1）；此后改剧本 = 下游全部重做，现在是修改成本最低的时刻"
3. 用户不满意 → 按意见修订剧本，再次呈现，**循环直到用户明确说"剧本定了"**——未定稿绝不进入阶段1b（分镜）
4. 用户自带完整剧本时：GATE1.5 简化为"7 大漏洞自检 + 问题清单"呈现（剧本正文不复述），用户确认或提出修改后进入 1b——**自检环节不可跳过**（用户剧本也可能有漏洞 4/5/7，发现了要提醒用户而不是默默改）
5. 定稿结论写入 01"GATE1.5 剧本定稿记录"节（定稿版本要点 + 用户修改意见 + 定稿时间）

## 四、故事板预拆分规则（剧本→分镜的桥，防"一锅粥"）

剧本定稿后、写分镜表之前，先做故事板级拆分（不产出独立文件，直接在脑中/草稿完成后写入 01 分镜表）：

- **一个镜头只回答一个问题**——"少年推门进屋，看到信，震惊抬头，镜头推进，外面打雷，母亲冲进来，父亲倒地"是七件事=至少 4-5 个镜头
- **四格拆分法**：复杂动作段落按 ①空间（谁在哪里）②动作（谁做了什么）③情绪（谁震惊/害怕/愤怒）④结果（观众要看到的关键信息）拆格，每格对应一个镜头或镜头内一个节拍
- **切分节奏**：约 15 秒一个叙事单元切分镜；**每 20-30 个分镜为一批**产出并检查，不要一口气排几百个分镜（长输出会吞镜头——排到后面忘了前面）
- **先检查开头一批再往下**：每批分镜先查前 20 个——开头有没有冲突钩子/关键动作有没有被吞（"冲进婚礼现场"不能变成"站在台上说话"）/台词在镜头时长内说不说得完/人物是否在正确场景——开头立不住，后面全白做
