# 武打动作引擎（打斗/动作戏专用）

> **何时读**：项目含打斗、追逐、近身搏斗、兵器交战、异能法术对抗等动作戏。本文件把"人物+武器+场景+战斗目的+时长"转化为**武器使用正确、攻防连续、身体力学成立、空间清晰、可直接生成**的战斗镜头。
> 源：用户提供的导演级武打动作引擎资料（other1.md，2026-10-24）+ 30s 雨夜皇宫屋顶打斗成品提示词。
> 与骨架 A 的关系：本文件负责**动作内容的正确性**（力学/攻防/空间），产出后仍装进骨架 A 的时间码镜头块；Camera 与 Action 分离原则写进 CAMERA / EDITING 节与镜头块。

## 核心链路（每段打斗必须走完）

```
交手账（整场回合化+点名胜负手）→ Combat State → Attack Mechanics → Intent → Camera → Start State → Attack → Defense → Counter → Impact → Reposition → Recovery → End State
```

**优先级（冲突时从高到低裁决）**：
剧情事实 > 武器力学 > 攻防因果 > 空间连续 > 人物打法 > 可生成性 > 镜头效果

**不得为了炫技破坏武器结构、距离、重心或动作逻辑。**

## 0｜整场编排（交手账——动手拆镜前先回合化）

[drama-skills: fight-craft.md#1]

剧本只写"两人打斗"时，**禁止直接进分镜**——先把整场打斗写成交手账：每回合三格。

| 回合 | 发起（谁/哪只手或脚/拿什么/从哪一侧来——按场景站位锚点写，不写画左画右） | 应对（闪/挡/接/反制/被打中） | 结果改变（距离/朝向/武器控制/伤/体力/下一回合谁先手） |
| --- | --- | --- | --- |
| R1 | {…} | {…} | {…} |

**硬约束**：

- 每个回合至少改变一项结果。连续两回合结果都没变，观众读到的就是重复；回到剧本找这一回合真正改变了什么，找不到就合并或删掉
- 台词、对视和喘息是回合之间的换气点，它们让下一回合重新开始，不要让它们打断一个回合的中间
- **胜负手 = 结果改变最大的那一拍**——交手账写完后点名（标 ★），它是本段慢动作的唯一合法落点（判据与配额见 cinematography.md「峰值与强调手段」节）

**与 Combat Setup 的关系**：Setup 锁单镜初始状态，交手账排整场回合串；交手账每回合 = 第 3 节状态机七段块的装填素材（没有回合，七段模板没有素材可装——"激烈对打"式泛写就是缺这一层）。

**落盘**：交手账写入 01_方案与剧本.md「打斗交手账」小节（模板见 assets/templates.md），R 编号一经分配不重排（同稳定镜号规则）。

## 1｜Combat Setup（开打前先锁定）

双方能力｜体型｜武器｜战斗目的｜初始位置｜距离｜朝向｜障碍｜伤势｜体力｜优势方｜总时长

- 全程持续维护：位置、距离、高度、朝向、武器所在手、攻守关系、伤势
- **上一段 End State 默认成为下一段 Start State**（与骨架 A 尾帧续接机制同构——打斗戏的 CONTINUITY RULE 就写这些状态的延续）

## 2｜Attack Mechanics（动作由武器决定——武器功能错配=最大崩坏源）

| 武器 | 合法动作 | 禁止 |
| --- | --- | --- |
| 枪矛 | 刺、戳、点、挑、拨、架、压、扫杆 | **禁止长期当刀劈砍** |
| 刀 | 劈、砍、斩、削、撩、格、拖切 | — |
| 剑 | 刺、削、点、撩、格、压剑 | — |
| 棍 | 扫、砸、戳、挑、架、拨 | — |
| 锤 | 砸、抡、撞、压 | **重击后必须恢复**（不能连续无恢复抡砸） |
| 匕首 | 刺、割、挑、贴身控制 | — |
| 软兵器（鞭/链/绸） | 甩、抽、缠、套、拉 | **必须体现惯性与回收**（无惯性转向=崩坏） |
| 拳脚肘膝 | 直拳/勾拳/摆拳/侧踢/横扫/正蹬/肘击/膝撞/格挡卸力/翻滚闪避 | **必须符合距离、支撑脚、腰胯发力、重心变化**（腿法无支撑脚=崩坏） |

**距离-武器匹配**：远距离优先长枪/投射；中距离刀剑棍拳腿；近距离短刀/拳肘膝与控制。

**投掷物数量守恒**：扔出去的飞刀/箭矢数量前后一致，不凭空增减。

## 3｜Combat State Machine（每段统一结构——禁止孤立招式堆叠）

```
Start State → Intent → Attack → Opponent Response → Gap → Counter → Reposition → Recovery → End State
```

**每个动作必须有战术目的**：抢距离 / 封路线 / 逼退 / 制造空档 / 脱离 / 试探 / 卖破绽。写镜头块时在表演注位置写明该动作的 Intent（"这一剑是逼他退到栏杆边，不是要杀他"）——模型理解了目的，动作才有攻防逻辑而不是广播体操。

## 4｜Spatial & Distance（空间连续）

- **首次交战必须建立**：双方位置、朝向、距离、**动作轴线**、摄影机区域、环境障碍
- 所有换位**必须拍出过程**——禁止瞬移、突然换手、状态重置
- 轴线纪律：正反打与越轴按 180 度规则；越轴必须有过渡镜头（跟拍绕行/插入中性镜头）
- 环境障碍是资产不是障碍：桌椅/栏杆/立柱/屋顶高低差要被打斗**用到**（踏瓦、借力、被逼至死角）

**多对手围攻的方位纪律** [drama-skills: fight-craft.md#4, blocking-playbooks.md#SHT-14]：

- 围攻在场景站位里给每个对手记一个相对主角的**固定方位**（"靠灯一侧""主角身后靠集装箱一侧"），所有镜头都按这个方位写；画外对手入画从记录的那一侧进来
- **每个回合只有一个对手在出手**，其余对手停在看得见的等待位置——观众读得清，每镜也只有一次接触
- 主角转身迎向另一个对手时**轴线跟着换了**：先用一个全景或中全景重新交代谁在哪，再进入下一回合，不在两个近景之间直接跳到新轴线上
- **慢动作、特写、群众反应或解说不能替代丢失的空间阶段**；对手战术调整应能追溯到此前看见的信息，避免每轮都重置成同一站位
- 与 §8"多人混战拆 1v1 焦点"的关系：本条是**编排层**（谁在哪、谁出手、换轴重建），§8 拆 1v1 是**生成端降级实现**（同框人数多到糊时的兜底）——先按方位纪律排，排不动再降级

## 5｜Impact & Recovery（命中反馈分型 + 打击呈现）

| 武器类型 | 命中反馈写法 |
| --- | --- |
| 刀剑 | 看刃线与避让（刃口相撞火花、贴脊摩擦、削断雨线） |
| 枪矛 | 看枪尖路径与偏转 |
| 棍锤 | 看惯性与身体位移（被砸者整个人位移，不是原地晃一下） |
| 拳脚 | 看头躯偏转、支撑脚与失衡 |
| 软兵器 | 看缠绕、拉扯、回弹 |

**攻击后必须出现恢复动作**：回收｜落地｜换脚｜回架｜恢复重心｜重新建立距离——没有 Recovery 的 Attack = 摆 pose = 崩坏。

### 打击呈现（把"打中了"卖给观众——分型是反馈内容，本节是呈现镜头语言）[drama-skills: fight-craft.md#3]

先分清这一下是什么。**落空、格挡、闪避、武器砸在环境上**——观众要看的是路线和空隙：用稳定的侧面或斜侧中景，让出手、让开和结果都在一个画框里看清。**武器落空砸在环境上（火星、水花、凹痕）比砸在人身上更好生成，也更能说明力道。**

真正打到脸或身体的那一下，两个运动中的身体在接触点上最难读清、最易生成走样。让观众相信打中了，靠下面三件事，而不是把拳头贴在脸上那一格拍清楚：

1. **连续镜头里遮住接触点**：两人全身都在画面里时，摄影机在**轴线同一侧**换到出手者肩后或斜后方，让拳脚路线朝向或背离镜头经过，接触点被前景的手臂或肩膀挡住。（为遮挡越到轴线另一侧反打=观众丢失方位，不值得）
2. **多镜覆盖里给打击特写**：只有承受者的脸或身体在画面里，拳脚从**画外闯入**、砸中，脸顺着来力甩开。画面里只有一个运动的身体，接触点可以露出来——这是"拳拳到肉"的来源，前提是剪辑把它剪短
3. **承受者的反应**：头顺着来力方向甩开，身体跟着走，脚下退步或失衡，手捂住被打的位置。**反应的方向必须和来力一致**
4. **声音和余波**：一声闷响、溅起的水、撞歪的物件，承受者退到哪里停住

**贴身缠斗单控制**：抱摔、缠斗这类贴身动作，一镜只写一个控制——谁的哪只手臂箍住谁的哪里，然后是挣脱或放倒。写开始控制和松开的两个状态，中间的角力用声音和一次发力带过，不写多步的手部换位。

**接触镜难生成时**（打到人身上/贴身控制）：走可生成性改写阶梯（prompt-rules.md 0.7——轴线同侧遮接触点、画外闯入打击特写本身就是可生成改写），**不做预先降级实现**；只有真实生成失败后才走 SKILL.md 回退阶梯（裁定 R3）。

## 6｜Camera（与 Action 分离）

Camera 描述至少包含：**景别｜机位｜运镜｜方向｜速度｜跟焦主体**（六要素齐）。

### 回合拆镜决策序（交手账回合 → 镜头，按序三选一）[drama-skills: fight-craft.md#2 / SHT-31]

一个回合在银幕上通常只有一两秒，而目标模型最短原生时长往往更长（H3/happyhorse 最短 3-4s）。一拍一镜、每镜停住等剪，整场会被拖慢。**生成端真相：镜头给多长，模型就把这几下拉多长，回合中间会出现停顿；正文里写「快」「一气呵成」或逐秒时间，都不能把动作压回真实速度。**按顺序选：

1. **多镜容器（打戏默认）**：一个回合在一次生成里切成「**起手的中景 → 打击的特写 → 余波的中景**」，各拍仍各自成镜。剪辑在生成出来的切点处紧剪，打击特写只留拳到前后的一小段，起手和余波也只留读得懂的部分——这是打戏读得出力道的主要做法
2. **整回合一镜**：发起、应对、结果作为本镜"唯一动作"连续完成，摄影机在一个稳定位置看完整条路线。仅当最短时长装得下一个完整回合时用；镜长取装得下这个回合的最短一档
3. **单独成镜**：只有**缴械、决定性一击或改变下一步选择的反应**才单独成镜。打中之后的连带结果（武器松脱、滚走）写进同一镜时常被略过——结果要紧就单独成镜，或作为下一镜的起点状态

### 打斗景别功能阶梯 [drama-skills: fight-craft.md#5]

- 每个新阶段的第一镜用**全景或中全景**交代距离：谁离谁几步、武器在谁手里、身后有什么
- 交手用**中景或双人中全景，能看到两个人的脚——距离靠脚下读出来**
- **近景和特写只给信息**：握紧的武器、脱手的落点、决定性一击之后的脸
- 9:16 竖屏横向窄，横扫、侧踢容易出画——把交手的方向摆成**朝向或背离镜头的纵深，或者斜线**；高举的武器和高位腿法需要纵向留白

### 打斗接触专条（写成执行端做得出的正文）[drama-skills: generability.md#7 VID-28]

打斗是精确拦截与多主体接触最集中的地方。分镜已决定回合、机位和哪一下单独成镜，本节只管把回合写成可生成的正文：

- **一段一个出手者**（每时段只有一个主体在出手）：`0–1.5 秒 他抡起木棍朝对方头顶劈下；1.5–3 秒 对方上身朝自己右侧一偏，木棍擦着左肩落空`。两个人在同一时段同时发力=精确拦截（prompt-rules 0.7），先后动作的咬合写不出来，交给剪辑在动作中途切换
- **左右按人物自己的身体说**：`他的右拳`、`她的左肩`；方向按场景锚点说（"朝集装箱一侧"）。**画左画右在机位一换就会反**
- **写路线和反应，不写接触点形变**：`右拳从镜头前方朝他下巴方向挥过，他的头猛地朝左甩开，踉跄后退两步`，**不写** `拳头打在脸上`、`脸被打得变形`。打击由承受者的反应、环境结果和声音读出（见 §5 打击呈现）
- **贴身控制写两个状态**：谁的哪只手臂箍住谁的哪里，然后是松开或放倒；中间不写多步换手
- **变速另作决定**：生成里默认写正常速度；慢动作只给决定性的那一下（交手账 ★ 胜负手），并写明慢放从哪一刻开始、到哪一刻结束；其余变速留给剪辑
- **伤与血按强度档**：照创作者选择的强度档和目标平台内容政策写结果，不自行加码

自动选择逻辑：
- **One Take（一镜到底）**：空间换位、兵器轨迹、环境互动——需要观众看清空间关系时
- **Rapid Cut（快切）**：近身爆发、打击反馈、高密度交换——1-2s/镜
- **切镜只能依附真实动作节点**（出手瞬间/命中瞬间/换位完成）——不在动作中间无理由切

**成品案例的镜头语言**（30s 雨夜屋顶打斗，21 个镜头块）：低机位极速前推贴瓦面 → 中景持续跟焦纵跃 → 微距特写刀刃擦肩 → 环绕机位腾空旋斩 → 侧面环绕半圈甩摇兵刃火花 → 极低仰拍急推踏瓦飞奔 → 侧后方跟拍追击 → 垂直仰摇跃向高阁 → 超高速平移跟拍兵刃交击 → 正面锁定碰撞点 → 越肩推进错身甩摇 → 正面追尾冲刺残影 → 远景缓慢后拉收束对峙。可复用模式：**开场贴地细节抓人 → 中段跟焦+环绕+甩摇交替 → 碰撞点正面特写 → 收尾远景拉开留余韵**。

## 7｜输出格式：状态机 → 骨架 A 镜头块（装填模板，照抄结构）

**打斗镜头块不写"动作三段式（从/过程/至）"，改写状态机七段**——七段本身就是三段式的扩展版（Start State=起始、Attack→Impact=过程、End State=终点），不要两套都写（重复=干扰）。**一行式装填**（每段用 → 连接，写成一个连贯段落，不分条列举）：

```
{时间区间}｜镜头{N}｜{标题}
{Camera 六要素：景别｜机位｜运镜｜方向｜速度｜跟焦主体}。
{Start State：起手姿态+距离+朝向} → {Intent：这一招的战术目的，双方各一个} →
{Attack：攻方动作+武器合法动作标注+力学（支撑脚/腰胯发力/重心）} →
{Response：守方应对+合法动作} → {Impact：按武器分型的命中反馈} →
{Recovery：双方各自的恢复（回收/落地/换脚/回架/重新建立距离）} →
{End State：本镜最后一帧的确定画面}。
{台词（如有）：角色名（发声方式描述）："台词"}
表演：{不是X，而是Y。核心是Z}。
```

**范例（成品级，可直接对照）**：

```
6.0s–8.5s｜镜头4｜第一招·交刃
中景｜侧面机位垂直于两人连线｜手持轻微晃动｜水平｜中速｜跟焦两人刃口接触点。85mm。
Start State（两人相距五步静止对峙，她剑尖垂、他按刀）→ Intent（玄鸦：抢距离+试探她的根基；
沈青绡：封正面路线护住中线，把刀势斜着引进空处卸力，这一格不是硬接）→
Attack（玄鸦右脚前跨弓步、双手握刀全力下劈——刀的合法动作：劈）→
Response（沈青绡不退反侧身半马步、双手合握剑向左上方斜架格挡——剑的合法动作：格）→
Impact（刀剑分型看刃线与避让：两刃呈十字相抵迸火星，雨水触刃汽化腾起极细白汽，
刀锋压着剑脊下滑半寸，剑身微弯蓄弹力）→
Recovery（玄鸦劈势用老、双臂沿刀身回弹半寸重新收拢握紧回架；沈青绡吃住刀势后
肩胛下沉半寸、马步重新压实——双方各自回稳，无人僵直定格）→
End State（两刃锁死十字相抵、火星迸起、两人相距一臂半）。
表演：不是杂耍比划，是两件真兵器第一次咬合。核心是双方都在称量对方的力量。
```

> 非打斗镜头（对白/反应/空镜）仍用 prompt-rules.md 骨架 A 的动作三段式——两套结构的分工：**打斗镜头块=状态机七段，非打斗镜头块=动作三段式**。同一段落内可混用。

段落级补充节：
- **HARD LOCK**（写进 NO 节）：禁止武器功能错配、枪矛长期挥砍、软兵器无惯性转向、拳脚无重心发力、腿法无支撑脚、投掷物数量变化、重武器连续无恢复、人物瞬移、孤立招式堆叠、无过程换手换位
- **物理与质感**（写进 FORMAT/LIGHTING）：雨滴冲击、瓦片崩飞、金属火花、尘土飞溅、衣摆滞后、强动态模糊、仅终结一击短暂定格，**禁止长定格、禁止摆 pose、禁止长时间凌空飞行**。速度处理：默认正常速度（生成端真相：镜头给多长，模型就把动作拉多长——写"快"压不回真实速度，高危动作降速优先用"拆更短镜头+切点紧剪"实现，不用整段升格）。慢动作是强调手段，只花在已点名峰值上——判据与配额见 cinematography.md「峰值与强调手段」节（唯一的家）[drama-skills: fight-craft.md#2]
- **尺度锚定**：巨大生物/机甲戏写明体型数字与参照物对比（"巨兽约300米，废弃工程机械在其脚下如玩具"）——尺度靠参照物锚定不靠形容词

## 8｜高风险动作的生成端处理（主方案优先——回退列仅在生成失败后使用）

> 主方案就是表现力方案，生成难度是走可生成性改写阶梯的触发器（prompt-rules.md 0.7），不是回避表现力的理由；"生成失败后的回退写法"只在真实失败后启用（SKILL.md 回退阶梯），**不预先降级、不在 GATE1 让用户二选一**——强调手段的分配走 cinematography.md「峰值与强调手段」节。

| 高风险动作 | 主方案 | 生成失败后的回退写法 |
| --- | --- | --- |
| 腾空旋斩/飞檐 | 拆短镜（腾空段独立成镜 1-2s，落地段独立成镜），慢动作仅腾空顶点 0.3-0.5s 且须有峰值标注（←峰值：交手账R<N>，见 cinematography.md「峰值与强调手段」节） | 缩短腾空时间，落地即接下一动作 |
| 兵刃连续交击 | 1-2s 快切分镜逐个交击 | 单次交击特写+音效补密度 |
| 反先验动作（腿蹬弓类） | **必走关键帧锁定**：情景图先给出该姿势，视频只写后续运动（prompt-rules.md 0.2） | 改为常规先验动作+借先验概念（"像哪吒"） |
| 多人混战 | 拆成 1v1 焦点+背景虚化群像 | 减少同框人数，分镜轮切 |
| 长距离追逐 | 分 2-3 段尾帧续接 | 缩短单段距离 |

## 自检清单（打斗戏交付前）

- [ ] 每个动作有战术目的（Intent），无孤立招式堆叠
- [ ] 武器动作全部合法（无枪矛劈砍/软兵器无惯性/重锤无恢复）
- [ ] 拳脚有支撑脚、腰胯发力、重心变化描述
- [ ] 命中反馈按武器分型写出（刃线/枪尖/惯性位移/头躯偏转/缠绕回弹）
- [ ] 攻击后有 Recovery（回收/落地/换脚/回架/重新建立距离）
- [ ] 换位拍出过程，无瞬移/突然换手
- [ ] 上一段 End State = 下一段 Start State（伤势/体力/位置延续）
- [ ] Camera 六要素齐（景别/机位/运镜/方向/速度/跟焦主体）
- [ ] 切镜依附真实动作节点
- [ ] 投掷物数量守恒
- [ ] NO 节含 HARD LOCK 清单
- [ ] 反先验动作已走关键帧锁定
