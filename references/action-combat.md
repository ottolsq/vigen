# 武打动作引擎（打斗/动作戏专用）

> **何时读**：项目含打斗、追逐、近身搏斗、兵器交战、异能法术对抗等动作戏。本文件把"人物+武器+场景+战斗目的+时长"转化为**武器使用正确、攻防连续、身体力学成立、空间清晰、可直接生成**的战斗镜头。
> 源：用户提供的导演级武打动作引擎资料（other1.md，2026-10-24）+ 30s 雨夜皇宫屋顶打斗成品提示词。
> 与骨架 A 的关系：本文件负责**动作内容的正确性**（力学/攻防/空间），产出后仍装进骨架 A 的时间码镜头块；Camera 与 Action 分离原则写进 CAMERA / EDITING 节与镜头块。

## 核心链路（每段打斗必须走完）

```
Combat State → Attack Mechanics → Intent → Camera → Start State → Attack → Defense → Counter → Impact → Reposition → Recovery → End State
```

**优先级（冲突时从高到低裁决）**：
剧情事实 > 武器力学 > 攻防因果 > 空间连续 > 人物打法 > 可生成性 > 镜头效果

**不得为了炫技破坏武器结构、距离、重心或动作逻辑。**

## 1｜Combat Setup（开打前先锁定）

双方能力｜体型｜武器｜战斗目的｜初始位置｜距离｜朝向｜障碍｜伤势｜体力｜优势方｜总时长

- 全程持续维护：位置、距离、高度、朝向、武器所在手、攻守关系、伤势
- **上一段 End State 默认成为下一段 Start State**（与骨架 A 尾帧续接机制同构——打斗戏的 CONTINUITY RULE 就写这些状态的延续）

## 2｜Attack Mechanics（动作由武器决定——武器功能错配=最大崩坏源）

| 武器 | 合法动作 | 禁止 |
| --- | --- | --- |
| 枪矛 | 刺、戳、点、挑、拨、架、压、扫杆 | **禁止长期当刀劈砍** |
| 刀 | 劈、砍、斩、削、撩、格、拖切 | — |
| 剑 | 刺、削、点、撩、格、压剑 | — |
| 棍 | 扫、砸、戳、挑、架、拨 | — |
| 锤 | 砸、抡、撞、压 | **重击后必须恢复**（不能连续无恢复抡砸） |
| 匕首 | 刺、割、挑、贴身控制 | — |
| 软兵器（鞭/链/绸） | 甩、抽、缠、套、拉 | **必须体现惯性与回收**（无惯性转向=崩坏） |
| 拳脚肘膝 | 直拳/勾拳/摆拳/侧踢/横扫/正蹬/肘击/膝撞/格挡卸力/翻滚闪避 | **必须符合距离、支撑脚、腰胯发力、重心变化**（腿法无支撑脚=崩坏） |

**距离-武器匹配**：远距离优先长枪/投射；中距离刀剑棍拳腿；近距离短刀/拳肘膝与控制。

**投掷物数量守恒**：扔出去的飞刀/箭矢数量前后一致，不凭空增减。

## 3｜Combat State Machine（每段统一结构——禁止孤立招式堆叠）

```
Start State → Intent → Attack → Opponent Response → Gap → Counter → Reposition → Recovery → End State
```

**每个动作必须有战术目的**：抢距离 / 封路线 / 逼退 / 制造空档 / 脱离 / 试探 / 卖破绽。写镜头块时在表演注位置写明该动作的 Intent（"这一剑是逼他退到栏杆边，不是要杀他"）——模型理解了目的，动作才有攻防逻辑而不是广播体操。

## 4｜Spatial & Distance（空间连续）

- **首次交战必须建立**：双方位置、朝向、距离、**动作轴线**、摄影机区域、环境障碍
- 所有换位**必须拍出过程**——禁止瞬移、突然换手、状态重置
- 轴线纪律：正反打与越轴按 180 度规则；越轴必须有过渡镜头（跟拍绕行/插入中性镜头）
- 环境障碍是资产不是障碍：桌椅/栏杆/立柱/屋顶高低差要被打斗**用到**（踏瓦、借力、被逼至死角）

## 5｜Impact & Recovery（命中反馈按武器分型）

| 武器类型 | 命中反馈写法 |
| --- | --- |
| 刀剑 | 看刃线与避让（刃口相撞火花、贴脊摩擦、削断雨线） |
| 枪矛 | 看枪尖路径与偏转 |
| 棍锤 | 看惯性与身体位移（被砸者整个人位移，不是原地晃一下） |
| 拳脚 | 看头躯偏转、支撑脚与失衡 |
| 软兵器 | 看缠绕、拉扯、回弹 |

**攻击后必须出现恢复动作**：回收｜落地｜换脚｜回架｜恢复重心｜重新建立距离——没有 Recovery 的 Attack = 摆 pose = 崩坏。

## 6｜Camera（与 Action 分离）

Camera 描述至少包含：**景别｜机位｜运镜｜方向｜速度｜跟焦主体**（六要素齐）。

自动选择逻辑：
- **One Take（一镜到底）**：空间换位、兵器轨迹、环境互动——需要观众看清空间关系时
- **Rapid Cut（快切）**：近身爆发、打击反馈、高密度交换——1-2s/镜
- **切镜只能依附真实动作节点**（出手瞬间/命中瞬间/换位完成）——不在动作中间无理由切

**成品案例的镜头语言**（30s 雨夜屋顶打斗，21 个镜头块）：低机位极速前推贴瓦面 → 中景持续跟焦纵跃 → 微距特写刀刃擦肩 → 环绕机位腾空旋斩 → 侧面环绕半圈甩摇兵刃火花 → 极低仰拍急推踏瓦飞奔 → 侧后方跟拍追击 → 垂直仰摇跃向高阁 → 超高速平移跟拍兵刃交击 → 正面锁定碰撞点 → 越肩推进错身甩摇 → 正面追尾冲刺残影 → 远景缓慢后拉收束对峙。可复用模式：**开场贴地细节抓人 → 中段跟焦+环绕+甩摇交替 → 碰撞点正面特写 → 收尾远景拉开留余韵**。

## 7｜输出格式（装进骨架 A 的镜头块）

每段打斗镜头块：
```
{时间区间}｜镜头{N}｜{标题}
{Combat Setup 引用：机位/景别/FOV/跟焦主体}。
{Start State}→{Intent}→{Action（武器合法动作+力学：支撑脚/腰胯发力/重心）}→{Response}→{Impact（按武器分型反馈）}→{Recovery}→{End State}。
{Continuity：位置/距离/朝向/武器所在手/伤势延续}。
```

段落级补充节：
- **HARD LOCK**（写进 NO 节）：禁止武器功能错配、枪矛长期挥砍、软兵器无惯性转向、拳脚无重心发力、腿法无支撑脚、投掷物数量变化、重武器连续无恢复、人物瞬移、孤立招式堆叠、无过程换手换位
- **物理与质感**（写进 FORMAT/LIGHTING）：雨滴冲击、瓦片崩飞、金属火花、尘土飞溅、衣摆滞后、强动态模糊、Time Ramp 快慢结合（慢动作给模型更多帧——高危动作降速处理）、仅终结一击短暂定格，**禁止长定格、禁止摆 pose、禁止长时间凌空飞行**
- **尺度锚定**：巨大生物/机甲戏写明体型数字与参照物对比（"巨兽约300米，废弃工程机械在其脚下如玩具"）——尺度靠参照物锚定不靠形容词

## 8｜高风险动作的生成端处理（与双方案制联动）

| 高风险动作 | 主方案 | 保底方案 |
| --- | --- | --- |
| 腾空旋斩/飞檐 | 完整写法+慢动作（Time Ramp） | 缩短腾空时间，落地即接下一动作 |
| 兵刃连续交击 | 1-2s 快切分镜逐个交击 | 单次交击特写+音效补密度 |
| 反先验动作（腿蹬弓类） | **必走关键帧锁定**：情景图先给出该姿势，视频只写后续运动（prompt-rules.md 0.2） | 改为常规先验动作+借先验概念（"像哪吒"） |
| 多人混战 | 拆成 1v1 焦点+背景虚化群像 | 减少同框人数，分镜轮切 |
| 长距离追逐 | 分 2-3 段尾帧续接 | 缩短单段距离 |

## 自检清单（打斗戏交付前）

- [ ] 每个动作有战术目的（Intent），无孤立招式堆叠
- [ ] 武器动作全部合法（无枪矛劈砍/软兵器无惯性/重锤无恢复）
- [ ] 拳脚有支撑脚、腰胯发力、重心变化描述
- [ ] 命中反馈按武器分型写出（刃线/枪尖/惯性位移/头躯偏转/缠绕回弹）
- [ ] 攻击后有 Recovery（回收/落地/换脚/回架/重新建立距离）
- [ ] 换位拍出过程，无瞬移/突然换手
- [ ] 上一段 End State = 下一段 Start State（伤势/体力/位置延续）
- [ ] Camera 六要素齐（景别/机位/运镜/方向/速度/跟焦主体）
- [ ] 切镜依附真实动作节点
- [ ] 投掷物数量守恒
- [ ] NO 节含 HARD LOCK 清单
- [ ] 反先验动作已走关键帧锁定
