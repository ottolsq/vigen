## 核心链路（每段打斗必须走完）

```
交手账（整场回合化+点名胜负手）→ Combat State → Attack Mechanics → Intent → Camera → Start State → Attack → Defense → Counter → Impact → Reposition → Recovery → End State
```

**优先级（冲突时从高到低裁决）**：
剧情事实 > 武器力学 > 攻防因果 > 空间连续 > 人物打法 > 可生成性 > 镜头效果

**不得为了炫技破坏武器结构、距离、重心或动作逻辑。**

## 0｜整场编排（交手账——动手拆镜前先回合化）

[drama-skills: fight-craft.md#1]

剧本只写"两人打斗"时，**禁止直接进分镜**——先把整场打斗写成交手账：每回合三格。

| 回合 | 发起（谁/哪只手或脚/拿什么/从哪一侧来——按场景站位锚点写，不写画左画右） | 应对（闪/挡/接/反制/被打中） | 结果改变（距离/朝向/武器控制/伤/体力/下一回合谁先手） |
| --- | --- | --- | --- |
| R1 | {…} | {…} | {…} |

**硬约束**：

- 每个回合至少改变一项结果。连续两回合结果都没变，观众读到的就是重复；回到剧本找这一回合真正改变了什么，找不到就合并或删掉
- 台词、对视和喘息是回合之间的换气点，它们让下一回合重新开始，不要让它们打断一个回合的中间
- **胜负手 = 结果改变最大的那一拍**——交手账写完后点名（标 ★），它是本段慢动作的唯一合法落点（判据与配额见 cinematography.md「峰值与强调手段」节）

**回合升级三线（越打越凶——只写"更激烈"等于没写）** `[社区方法论]`：

| 线 | 递进写法 | 观众读到的信号 |
| --- | --- | --- |
| 速度线 | 中速 → 快 → 极速 → 慢 → 爆发 | 前段速度爬坡，后段力道接管；速度先到顶，力道再炸开 |
| 力道线 | 挡得住 → 挡不住 → 被击飞 | 观众看不懂速度数字，但看得懂格挡结果的变化 |
| 攻击方式线 | 冲拳/摆拳 → 推掌/劈掌 → 横肘/砸肘 → 标指/关节技 | 越往后越凶、越致命，不是单纯越打越快 |
| 命中部位线 | 躯干/手臂 → 肋骨/腹部 → 太阳穴/下巴 → 喉咙/关节 | 越往后观众越紧张 |
| 环境反馈线 | 擦痕 → 裂纹 → 碎石 → 碎裂塌陷 → 深坑 | 环境损伤必须累积，不能下一镜恢复原状 |

> 交手账每回合的「结果改变」列至少落一条升级线；连续两回合同一线不升级=重复。

**整场结构按类型选骨架** `[社区方法论]`：

| 类型 | 五步骨架 |
| --- | --- |
| 双人攻防 | 不同优势距离 → 一方逼对方离开舒适距离 → 地形/武器/假动作翻盘 → 第二轮换位换轴 → 明确谁获得空间/时间/行动优势 |
| 一人对多人 | 全景交代每人位置 → 不同方向与节奏进攻 → 借一个对手的位移挡住另一个 → 已退出者保留在画面 → 结尾明确剩余人数与主角去向 |
| 远程能量 | 展示双方释放条件 → 第一轮改变场景或迫使移动 → 折射/吸收/偏转/切断来源反制 → 改变路径或释放位置 → 结果落在可见目标或无人环境 |
| 人兽对决 | 体型比例与安全距离 → 巨兽一次大范围动作改变地形 → 主角从侧翼/高度/弱点取得机会 → 巨兽调整攻击方式反转 → 结果落在倒塌/退让/脱离 |
| 单人突围/演武 | 建立路线/出口/当前状态 → 第一种威胁改变步法或高度 → 第二种威胁封路、主角用环境开新通道 → 最后障碍检验前面建立的能力 → 抵达/脱离/收势在稳定可读位置 |
| 风格化材质 | 定义材质/关节/镜头限制 → 全体角色与特效同一媒介逻辑 → 每次接触产生符合材料的反馈 → 镜头不破坏平面/舞台规则 → 收尾保留线头/折痕/碎屑 |

**时长分档** `[社区方法论]`：4-8s 一个完整动作闭环（最多一次明显转折）；9-18s 起动/争夺/反制/结果 4-5 个阶段；19-30s 拆 5-7 段并在中段安排一次有效反转。段长先按本档拆，再按目标模型上限取整。

**参考素材职责单一**：动作参考视频只继承身体轨迹/节奏/发力方式；运镜参考视频只继承机位/路径/速度；身份/场景/服装各自挂在独立素材上。一份素材不同时控制身份、场景、动作和镜头（用途声明写法见 prompt-rules 骨架 A）。

**打戏不用空镜打断动作** `[社区方法论]`：动作段只在回合之间用 ≤0.5s 的环境声/对手反应换气；不得用空镜替代丢失的空间阶段或动作结果；血腥结果的安全降级按 content-safety，不自行加码。

**与 Combat Setup 的关系**：Setup 锁单镜初始状态，交手账排整场回合串；交手账每回合 = 第 3 节状态机七段块的装填素材（没有回合，七段模板没有素材可装——"激烈对打"式泛写就是缺这一层）。

**落盘**：交手账写入 01_方案与剧本.md「打斗交手账」小节（模板见 assets/templates.md），R 编号一经分配不重排（同稳定镜号规则）。

## 1｜Combat Setup（开打前先锁定）

双方能力｜体型｜武器｜战斗目的｜初始位置｜距离｜朝向｜障碍｜伤势｜体力｜优势方｜总时长

- 全程持续维护：位置、距离、高度、朝向、武器所在手、攻守关系、伤势
- **上一段 End State 默认成为下一段 Start State**（与骨架 A 尾帧续接机制同构——打斗戏的 CONTINUITY RULE 就写这些状态的延续）

**角色动作档案（8 项，开打前逐人填）** `[社区方法论]`：①优势距离 ②起手姿态 ③移动方式 ④主要攻击方式 ⑤防守与反制习惯 ⑥武器/弹药/能量资源 ⑦力量节奏（顿挫型/圆活型，见 §9）⑧结束战斗的方式。不同角色至少在前三项拉开差异；体型差异反映在速度、受力与环境反馈上，不能只换皮。

**伤损累积账（打斗段逐镜维护）** `[成品样例]`：每角色记「起始伤损 → 本镜新增 → 当前状态」；伤损只累积/维持，不能下一镜恢复；伤损影响动作速度、格挡力度、呼吸与站姿。示例：A 从灵纹明灭→单膝跪地→嘴角溢血；B 从重甲无痕→裂痕→胸甲碎裂。与 01 交手账「结果改变」列、04 七段 End State 并用。

## 2｜Attack Mechanics（动作由武器决定——武器功能错配=最大崩坏源）

| 武器 | 合法动作 | 禁止 |
| --- | --- | --- |
| 枪矛 | 刺、戳、点、挑、拨、架、压、扫杆 | **禁止长期当刀劈砍** |
| 刀 | 劈、砍、斩、削、撩、格、拖切 | — |
| 剑 | 刺、削、点、撩、格、压剑 | — |
| 棍 | 扫、砸、戳、挑、架、拨 | — |
| 锤 | 砸、抡、撞、压 | **重击后必须恢复**（不能连续无恢复抡砸） |
| 匕首 | 刺、割、挑、贴身控制 | — |
| 软兵器（鞭/链/绸） | 甩、抽、缠、套、拉 | **必须体现惯性与回收**（无惯性转向=崩坏） |
| 拳脚肘膝 | 直拳/勾拳/摆拳/侧踢/横扫/正蹬/肘击/膝撞/格挡卸力/翻滚闪避 | **必须符合距离、支撑脚、腰胯发力、重心变化**（腿法无支撑脚=崩坏） |

**距离-武器匹配**：远距离优先长枪/投射；中距离刀剑棍拳腿；近距离短刀/拳肘膝与控制。

**投掷物数量守恒**：扔出去的飞刀/箭矢数量前后一致，不凭空增减。

## 3｜Combat State Machine（每段统一结构——禁止孤立招式堆叠）

```
Start State → Intent → Attack → Opponent Response → Gap → Counter → Reposition → Recovery → End State
```

**每个动作必须有战术目的**：抢距离 / 封路线 / 逼退 / 制造空档 / 脱离 / 试探 / 卖破绽。写镜头块时在表演注位置写明该动作的 Intent（"这一剑是逼他退到栏杆边，不是要杀他"）——模型理解了目的，动作才有攻防逻辑而不是广播体操。

**写法总则：写物理受力，不写动作形容词** `[社区方法论]`：AI 对"高速出拳/激烈战斗/非常厉害"这类词只会加忙乱；有效写法是把动作写成身体状态与受力链——被压制/步伐凌乱/重心不稳 → 蹬地/转腰/送肩 → 接触/被挡/落空 → 受击位移/失衡/喘息。先写"怎么被压制、怎么发力"，再写"打了什么"。

**动作指令 vs 物理指令（同一拍的两种写法）**：
- ✗ 动作指令：`主角快速冲向敌人，连续出拳，非常厉害。`
- ✓ 物理指令：`主角被对手持续压制，步伐凌乱，重心不稳；被逼退的瞬间双腿猛蹬地面，强行反击，拳头带着整个身体的重量向前冲刺。`

### 3.5｜防守三态（Response 不能瞬移回完整防守）

[社区方法论: 武戏Skill / seedance-combat-prompt 防守三态]

防守不是"格挡/没格挡"二元。每次被压制都要走完三态：

```
完整态（姿势到位、重心稳、正式格挡）
  → 崩防线（格挡被破开，双臂被弹开、胸腹暴露，0.3-0.5s 空窗）
  → 过渡态（来不及重建完整格挡，只能本能闪/后仰/单臂拍/撤步/缩身，姿势狼狈、重心不稳）
  → 恢复（轻击 0.3-0.5s；重击 0.5-1s；终结技级不恢复，直接被命中）
```

**硬约束**：破防后的下一句不能又写"双臂格挡"——必须先写过渡态的零碎防守；否则观众看到的是"被破防这事没发生过"。

**不同攻击 → 不同格挡 → 姿势衔接反击** `[社区方法论]`：

| 攻击类型 | 格挡方式 | 格挡后的姿势 = 下一击起势 |
| --- | --- | --- |
| 直线中段（刺拳/直拳） | 掌拨偏转，侧身，后手护胸 | 拨开时身体已转至侧面 → 拨→转→踢 |
| 弧线横扫（摆拳/鞭腿） | 双臂交叉封死，重心微沉 | 弹开方向=出腿起势 → 弹开→腿起 |
| 近身重击（横肘/砸肘） | 双臂上托+后撤半步，身体后倾卸力 | 托+退，不原地硬扛 → 退后推掌/标指 |
| 精准刺击（标指/插指） | 侧身闪避+掌拍偏转 | 不硬挡 → 闪后反击 |
| 下盘攻击（低扫） | 提膝格挡，小腿垂直护住 | 提膝即正蹬/侧踢蓄力 → 挡→蹬 |
| 贴身向上（膝顶） | 双掌下压+侧身让力 | 双掌在下 → 起身推掌/标指 |
| 直线推力（正蹬/推踢） | 双掌接推+滑退卸力 | 力被引走 → 接+滑后反击 |
| 垂直重击（下劈腿） | 交叉臂上格+下蹲卸力 | 被压得微蹲 → 蹲起后贴身 |

> 防守姿势也要递进：第 1 轮轻松卸力 → 第 2 轮开始吃力、后退半步 → 第 3 轮格挡被崩开 → 第 4 轮不再硬挡，改化劲/闪避/反击。防守端的"越挡越吃力"与 §0 的升级三线同步。

## 4｜Spatial & Distance（空间连续）

- **首次交战必须建立**：双方位置、朝向、距离、**动作轴线**、摄影机区域、环境障碍
- 所有换位**必须拍出过程**——禁止瞬移、突然换手、状态重置
- 轴线纪律：正反打与越轴按 180 度规则；越轴必须有过渡镜头（跟拍绕行/插入中性镜头）
- 环境障碍是资产不是障碍：桌椅/栏杆/立柱/屋顶高低差要被打斗**用到**（踏瓦、借力、被逼至死角）

**多对手围攻的方位纪律** [drama-skills: fight-craft.md#4, blocking-playbooks.md#SHT-14]：

- 围攻在场景站位里给每个对手记一个相对主角的**固定方位**（"靠灯一侧""主角身后靠集装箱一侧"），所有镜头都按这个方位写；画外对手入画从记录的那一侧进来
- **每个回合只有一个对手在出手**，其余对手停在看得见的等待位置——观众读得清，每镜也只有一次接触
- 主角转身迎向另一个对手时**轴线跟着换了**：先用一个全景或中全景重新交代谁在哪，再进入下一回合，不在两个近景之间直接跳到新轴线上
- **慢动作、特写、群众反应或解说不能替代丢失的空间阶段**；对手战术调整应能追溯到此前看见的信息，避免每轮都重置成同一站位
- 与 §8"多人混战拆 1v1 焦点"的关系：本条是**编排层**（谁在哪、谁出手、换轴重建），§8 拆 1v1 是**生成端降级实现**（同框人数多到糊时的兜底）——先按方位纪律排，排不动再降级

**闪避大幅化** `[社区方法论]`：燃向/二次元/漫剧档的闪避禁止"侧身一让/微微侧移"这类小幅平移——小幅闪避=画面停滞。改成下潜贴地/后仰≥45°/后跃/旋转闪避/大幅横移跳开；闪避本身也是视觉动作。写实格斗允许小幅偏身，但必须写偏身幅度+来拳擦过的路径+随即反击，不能只写"躲开"。

**空间维度变化**：9s 以上或含腾空的打斗段至少 2 次空间维度变化（腾空/贴地/倒置/高低差），否则容易退化成站桩对轰 `[社区方法论]`。

**打斗切镜连续性八项**（每个切点前逐项核对，与 V3.22 走位总谱/道具账/环境动效账并用）：①双方左右位置 ②面朝方向与身体姿态 ③运动方向与速度 ④武器所在手/角度/完整状态 ⑤弹药/能量/道具数量 ⑥对手是否还能行动 ⑦场景损伤与移动物件 ⑧仍在持续的尘土/火花/液体/光效。切镜只改变观看位置，已发生的事件不能因机位变化被重置。

## 5｜Impact & Recovery（命中反馈分型 + 打击呈现）

| 武器类型 | 命中反馈写法 |
| --- | --- |
| 刀剑 | 看刃线与避让（刃口相撞火花、贴脊摩擦、削断雨线） |
| 枪矛 | 看枪尖路径与偏转 |
| 棍锤 | 看惯性与身体位移（被砸者整个人位移，不是原地晃一下） |
| 拳脚 | 看头躯偏转、支撑脚与失衡 |
| 软兵器 | 看缠绕、拉扯、回弹 |

**攻击后必须出现恢复动作**：回收｜落地｜换脚｜回架｜恢复重心｜重新建立距离——没有 Recovery 的 Attack = 摆 pose = 崩坏。

### 打击呈现（把"打中了"卖给观众——分型是反馈内容，本节是呈现镜头语言）[drama-skills: fight-craft.md#3]

先分清这一下是什么。**落空、格挡、闪避、武器砸在环境上**——观众要看的是路线和空隙：用稳定的侧面或斜侧中景，让出手、让开和结果都在一个画框里看清。**武器落空砸在环境上（火星、水花、凹痕）比砸在人身上更好生成，也更能说明力道。**

真正打到脸或身体的那一下，两个运动中的身体在接触点上最难读清、最易生成走样。让观众相信打中了，靠下面三件事，而不是把拳头贴在脸上那一格拍清楚：

1. **连续镜头里遮住接触点**：两人全身都在画面里时，摄影机在**轴线同一侧**换到出手者肩后或斜后方，让拳脚路线朝向或背离镜头经过，接触点被前景的手臂或肩膀挡住。（为遮挡越到轴线另一侧反打=观众丢失方位，不值得）
2. **多镜覆盖里给打击特写**：只有承受者的脸或身体在画面里，拳脚从**画外闯入**、砸中，脸顺着来力甩开。画面里只有一个运动的身体，接触点可以露出来——这是"拳拳到肉"的来源，前提是剪辑把它剪短
3. **承受者的反应**：头顺着来力方向甩开，身体跟着走，脚下退步或失衡，手捂住被打的位置。**反应的方向必须和来力一致**
4. **声音和余波**：一声闷响、溅起的水、撞歪的物件，承受者退到哪里停住

**贴身缠斗单控制**：抱摔、缠斗这类贴身动作，一镜只写一个控制——谁的哪只手臂箍住谁的哪里，然后是挣脱或放倒。写开始控制和松开的两个状态，中间的角力用声音和一次发力带过，不写多步的手部换位。

**接触镜难生成时**（打到人身上/贴身控制）：走可生成性改写阶梯（prompt-rules.md 0.7——轴线同侧遮接触点、画外闯入打击特写本身就是可生成改写），**不做预先降级实现**；只有真实生成失败后才走 SKILL.md 回退阶梯（裁定 R3）。

### 命中反应按部位分型（被击反应差异化） `[社区方法论]`

| 命中部位 | 身体反应 | 写法要点 |
| --- | --- | --- |
| 面部/头部 | 头颅顺来力后仰、发丝甩动、脚步踉跄 | 反应方向与来力一致；可加瞳孔骤缩/血线，血腥按强度档 |
| 腹部/肋部 | 身体弓成虾形、双脚离地或后退、呼吸断裂 | 重击写"被掀起来"的整身位移，不写原地晃一下 |
| 下盘/腿部 | 单膝跪地、重心塌陷、手撑地 | 下盘受击后行动受限要延续到后续回合 |
| 肩颈 | 身体旋转、撞入地面/墙面、锁骨下沉 | 撞墙/嵌地后保留凹痕与碎屑 |
| 手臂/格挡 | 格挡臂震颤、护臂崩开、双臂甩向两侧 | 这是"挡不住了"的信号，接 §3.5 崩防线 |
| 喉咙/关节（擒拿/致命） | 动作冻结、关节反扭、失声/跪倒 | 不自行加码血腥；结果按 content-safety 降级 |

**重量与疲态层（让身体有血有肉）** `[社区方法论]`：落地沉重、膝盖微屈缓冲、肩膀下沉、胸口起伏、肌肉紧绷、咬牙；连续交锋后动作变慢、格挡后手臂发颤、起身先撑膝。面部锚点（咬紧牙关/瞳孔放大/冷汗）按 expressions.md 物理化改写，不另建词库。**疲态逐镜累积：轻→中→重，不能上一镜力竭下一镜满血。**

**连击多区域**：连续快攻不要锤一个点——面部→腰侧→腹部→面部，四拳四区域，轨迹各异、落点分散 `[社区方法论]`。

### 打击空气反馈与能量层（燃向档：二次元/漫剧/仙侠/异能可选，写实项目不强制）

> 本节只管"打击空气层+能量节奏"；光效本体（法阵/剑气/粒子）仍按 vfx-effects.md 的三层/emissive/高光锚定写。`[社区方法论]`，具体阈值 `[待实测]`。

- **每击都有空气反馈，轻≠弱**：轻击=路径空气微扭曲+命中空气波纹；重击=拳风切开空气、命中音爆气浪、脚下碎尘震起；终结=环形冲击波+地面碎裂。轻击配大特效/重击零特效=能量不守恒。
- **攻击形态决定气爆形态**：直线（冲拳/标指/正蹬）=细长气穴；弧线（摆拳/鞭腿/横肘）=月牙气刃；下砸（砸肘/下劈）=向两侧翻涌的气帘；旋转（旋风踢/反背肘）=螺旋气旋；寸劲=接触点骤然压缩后炸开。
- **速度的空气证据**：快速=半透明残影 0.1s；极快=可见气痕+残影 0.2s；瞬速=锥形压缩空气层+沉闷音爆。
- **余波回填**：重击后 0.3s 回填气流卷尘、发丝回飘、空气余震；被击者滑行时脚下拖出两道尘土气轨。
- **特效轨迹四要素**：起源点（拳面/脚尖/刃口）→流动形态（直线穿刺/弧线切割/螺旋扩散/垂直坠落/涟漪扩散）→终点爆散（冲击波/碎裂/湮灭）→余韵残留（焦痕/波纹/余烬/光痕）。缺任一项=特效像贴图。
- **特效生长三段**：萌芽（蓄力，弱但可辨）→生长（沿攻击轨迹增强、密度递增）→绽放（命中巅峰）。连打过程保持零特效，收尾重击带特效当"句号"；前段一招一炸、后段全程铺满炸。
- **特效服从角色主色**：角色卡的主色是唯一归属；流派原始配色只作参考，找不到主色归属的颜色一律删掉。冷暖对抗优先互补色（暖紫 vs 冷青蓝），同色系特效打架没有冲突感。
- **能量生命周期**：汇聚→释放→碰撞→消散；不全屏长时间发光，不遮住人物轮廓与兵器接触点（接触点是观众读力道的地方）。

## 6｜Camera（与 Action 分离）

Camera 描述至少包含：**景别｜机位｜运镜｜方向｜速度｜跟焦主体**（六要素齐）。

**景别 ↔ 动作幅度匹配（按本镜职责选，不按动作热闹程度选）** `[社区方法论]`：

| 动作幅度 | 景别 | 边界 |
| --- | --- | --- |
| 大幅：腾空/旋转/下劈/扫腿/飞踢/摔投 | 中景/全景，展示全貌+空间纵深 | 不要只用近景/特写读全貌 |
| 小幅：拳/掌/肘/寸拳/格挡/指法 | 近景/中近景，放大密度 | 全景只用于交代空间/走位，不承担读拳脚细节 |
| 中距攻防/踢击/单招 | 中景 | 微表情/手指细节不可见 |
| 接触点/破绽/关键命中 | 特写 0.2-0.5s，作为标点 | 不要持续特写（大幅动作变成一团光） |

**空间感铁律：中景及以上禁 90° 侧面正拍**。两人完整身子同框用 90° 侧面=横版格斗游戏，兵器厚度与空间纵深消失；必须用 30-60° 斜角（可叠仰/俯）。近景/中近景/特写允许 90° 侧拍（只看到局部，空间感由主体细节提供）。

**镜头目的四原则** `[成品样例]`：①正常速度对招 → 中近景/近景·侧面·带微移动（出拳时镜头随拳前推 0.2s、格挡时微后震，移动感≠乱晃）②蓄力大前摇 → 全景/中景·15-30°仰视·慢推（环绕仅当本镜命中 R4），特效在蓄力点凝聚成实体③快速攻防 → 中景/全景·30-60°斜角·方向性移动（镜头移动方向与攻击方向一致=速度感翻倍）④特写 → 破绽/转折/命中反应·急速推镜后 0.2-0.5s 立即切走（特写是标点不是段落）。

**跟随目标必须写死**：跟拍类运镜写跟随谁/哪个部位（跟随右拳推进/跟随踢击弧线/跟随腰部横移/推进至命中点前 0.5 米骤停），不写"跟随拍摄"。

**镜头节奏三拍（单次关键命中）** `[成品样例]`：①出拳前短暂停顿 0.2-0.3s（蓄力感）②命中瞬间快速推进+微震（短促推近；微震幅度小，不整镜晃）③慢一拍切近景/中景，气浪掀起头发/衣摆，碎石落定。**三拍只用于关键命中；普通交锋用正常速度+稳定跟拍。**冲击帧（1-2 帧黑白闪/反色）属闪白家族，本镜写触发画面并标注峰值来源，成片 1-2 帧由剪辑完成。

**隐形切镜**：切点优先藏在身体遮挡（披风/手臂/兵器扫过镜头）、甩镜模糊、冲击帧里；切后延续上一镜的位置/朝向/动量/伤损（与 §4 打斗切镜连续性八项并用）。切镜仍依附真实动作节点，不为炫技无理由切。

### 回合拆镜决策序（交手账回合 → 镜头，按序三选一）[drama-skills: fight-craft.md#2 / SHT-31]

一个回合在银幕上通常只有一两秒，而目标模型最短原生时长往往更长（H3/happyhorse 最短 3-4s）。一拍一镜、每镜停住等剪，整场会被拖慢。**生成端真相：镜头给多长，模型就把这几下拉多长，回合中间会出现停顿；正文里写「快」「一气呵成」或逐秒时间，都不能把动作压回真实速度。**按顺序选：

1. **多镜容器（打戏默认）**：一个回合在一次生成里切成「**起手的中景 → 打击的特写 → 余波的中景**」，各拍仍各自成镜。剪辑在生成出来的切点处紧剪，打击特写只留拳到前后的一小段，起手和余波也只留读得懂的部分——这是打戏读得出力道的主要做法
2. **整回合一镜**：发起、应对、结果作为本镜"唯一动作"连续完成，摄影机在一个稳定位置看完整条路线。仅当最短时长装得下一个完整回合时用；镜长取装得下这个回合的最短一档
3. **单独成镜**：只有**缴械、决定性一击或改变下一步选择的反应**才单独成镜。打中之后的连带结果（武器松脱、滚走）写进同一镜时常被略过——结果要紧就单独成镜，或作为下一镜的起点状态

### 打斗景别功能阶梯 [drama-skills: fight-craft.md#5]

- 每个新阶段的第一镜用**全景或中全景**交代距离：谁离谁几步、武器在谁手里、身后有什么
- 交手用**中景或双人中全景，能看到两个人的脚——距离靠脚下读出来**
- **近景和特写只给信息**：握紧的武器、脱手的落点、决定性一击之后的脸
- 9:16 竖屏横向窄，横扫、侧踢容易出画——把交手的方向摆成**朝向或背离镜头的纵深，或者斜线**；高举的武器和高位腿法需要纵向留白

**武器镜头速查** `[成品样例]`：

| 情境 | 景别/视角/运镜 | 必须让观众看到 |
| --- | --- | --- |
| 常规兵器对招 | 中近景/近景·侧面 90° 或 45° 斜侧·跟拍/小幅横移 | 手腕翻转、兵器变线、格挡碰撞 |
| 高速兵器攻防 | 中景·30-60° 斜角（禁正面和 90° 侧面）·快速横移/斜向推进 | 步法+兵器轨迹+空间纵深 |
| 大范围剑花/横斩 | 中景→全景·45° 斜拍/斜仰·环绕（≤180°）/急速拉镜 | 完整圆弧、光轨层次、身体舒展 |
| 腾空劈刺/大前摇 | 全景·15-30° 仰视·慢推→俯冲跟随 | 蓄力压迫、腾空高度、落地冲击 |
| 低位扫击/地躺 | 中景/全景·45-60° 斜俯或垂直俯拍·高空俯拍跟随 | 贴地轨迹、地面碎屑、下盘破坏 |
| 穿刺/格挡命中 | 特写·正面微侧/侧面微偏·急速推镜→定格 0.2s | 刺入、咬合、火花、裂纹 |
| 缴械/缠械 | 近景/特写·45° 斜侧·慢动作跟镜 | 兵器缠绕、摩擦、持械手腕被控 |

> 兵器碰撞不能只写爆炸——必须写剑身/剑格/刀锋/镰钩的物理接触，爆炸只是反馈不是动作本体。

**环绕与旋转**：近景对招段优先小幅度线性运镜（急速横移跟拍/急速推镜/跟拍跟镜/震镜）；环绕只用于无攻防接触的对峙/蓄力段，且运镜功能仍按 cinematography R1-R7 选——命中 R4 才用，≤180°，禁 360° 满圈，禁螺旋上升（眩晕/失向，三人同场更严重）`[社区方法论]`。

### 打斗接触专条（写成执行端做得出的正文）[drama-skills: generability.md#7 VID-28]

打斗是精确拦截与多主体接触最集中的地方。分镜已决定回合、机位和哪一下单独成镜，本节只管把回合写成可生成的正文：

- **一段一个出手者**（规则本体见 §4 围攻方位纪律 + prompt-rules 重叠原则边界裁决；此处只给本镜写法）：`0–1.5 秒 他抡起木棍朝对方头顶劈下；1.5–3 秒 对方上身朝自己右侧一偏，木棍擦着左肩落空`。先后动作的咬合写不出来，交给剪辑在动作中途切换
- **左右按人物自己的身体说**：`他的右拳`、`她的左肩`；方向按场景锚点说（"朝集装箱一侧"）。**画左画右在机位一换就会反**
- **写路线和反应，不写接触点形变**：`右拳从镜头前方朝他下巴方向挥过，他的头猛地朝左甩开，踉跄后退两步`，**不写** `拳头打在脸上`、`脸被打得变形`。打击由承受者的反应、环境结果和声音读出（见 §5 打击呈现）
- **贴身控制写两个状态**：谁的哪只手臂箍住谁的哪里，然后是松开或放倒；中间不写多步换手
- **变速另作决定**：生成里默认写正常速度；慢动作只给决定性的那一下（交手账 ★ 胜负手），并写明慢放从哪一刻开始、到哪一刻结束；其余变速留给剪辑
- **伤与血按强度档**：照创作者选择的强度档和目标平台内容政策写结果，不自行加码

自动选择逻辑：
- **One Take（一镜到底）**：空间换位、兵器轨迹、环境互动——需要观众看清空间关系时
- **Rapid Cut（快切）**：近身爆发、打击反馈、高密度交换——1-2s/镜
- **切镜只能依附真实动作节点**（出手瞬间/命中瞬间/换位完成）——不在动作中间无理由切

**成品案例的镜头语言**（30s 雨夜屋顶打斗，21 个镜头块）：低机位极速前推贴瓦面 → 中景持续跟焦纵跃 → 微距特写刀刃擦肩 → 环绕机位腾空旋斩 → 侧面环绕半圈甩摇兵刃火花 → 极低仰拍急推踏瓦飞奔 → 侧后方跟拍追击 → 垂直仰摇跃向高阁 → 超高速平移跟拍兵刃交击 → 正面锁定碰撞点 → 越肩推进错身甩摇 → 正面追尾冲刺残影 → 远景缓慢后拉收束对峙。可复用模式：**开场贴地细节抓人 → 中段跟焦+环绕+甩摇交替 → 碰撞点正面特写 → 收尾远景拉开留余韵**。

## 6.5｜近景对招与打击密度（密度型观赏性）

[社区方法论 + 成品样例: seedance-combat-prompt 近景对招体系]

远景/全景看"大动作"（腾空/旋转/下劈）＝奇观型观赏性；近景/中近景看"杀意"（拳脚交错/格挡弹开/寸拳贴脸）＝密度压迫型观赏性。只有大动作没有近景对招=只有爆炸没有枪战。

**使用条件**：短视频/二次元/漫剧/武侠档的 15-30s 打戏，至少 1 段 2-3s 上半身近景对招；位置放在开局突进后（建立"打起来了"）或情绪拐点前（密度推满再翻转）。电影化长段按剧情需要，不强行配；长兵器大幅动作段不硬塞近景对招。

**镜头语法**：中近景（胸以上+双臂）=对招主体；近景（肩以上）=冲刺密度；特写（面/手/接触点）=微慢镜插入 0.2-0.5s。侧面 90° 仅限近景/中近景；中景以上按 §6 改 30-60° 斜角。

**三种节奏型** `[社区方法论]`：

| 节奏型 | 节奏 | 适用 |
| --- | --- | --- |
| 3 轻 1 重 | 三下快击+一记重击慢放，"刷刷刷——砰！" | 咏春/空手道/散打 |
| 左右交替加速 | 左-右-左-右，间隔越来越短，像打鼓加速 | 泰拳/八极/拳击 |
| 封-破-杀 | 两下格挡弹开→一次破防→一次致命，"挡住了→没挡住→完了" | 太极/擒拿/柔术 |

**招式链写法（硬规则）**：2-3s 近景段写 3-5 个招式，每个写"招式+落点+防守反馈"，用 `→` 连接；**禁止**"每秒攻击≥N次/每击间隔≤N秒/攻击频率/机枪节奏"这类抽象频率——AI 对定性节奏词的执行偏差大，必须给可拍摄的招式链。示例：

```
右摆拳打脸→左勾拳打下巴→右直拳打鼻梁→左横肘切眉骨→右标指刺咽喉；
对方依次侧偏、下潜、拍开、架桥、后撤。
```

> **与 0.13 动作密度的关系**：招式链是"意图级"的连招序列（招式名+落点+反馈），不是关节角度/厘米位移的逐帧微操；关节角度、具体位移仍只给峰值/决定性动作。两者不冲突，别把招式链写成解剖课。

**手部多样性与冲击力**：近景连招至少覆盖 2-3 种手部形态（拳/掌/指/肘/爪/腕/肩）；武侠/二次元档优先肘击（近景冲击力排序：砸肘>横肘>寸拳>上勾拳>标指/插指>推掌>冲拳>拍掌）。写实拳击/MMA 按实际技法，不硬塞肘击。

**微反馈**：近景必须至少给 1 处身体微反馈——格挡震颤/拳面擦过汗珠或血珠/护臂崩开/汗珠甩出/呼吸断裂。微表情本体按 expressions.md 物理化改写，本节不另建词库。

**远近切换** `[社区方法论]`：
- 近景→远景三步：①近景重击命中（看清打击点）②中景被击者后退/被推飞（镜头跟拉，景别放大）③全景撞墙/滑行/腾空（看大动作全貌）。**禁止近景硬切远景**。
- 远景→近景两步：①全景→中景（突进贴脸，镜头急推）②中景→近景（拳已到眼前，微推锁定面部）。突进自带速度感，可以两步压缩。

**呼吸帧**：终结/转折前 0.3-0.5s 静止或极慢；前提是前面 ≥1.5s 高速段——速度差=情绪弹射器，没有高速铺垫的定格=无聊停顿。呼吸帧属定格/慢镜强调手段，按 cinematography「峰值与强调手段」标注峰值来源，不另立预算。

**顿挫 vs 圆活**：八极/泰拳/空手道=顿挫型（每击独立爆发，打完即收）；太极/咏春/巴西战舞=圆活型（连贯无缝）。两种节奏对撞=刚柔对比，不是招式不同而已。

## 7｜输出格式：状态机 → 骨架 A 镜头块（装填模板，照抄结构）

> 每段打斗同时填「环境动效账」（templates-execution 八）：每次接触至少一条环境响应；动物按 realism 第七节核对皮肉惯性。

**打斗镜头块不写"动作三段式（从/过程/至）"，改写状态机七段**——七段本身就是三段式的扩展版（Start State=起始、Attack→Impact=过程、End State=终点），不要两套都写（重复=干扰）。**一行式装填**（每段用 → 连接，写成一个连贯段落，不分条列举）：

```
{时间区间}｜镜头{N}｜{标题}
{Camera 六要素：景别｜机位｜运镜｜方向｜速度｜跟焦主体}。
{Start State：起手姿态+距离+朝向} → {Intent：这一招的战术目的，双方各一个} →
{Attack：攻方动作+武器合法动作标注+力学（支撑脚/腰胯发力/重心）} →
{Response：守方应对+合法动作} → {Impact：按武器分型的命中反馈} →
{Recovery：双方各自的恢复（回收/落地/换脚/回架/重新建立距离）} →
{End State：本镜最后一帧的确定画面}。
{台词（如有）：角色名（发声方式描述）："台词"}
表演：{不是X，而是Y。核心是Z}。
```

**范例（成品级，可直接对照）**：

```
6.0s–8.5s｜镜头4｜第一招·交刃
中景｜侧面机位垂直于两人连线｜手持轻微晃动｜水平｜中速｜跟焦两人刃口接触点。85mm。
Start State（两人相距五步静止对峙，她剑尖垂、他按刀）→ Intent（玄鸦：抢距离+试探她的根基；
沈青绡：封正面路线护住中线，把刀势斜着引进空处卸力，这一格不是硬接）→
Attack（玄鸦右脚前跨弓步、双手握刀全力下劈——刀的合法动作：劈）→
Response（沈青绡不退反侧身半马步、双手合握剑向左上方斜架格挡——剑的合法动作：格）→
Impact（刀剑分型看刃线与避让：两刃呈十字相抵迸火星，雨水触刃汽化腾起极细白汽，
刀锋压着剑脊下滑半寸，剑身微弯蓄弹力）→
Recovery（玄鸦劈势用老、双臂沿刀身回弹半寸重新收拢握紧回架；沈青绡吃住刀势后
肩胛下沉半寸、马步重新压实——双方各自回稳，无人僵直定格）→
End State（两刃锁死十字相抵、火星迸起、两人相距一臂半）。
表演：不是杂耍比划，是两件真兵器第一次咬合。核心是双方都在称量对方的力量。
```

> 非打斗镜头（对白/反应/空镜）仍用 prompt-rules.md 骨架 A 的动作三段式——两套结构的分工：**打斗镜头块=状态机七段，非打斗镜头块=动作三段式**。同一段落内可混用。

> **打斗段标记（V3.21）**：04 打斗段段首必须写 `打斗段：是（交手账 RX-RY）`；A17 机检——有标记但缺七段任一节 → 报错；标记存在但 01 无「打斗交手账」→ 报错。没有标记的段按非打斗处理，仍用三段式。标记是"这段用了 action-combat"的留痕，不是给模型看的正文。

> **近景对招的写法落位（V3.26）**：近景对招不另起结构——它是七段中 Attack→Response→Impact 的压缩：Attack 写招式链前半，Response 写逐招防守反馈，Impact 写最后一击的命中反应；Start/Intent/Recovery/End 仍各一句。这样 A17 的七段检查不受影响。用了近景对招的段，段首可加 `近景对招：是（X-Ys）` 留痕（可选，不硬查），并在 01 可选能力台账登记。

> **短视频打戏档（≤15s 独立片段）** `[社区方法论]`：第一帧双人同框/近景（不先铺全景），1.5s 内出现第一次有效攻防接触；结尾停在终结技的冲击波/碎屑/气焰——峰值收尾，不补 0.5s 收尾平静帧。电影化/长段落不适用。

> **空镜与换气**：打斗段不用空镜打断动作；回合间换气用 ≤0.5s 的环境声/对手反应/道具余波；内容安全降级时按 content-safety 用影子/远景/遮挡替代，不自行加码。

段落级补充节：
- **HARD LOCK**（写进 NO 节）：禁止武器功能错配、枪矛长期挥砍、软兵器无惯性转向、拳脚无重心发力、腿法无支撑脚、投掷物数量变化、重武器连续无恢复、人物瞬移、孤立招式堆叠、无过程换手换位、**武器互换/凭空出现或消失、打中空气却有人倒飞、无支点腾空/无落点、伤损恢复、全屏长时间发光遮住人物轮廓/兵器接触点、切镜后位置/朝向/动量/伤损重置**
- **物理与质感**（写进 FORMAT/LIGHTING）：雨滴冲击、瓦片崩飞、金属火花、尘土飞溅、衣摆滞后、强动态模糊、仅终结一击短暂定格，**禁止长定格、禁止摆 pose、禁止长时间凌空飞行**。速度处理：默认正常速度（生成端真相：镜头给多长，模型就把动作拉多长——写"快"压不回真实速度，高危动作降速优先用"拆更短镜头+切点紧剪"实现，不用整段升格）。慢动作是强调手段，只花在已点名峰值上——判据与配额见 cinematography.md「峰值与强调手段」节（唯一的家）[drama-skills: fight-craft.md#2]
- **尺度锚定**：巨大生物/机甲戏写明体型数字与参照物对比（"巨兽约300米，废弃工程机械在其脚下如玩具"）——尺度靠参照物锚定不靠形容词

**可复用要点**：
- **隐形切镜**：身体遮挡/甩镜/冲击帧；切后延续位置/朝向/动量/伤损。
- **伤损累积**：A 灵纹明灭→单膝→溢血；B 重甲无痕→裂痕→胸甲碎；不能下一镜恢复。
- **全片唯一一次慢镜**放在反推决胜（0.5x）；普通交锋正常速度；关键命中可插 1-2 帧冲击帧。
- **因果顺序**：先发力、先接触，再火星/冲击波/震动/音效；格挡与落空分明，不出现"打中空气却有人倒飞"。
- **腾空有蹬踏支点与落点；击飞有力量来源、飞行弧线与落点。**
- **能量生命周期**：汇聚→释放→碰撞→消散；不全屏长时间发光，不遮人物轮廓与兵器接触点。
- **结尾**：30s 国漫可用稳定远景收束；≤15s 短视频打戏档仍按 §7"峰值收尾、不补平静帧"。

## 8｜高风险动作的生成端处理（主方案优先——回退列仅在生成失败后使用）

> 主方案就是表现力方案，生成难度是走可生成性改写阶梯的触发器（prompt-rules.md 0.7），不是回避表现力的理由；"生成失败后的回退写法"只在真实失败后启用（SKILL.md 回退阶梯），**不预先降级、不在 GATE1 让用户二选一**——强调手段的分配走 cinematography.md「峰值与强调手段」节。

| 高风险动作 | 主方案 | 生成失败后的回退写法 |
| --- | --- | --- |
| 腾空旋斩/飞檐 | 拆短镜（腾空段独立成镜 1-2s，落地段独立成镜），慢动作仅腾空顶点 0.3-0.5s 且须有峰值标注（←峰值：交手账R<N>，见 cinematography.md「峰值与强调手段」节） | 缩短腾空时间，落地即接下一动作 |
| 兵刃连续交击 | 1-2s 快切分镜逐个交击 | 单次交击特写+音效补密度 |
| 反先验动作（腿蹬弓类） | **必走关键帧锁定**：情景图先给出该姿势，视频只写后续运动（prompt-rules.md 0.2） | 改为常规先验动作+借先验概念（"像哪吒"） |
| 多人混战 | 拆成 1v1 焦点+背景虚化群像 | 减少同框人数，分镜轮切 |
| 长距离追逐 | 分 2-3 段尾帧续接 | 缩短单段距离 |

## 9｜武学风格签名速查（一页——给角色定节奏与距离，不搬招式明细）

[社区方法论: seedance-combat-prompt 武学库提炼；只取距离/节奏/签名/镜头偏好/禁忌，不搬具体招式名与虚构门派]

## 10｜失败诊断与单变量修正（打斗段出问题先查此表）

[社区方法论: fight-prompt-director 失败诊断]

**三类变量**：动作（方向/目标/接触结果/身体回应/位移/速度/距离/资源/下一拍接口）、镜头（景别/机位/轴线/速度/切点/跟随/遮挡/职责）、参考素材（首帧姿势/人物轮廓/武器可见性/素材职责/顺序/首尾帧差异）。

| 症状 | 归属 | 首选修正 |
| --- | --- | --- |
| 双方各打各的 | 动作 | 补全发起→接触→回应→位移→下一拍接口 |
| 接触点看不清 | 镜头 | 侧向中景或短促接触特写；不在接触前用遮挡/过近特写 |
| 人物左右互换 | 镜头/空间 | 固定轴线与屏幕方向；切镜前记录站位，越轴加过渡镜 |
| 动作自动减少 | 动作 | 删装饰描述，保留关键动作+结果，不堆形容词 |
| 身体融合 | 参考素材 | 换轮廓分离、肢体完整的首帧 |
| 武器复制/变形 | 参考素材 | 完整武器图+数量/长度/材质/握法写死 |
| 远程攻击凭空出现 | 动作 | 补取用/装填/充能，交代路径与落点 |
| 远程角色突然近战 | 动作 | 加后撤/侧移/掩体/副武器反制 |
| 受击没有力量 | 动作 | 写接触部位+受力方向+位移+材质反馈 |
| 场景损伤恢复 | 动作 | 后续时间段重复记录损伤状态 |
| 镜头随机跳切 | 镜头 | 减机位，每镜只承担一个职责 |
| 首尾帧过渡扭曲 | 参考素材 | 缩小姿势/机位差异，必要时加中间落点 |
| 参考视频被完整复刻 | 参考素材 | 用途声明只继承动作轨迹或摄影机路径 |
| 特效没有来源 | 动作 | 删除特效或绑定武器/装置/能力/接触点 |
| 防守瞬间恢复 | 动作 | 走 §3.5 防守三态，破防后先过渡态再恢复 |
| 近景像慢动作摆拍 | 动作/镜头 | 招式链改意图级；镜头加微移动；特写 0.2-0.5s 切走 |
| 特效炸裂但像假人比划/没有拳拳到肉 | 动作 | 改物理受力链：先写被压制/失衡→蹬地转腰送肩→接触→受击位移/喘息；删动作形容词与堆叠特效 |
| 打中空气却有人倒飞 | 动作/空间 | 补接触点与受力方向；格挡/落空/命中三态分明，击飞必须写力量来源 |
| 腾空无支点/落地无缓冲 | 动作 | 每次腾空写蹬踏支点与落点；落地写膝屈缓冲/滑步卸力 |
| 人物伤损恢复/疲态不连续 | 动作 | 按 §1 伤损累积账逐镜记；伤损与疲态只累积，不下一镜满血 |

**单变量修正纪律**：每轮只改动作/镜头/参考素材中的一类；连续两轮无改善→重新检查问题是否分错变量；不要同时重写全部提示词。修正记录写 01 质量缺陷台账：

```
本轮主要症状：{只写一个}
归属变量：{动作/镜头/参考素材}
本轮唯一修改：{具体改动}
保持不变：{其余条件}
复测观察：{修正后结果}
```

## 自检清单（打斗戏交付前）

- [ ] 每个动作有战术目的（Intent），无孤立招式堆叠
- [ ] 武器动作全部合法（无枪矛劈砍/软兵器无惯性/重锤无恢复）
- [ ] 拳脚有支撑脚、腰胯发力、重心变化描述
- [ ] 命中反馈按武器分型写出（刃线/枪尖/惯性位移/头躯偏转/缠绕回弹）
- [ ] 攻击后有 Recovery（回收/落地/换脚/回架/重新建立距离）
- [ ] 换位拍出过程，无瞬移/突然换手
- [ ] 上一段 End State = 下一段 Start State（伤势/体力/位置延续）
- [ ] Camera 六要素齐（景别/机位/运镜/方向/速度/跟焦主体）
- [ ] 切镜依附真实动作节点
- [ ] 投掷物数量守恒
- [ ] NO 节含 HARD LOCK 清单
- [ ] 反先验动作已走关键帧锁定
- [ ] 防守走完整态→崩防线→过渡态，破防后没有瞬间恢复完整格挡
- [ ] 不同攻击对应不同格挡，格挡姿势能衔接反击
- [ ] 命中反应按部位差异化（脸/腹/下盘/肩颈/格挡臂）
- [ ] 闪避是大幅动作，或写明偏身幅度+来拳擦过路径+随即反击
- [ ] 近景对招（如用）：3-5 招招式链+落点+防守反馈；无抽象频率；2-3 种手部形态；≥1 处微反馈；远近切换经中景
- [ ] 中景及以上没有 90° 侧面正拍
- [ ] 大幅动作配中景/全景，小幅动作配近景/中近景
- [ ] 连击跨区域，不锤一个点
- [ ] 燃向档：每击有空气反馈；轻击小特效/重击大特效；特效颜色有角色主色归属
- [ ] 打斗段没有空镜打断动作（换气/安全降级除外）
- [ ] 短视频打戏档：1.5s 内首次接触、峰值收尾、无平静收尾帧
- [ ] 写的是物理受力链，不是动作形容词（被压制/失衡→发力→接触→反应）
- [ ] 伤损累积不恢复；疲态逐镜加重（轻→中→重）
- [ ] 腾空有支点/落点；击飞有来力/弧线/落点
- [ ] 切镜后位置/朝向/动量/伤损延续；隐形切镜依附动作节点
- [ ] 能量汇聚→释放→碰撞→消散；不遮人物轮廓/兵器接触点
- [ ] 关键命中用镜头三拍；冲击帧/黑白闪带峰值标注
- [ ] 拟声词仅在目标模型实测有效时用（可选）
- [ ] 出现问题按 §10 单变量修正，不整段重写
