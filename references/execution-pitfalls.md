# 执行端操作坑清单（V3.9，用户实测）

> 本文件是执行端操作参考，**不进入 vigen 运行时链路**（Module Map 不读）。提示词规则在 SKILL/references；这里只记"工具怎么用会翻车"。

## 1. 参考图尺寸（最贵的一坑）

- 模型硬下限：**每边 ≥256**；240px webp 会直接报 2013 并扣费。
- 挂图前先跑：

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=s=x:p=0 <图>
```

- 两边都过 256 再挂；细节图建议 ≥1024。低于下限先放大/重导，不直接挂。

## 2. 画布单 in 口的 ref 序号

- `{{ref N}}` 的序号 = **连线创建顺序**，不是图片文件名/素材顺序。
- **append**：通常只新增编号（ref7/ref8），不打乱既有序——提示词挂图顺序表追加即可。
- **中途插入导致既有 ref 重排**：才需要删全部入线、按最终顺序重连；无论哪种，逐条核对 `{{ref N}}` 与用途声明，并同步 04 挂图顺序表（实测 v21/v22 插入错位）。

## 3. 尾帧依赖链

- 段 N+1 需要段 N 的尾帧时，不要停下等：先写 `PLAN-TAIL-<N>` 占位，照常产出 04；抽帧后绑 `REF-TAIL-<N>`。
- 与 E2 图片挂图同款人机并行；等尾帧=把串行等待放进关键路径。

## 4. 生成端只能全文重发（当前画布 setPrompt）

- 生成端没有局部编辑：每次重发前，把当前 prompt 存成**版本摘要**（版本号+改动点）写进 01 变更记录。
- 重发后与 04 文档对比；**禁止凭上下文记忆当前版本**（带错版本=整段返工）。

## 5. 文件操作

- **exports 写错 target**：04.md 落根目录 → 始终写项目目录下的 `04_视频提示词.md`。
- **edit 的 oldText 必须逐字符匹配**：先 Read 当前块，整段替换；不凭记忆拼 oldText。
- **不能读写同路径**：先写临时文件，再移动到目标。
- **ffmpeg 单张 PNG 的 image sequence 警告**：用 `-frames:v 1`，或用明确的 `%02d` 命名，避免把单张当序列。

## 6. 校验平台

- `check.py` 需要本机 Python；沙盒里的 `python3` 可能挂死。
- 当前执行口径：全量用 `check.py`（权威），或 `node "{技能目录}/scripts/check.mjs" <项目目录> --partial`（K1-K16 全量，与 `check.py` 同输出/同退出码）。无 Python 时用后者。
- 锁定审计（A16）：另加 `--gate A16`；机检风格圣经逐字/入画 REF 登记/持续在场三项，技术动作与朝向三要素仍人工核对。
- **画布→文档同步脚本不做**：用户后续可能更换画布软件，不同软件 API 不通用；只保留通用操作纪律（参考图全量重连 / 版本账 / 尺寸校验），不绑定具体画布。
