# 导演风格库（8 位导演视觉档案）

> **何时读**：用户点名导演风格（"王家卫感""诺兰风""韦斯·安德森式"），或项目主题与某导演美学高度匹配时。**风格提示词一旦选用即并入 02_锚定表风格圣经（作为扩展词条），全项目逐字复用，中途不换**。
> 每位导演档案 = 视觉参数表（六维度）+ 可直接复制的风格提示词。参数表用于分镜设计时的运镜/光线/节奏决策依据；风格提示词用于图片端。
> 源：社区电影视觉分析资料（2026-10），与 styles.md 的 15 风格互补（styles.md 是类型风格，本文件是作者风格）。

## 1. 王家卫 —— 霓虹湿街、抽帧拖影、贴身窥视

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 18mm 超广角贴身手持；2.35:1 宽银幕 |
| 构图 | 前景遮挡（门框、雨伞、玻璃、烟雾），人物偏居画面一隅 |
| 光线 | 实用光为主（霓虹、台灯、车厢顶灯），大光比，暗部不死黑 |
| 色彩 | 青绿（teal）阴影 + 洋红/橙红高光，整体偏暖绿 |
| 运动 | 手持轻微漂移 + 抽帧拖影（step-printing），慢门 |
| 节奏 | 跳切、碎片化、内心独白式 |

**风格提示词**：`2.35:1宽银幕，18mm超广角贴身手持，前景遮挡式构图（门框雨伞、玻璃、烟雾），实用光源大光比，青绿阴影配洋红高光强烈对冲，慢门抽帧拖影，粗颗粒胶片质感，暗部不死黑，情绪暧昧而疏离`

> 适配提示：抽帧拖影是王家卫标志性技法，但 AI 视频模型对 step-printing 的执行不稳定——图片端写"粗颗粒胶片质感+大光比"即可，视频端用 `Shake Slightly`（H3）或"手持轻微晃动"（happyhorse）近似，拖影效果建议后期在剪映做（帧率抽帧+动态模糊）。

## 2. 张艺谋 —— 大色块、高饱和、仪式感对称

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 中焦到广角；大量正对轴线的大全景 |
| 构图 | 严格中轴对称，人物居中，背景阵列化重复（人海、方阵、灯笼墙） |
| 光线 | 平光或顶光为主，色彩靠美术而非布光 |
| 色彩 | 单一主色爆满画面（正红、明黄、青蓝），大面积纯色块 |
| 运动 | 缓慢推进、仪式化横移，节奏庄重 |
| 节奏 | 古典、稳定、一板一眼 |

**风格提示词**：`大面积单一主色块铺满画面（正红/明黄/青蓝），严格中轴对称构图，背景阵列化重复（人海、方阵、灯笼墙），平光或顶光、色彩靠美术不靠布光，高饱和，缓慢推进或仪式化横移，古典庄重一板一眼的节奏`

> 注意：本风格与核心规则"避免居中构图"冲突——**用户点名张艺谋风格时对称居中是该美学的核心特征，例外允许**；其余风格仍遵循偏心构图原则。

## 3. 侯孝贤 —— 固定长镜头、远观、自然光、生活流

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 中长焦固定机位（50-85mm）；4:3 或 1.85:1 |
| 构图 | 远景、中远景，人物进出画框，常留大片空景 |
| 光线 | 纯自然光、窗光、灯泡，不做任何修饰 |
| 色彩 | 低饱和、褪色感、绿灰调 |
| 运动 | 几乎不动；偶尔极缓慢横摇或微微呼吸 |
| 节奏 | 极慢，一个镜头撑很久 |

**风格提示词**：`50-85mm中长焦固定机位，远景与中远景，人物进出画框、常留大片空景，纯自然光与窗光不做任何修饰，低饱和褪色感绿灰调，镜头几乎不动，一个镜头撑很久，生活流式留白`

> 适配提示：侯孝贤美学 = "固定机位+主体动"（AI 视频最稳组合），天然适配 AI 生成；"一个镜头撑很久"与短视频 15-60s 节奏冲突——只取"远观+自然光+绿灰调"视觉特征，镜头时长仍按项目节奏模板。

## 4. 姜文 —— 高反差、荒诞浪漫、快速手持

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 广角略畸变（25-35mm）快速推拉 |
| 构图 | 不稳定、倾斜、突然的极近特写 |
| 光线 | 硬光、强投影，黑白时期对比拉满 |
| 色彩 | 高反差黑白；或浓烈的暖金黄（阳光灿烂感） |
| 运动 | 手持快速移动、突然甩镜、跳切 |
| 节奏 | 极快，呼吸感强 |

**风格提示词**：`25-35mm广角略畸变，不稳定倾斜构图、突然切入的极近特写，硬光与强投影，高反差黑白或浓烈暖金黄，手持快速推拉与甩镜，跳切，极快的呼吸感剪辑，荒诞浪漫`

> 适配提示：快速手持+甩镜是 AI 视频高风险运镜（抖动/形变）——降级：手持改 `subtle handheld, slight natural shake`；甩镜改两段生成+剪辑模糊转场；快速推拉改 slow zoom + 后期变速。倾斜构图用荷兰角实现。

## 5. 杜琪峰 —— 冷蓝夜色、舞台站位、静待爆发

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 中远景为主，偶尔长焦压缩群像 |
| 构图 | 人物站位像舞台调度，几何关系极其精确 |
| 光线 | 顶光/侧光切割，暗部占比大，路灯做唯一暖源 |
| 色彩 | 冷蓝、青灰为主，点缀一点暖黄路灯 |
| 运动 | 静止为主；爆发时切极快 |
| 节奏 | 极静—极动，反差巨大 |

**风格提示词**：`中远景冷蓝夜色，舞台式人物站位调度、几何关系极其精确，顶光侧光切割画面、暗部占比大，路灯作为唯一暖源，长时间静止后接极快爆发式剪辑，静与动反差强烈`

> 适配提示："极静—极动"在 AI 生成端拆开处理——静段用固定机位（最稳），爆发段单独生成短镜头（3-5s），反差靠剪辑节奏实现，不指望单镜头内完成静动转换。

## 6. 贾樟柯 —— 粗粝纪实、手持DV、时代噪音

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 手持随机，构图不完美；DV 与数字感 |
| 构图 | 随意，偶尔切掉半个头，画框边缘不讲究 |
| 光线 | 现场光、荧光灯、尘土中的散射 |
| 色彩 | 低饱和灰绿黄，脏、旧、发闷 |
| 运动 | 随机跟随、晃动、突然停住 |
| 节奏 | 生活流，混乱中偶有静止 |

**风格提示词**：`手持DV粗粝纪实感，构图随意不讲究、偶尔切掉半个头，现场光与荧光灯、尘土中的散射，低饱和灰绿黄、脏旧发闷，随机跟随晃动后突然停住，生活流节奏，时代噪音感`

> 适配提示："切掉半个头"式不完美构图与核心规则"身份清晰可辨"（蓄力五标准之一）冲突——仅用于非关键叙事镜头的氛围空镜；主体镜头仍保证身份完整。DV 质感在图片端写"Grainy DV footage, slightly compressed"（格式指令比氛围词有效）。

## 7. 克里斯托弗·诺兰 —— IMAX大画幅、冷灰蓝、精密结构

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | IMAX 65mm，广角全景与超大特写硬切 |
| 构图 | 稳定、水平、信息密度高，实景为主 |
| 光线 | 自然光与实用光，低对比灰调，不做美化 |
| 色彩 | 冷灰、钢蓝、去饱和，肤色偏冷 |
| 运动 | 稳定器、航拍、机械般精准的推进 |
| 节奏 | 沉稳、理性、结构感强 |

**风格提示词**：`IMAX大画幅，广角全景与超大特写硬切，稳定水平的高信息密度构图，自然光与实用光、低对比灰调不做美化，冷灰钢蓝去饱和，稳定器与机械般精准的推进，沉稳理性结构感强`

### 诺兰调色专项（《盗梦空间》《敦刻尔克》色调）

- **风格定位**：冷暖对冲的"纪实化电影色彩"，肃穆、沉静、宏大史诗感
- **适用**：宏伟地标、大桥、山脉旷野、老建筑、大型工业场景、大环境人像
- **不适用**：甜美人像、多彩花海、霓虹夜市、美食、可爱小动物微距
- **调色提示词**：`IMAX 65mm胶片拍摄，专业电影摄影，超大动态范围，硬定向自然光，明暗强烈对比，深邃可控暗部，暗部保留丰富细节，高光不过曝，色彩克制低饱和度，青蓝阴影，暖棕受光面，冷暖对冲，厚重细腻胶片颗粒，写实材质纹理，浅景深，轻微镜头色散，自然真实投影，画面氛围肃穆沉静，电影级光影`
- 原负面清单（高饱和/死黑阴影/高光溢出/塑料质感/假HDR等）按 knowledge-index.md 负面词适配规则处理：gpt-image 转正向（"色彩克制低饱和、暗部保留细节、高光不过曝"已含正向表述）；H3 并入 ban list；happyhorse 只保留字幕水印禁令

## 8. 韦斯·安德森 —— 绝对对称、粉彩、平面化

| 维度 | 参数 |
| --- | --- |
| 焦段/画幅 | 中焦正对，严格居中；1.85:1 或 2.35:1 |
| 构图 | 绝对左右对称，人物永远在正中，平面化 |
| 光线 | 柔和均匀，几乎没有硬阴影 |
| 色彩 | 粉红、芥末黄、薄荷绿、天蓝；高明度低对比 |
| 运动 | 机械横移、90度转场、俯拍平铺（flat lay） |
| 节奏 | 轻快、俏皮、卡片式 |

**风格提示词**：`绝对左右对称、人物严格居中，中焦正对，平面化构图，柔和均匀光线几乎无硬阴影，粉红/芥末黄/薄荷绿/天蓝的高明度低对比粉彩配色，机械横移与俯拍平铺，轻快俏皮卡片式节奏`

> 注意：与张艺谋同理——对称居中是本美学核心，例外允许。"机械横移"在视频端用 `Truck Left/Right with small amplitude at slow speed`（H3）/"镜头缓慢匀速平滑横移"（happyhorse）实现，匀速机械感靠幅度速度修饰达成。90 度转场（直角甩镜）用两段生成+剪辑硬切实现。

## 通用适配规则

1. **导演风格 = 风格圣经扩展词条**：选用后，导演的"风格提示词"与 styles.md 基础风格圣经拼接使用（基础圣经在前，导演词条在后），整段冻结进 02_锚定表
2. **参数表指导分镜**：导演档案的"运动/节奏"行直接约束分镜设计（如侯孝贤项目全部固定机位、姜文项目允许手持+快切但仍按高风险降级表处理）
3. **冲突仲裁**：导演美学与核心规则冲突时（居中构图/切头构图/快速运镜），**点名该导演风格的项目按导演美学优先**，但 AI 技术限制类规则（高风险运镜降级/时长容量/动作终点）永远优先——美学可以让步，物理崩坏不能
4. 原资料中的"8K/超清"类词一律替换为具体质感词（胶片颗粒/材质纹理）
