## FACS 物理化表演引擎

### 核心原则

**只描述能被摄影机拍到的物理变化**：面部肌肉收缩/舒张、牵拉方向、位移幅度；骨骼与皮肤状态；五官位置；眼睛的完整物理状态（瞳孔直径、注视角度、眨眼、眼球运动）。

| ❌ 禁止 | ✅ 改用 |
| --- | --- |
| 主观情绪词（悲伤/委屈/感动/楚楚可怜） | 肌肉动作+瞳孔状态（"视线从远处慢慢落下，焦点短暂失去"） |
| 文学比喻（心如刀绞/眼神破碎） | 可拍摄的身体变化 |
| 内部感受（她想起了往事） | 外部表征（她的眨眼频率降低，视线固定在斜下方 30 度） |

**小肌肉群不许遗漏**：皱眉肌、降口角肌、颏肌、鼻肌、提上唇肌、眼轮匝肌——特写镜头的描述必须点到具体肌肉。
**不超解剖极限**（写实风格）：真人做不到的幅度不写（卡通/漫剧风格除外，风格化允许夸张）。

### 融合描述十要素（每个片段的角色描述必须覆盖，但以连续叙述呈现，不分条列举）

1. **剧情动作**：角色在做什么、肢体如何移动
2. **面部肌肉状态**：哪块肌肉收缩/舒张、牵拉方向、位移幅度
3. **眉眼状态**：眉毛位置变化、眼睑开合高度、**瞳孔直径变化**
4. **注视方向**：水平角度、垂直角度、注视目标、扫视模式
5. **口唇状态**：闭合/张开、嘴角方向、唇部厚度变化
6. **头部与颈部**：转动角度、俯仰角度、颈部肌肉张力
7. **双侧不对称性**：左右差异（真实表情几乎从不完全对称——一侧眉毛挑得更高、一侧嘴角压得更紧）
8. **对白同步**：有对白时"嘴唇在 X 和 O 的口型之间切换，同时保持 Y 的表情张力"
9. **微表情**：短于 0.5 秒的细微变化（一闪而过的皱眉、0.3s 的瞳孔收缩）
10. **张力维持期**：高强度表演时肌肉维持紧绷的时间（S≥6 必写）

### 表演强度分级 → 描述密度（强度决定写多细，不是写多夸张）

| 强度 | 密度 | 描述重点 |
| --- | --- | --- |
| S0-S2（平静/日常） | 简洁 | 眼神和嘴角的微小变化即可 |
| S3-S5（明显情绪） | 标准 | 覆盖主要肌肉动作、表情变化、眼神转移 |
| S6-S10（爆发/极致） | 极致 | 加入微表情、颤动、瞳孔剧烈变化、**肌肉张力维持细节** |

### 镜头距离 → 细节可见度联动（写了拍不到=浪费，该写的不写=空洞）

| 镜头距离 | 表情描述密度 | 重点 |
| --- | --- | --- |
| 远景/中景 | 偏概括 | 肢体动作与整体状态（**不要写眼神细节——拍不到**） |
| 近景 | 标准密度 | 主要面部肌肉 |
| 特写/大特写 | 极致密度 | 瞳孔直径、微表情、皮肤纹理 |

### 情绪节奏 → 摄像机参数（镜头语言必须与情绪同步）

| 情绪类型 | 焦段 | 运动 | 景深 | 机位 |
| --- | --- | --- | --- | --- |
| 平静/日常 | 标准焦段（35-50mm） | 固定或极缓慢推近 | 中等 | 平视 |
| 紧张/冲突 | 中长焦压缩空间（85mm+） | 手持轻微晃动 | 浅景深 f/1.8-2.8 | 平视或轻微俯仰 |
| 亲密/情感 | 中长焦特写 | 极缓慢推近 | 极浅景深 | 平视 |
| 动作/移动 | 广角或标准（24-35mm） | 跟移或环绕 | 中等 | 随动作 |
| 悬念/未知 | 长焦压缩 | 固定 | 焦点在关键物体上 | 局部特写 |
| **弱小/无助/脆弱** | 中长焦（压缩人与环境的空间关系） | 固定或缓慢抽离式拉远 | 中等到深（环境要可读——人被环境压住才成立） | **俯拍**（机位高向下） |
| **压迫/被压制** | 广角（贴近主体放大压迫感） | 缓慢下降（crane down） | 浅 | 俯拍或高角度 |

> 机位高度的心理含义**权威表在 cinematography.md「机位语义表」**（俯拍=人物弱小无助处境、仰拍=正面形象高大威严、荷兰角=混乱不安）——本表只补焦段/景深/运动三项，机位选型以那张表为准，不在此重复。

**情绪转折点 = 摄像机运动调整点**（片段内情绪发生转折时，运镜同步改变，如从固定转为推近）。

### 片段拆分规则（与模型时长上限联动）

- 单片段 **≤10 秒**（或按视频模型上限），**优先在情绪节点边界处拆分**——不在情绪中途切段
- **每个片段的起始状态必须与前一片段的结束状态完全一致**（与骨架 A 尾帧续接同构）
- 情绪转折词必须拆成独立节点；只有一句台词也至少推导 2 个节点（说话前状态 + 说话中/后状态）
- 角色超过 3 个：主要角色完整输出，其余只在关键节点写

### 输出格式（装进骨架 A 的镜头块）

每个片段的角色描述 = 一段连贯叙述（**不分条列举、不用表格**），按时间推进顺序组织句子，让模型理解表情的连续变化过程：

```
【摄像机】焦段 {85mm中长焦}｜角度 {平视/俯视15°/过肩}｜运动 {固定/缓慢推近/手持轻微晃动}｜
景深 {浅景深 f/1.8 背景虚化}｜构图 {三分法，人物在右1/3}｜焦点 {锁定A / 从A到B}
【角色A】{从本片段起始表情状态开始，按时间顺序叙述：面部肌肉变化→眉毛动作→眼睑开合→
瞳孔直径变化→注视方向转移→嘴角动作→头部转动→肩颈动作，自然融入剧情动作与对白。
密度按表演强度调节，全部用词客观物理化，零情绪词}
【角色B】{同上——多角色场景不许只写一个角色}
```

**范例（物理化改写前后）**：
- ❌ 词条原文："红眼忍泪——眼眶泛红，泪光打转，努力不让眼泪掉下，满是难过却仍在坚持"
- ✅ 物理化（S6，特写）："眼眶下缘与内眼角区域毛细血管扩张泛红，下眼睑眼轮匝肌持续收缩使睑裂变窄，泪液在下眼睑缘积聚形成反光层但未溢出；皱眉肌向内下方牵拉使眉内侧端抬高、眉间出现两道竖向浅纹；降口角肌轻微收缩使嘴角向下压约 3 毫米，颏肌出现两次短促颤动；视线固定在斜下方约 20 度，眨眼频率降低到每 4 秒一次，每次眨眼时上眼睑缓慢下落；呼吸停顿约 0.8 秒后出现一次较深的吸气，鼻翼轻微起伏；左侧眉尾比右侧低约 2 毫米（不对称）。"

### 全局禁令（反提示词体系）

- 不用任何主观情绪词，一律用肌肉动作与瞳孔状态替代
- 不遗漏小肌肉群；不超解剖极限（写实风格）
- 不因模型的文学倾向加入修辞手法
- 不用分条列举/表格呈现角色表演描述（必须连贯叙述）
- 不输出无法视觉呈现的内部感受
- 不忽略镜头距离对细节可见度的影响
- 有对白场景不让表情肌肉描述覆盖口型需求
- 不把眼睛仅当面部肌肉群之一——必须单独描述瞳孔、注视方向、眨眼
- 不用主观词描述眼神
- 不遗漏对白潜台词推导（掩饰性台词"我没事""随便你"必须推导真实情绪并写成物理表征）
- 多角色场景不只写一个角色
- 不省略片段之间的衔接说明

## 微表情表演五步法（引擎的日常简化版）

创作面部微表情的重点**不是叠加情绪词**（"悲伤、委屈、感动"），而是把情绪拆解成具体、连贯的表演变化：

1. **先设计情绪变化线**：不让人物从头到尾同一表情。设定清晰过程——从哪开始、在哪个动作转折、最终停在哪。例：平静开始→想到某事短暂停顿→试着露出笑意→笑容慢慢消失→眼眶湿润
2. **情绪词转面部动作**："眼神悲伤"（抽象）→"视线从远处慢慢落下，焦点短暂失去"（可拍摄）；"忍住眼泪"→"轻轻抿唇，呼吸停顿一下，缓慢眨眼，眼眶逐渐泛起泪光"
3. **动作有先后和节奏**：眼神先变→嘴角随后放松→呼吸轻微停顿。用"逐渐/短暂停留/缓慢消退"帮助过渡。**不要**眼睛眉毛嘴角同时大幅变化，不要每秒都加新动作
4. **控制表演幅度**：面部特写里细小变化已足够清楚——"嘴角轻微扬起后自然松开、眼睑略微收紧、眼角逐渐湿润"。幅度过大=夸张表演；肌肉细节过多=画面重点分散（**密度按表演强度分级，见引擎**）
5. **结尾要有铺垫**：流泪不直接写"开始哭泣"，按"情绪压住→眼眶湿润→泪水积聚→一滴眼泪滑落→表情恢复平静"逐步安排；镜头在情绪变化后缓慢推进，泪水落下后短暂停留收束

**写完检查三点**：情绪线是否明确 / 表情动作是否具体 / 前后变化是否连贯。

> 与核心规则的关系：五步法即"动作三段式"在面部表演上的展开——每条表情词条在视频提示词中应拆为 起始状态→渐变过程（含节奏词）→终点状态；每镜只选一个主要心理变化（对应容量规则）。**特写/大特写镜头走 FACS 引擎全量密度；中远景用五步法即可。**

## 身体姿态库（无力的全身序列——面部词条库补不上的维度）

> **为什么需要本节**：上方 95 条表情词条**全部是面部**（眼神/嘴角/眉毛/眼眶），没有一条涉及身体姿态。但"弱小/无助/无力"这类情绪**主要靠身体承载**，脸只是配角——缩肩、弓身、护要害、脱力瘫软，这些拍不到就等于没演。
> **本节全部为 `[成品样例]`**：逐字摘自用户提供的成品提示词，标注出处文件与行号，可直接改写复用。**不掺无出处的归纳分类。**
> **用法**：先按方法层选强度档（S0-S10），再从本节取身体序列，与面部词条合并成一条连续叙述（不分条列举——方法层十要素要求）。

### 一、无力 / 力气耗尽（全身递进序列）

**范本 A：负重前行式无力** `[成品样例: other10.md:1316-1327]`
> 她已经没有力气正常直立行走。上身明显弓着。肩膀向前缩。她把襁褓完全藏在胸口和下巴之间，用自己的头、肩膀和身体挡住迎面暴雨。撑伞的手已经因为刚才掉伞而空着。这只空出来的手不再摆动，而是时不时抓住桥边竹杆帮助保持平衡。每走一步都会先探脚，再迅速把另一只脚跟上。她喘得非常厉害。几次张嘴大口吸气。脚下打滑时会本能缩肩，把孩子抱得更紧。她的目光始终锁在前方岸边。已经顾不上回头。

**可复用结构（五件）**：①能力状态声明先行（"已经没有力气正常直立行走"）②躯干形变（弓身/缩肩）③护住要害物（藏在胸口与下巴之间）④步态退化（先探脚再跟上、需扶物保持平衡）⑤呼吸外化（喘得厉害、张嘴大口吸气）

**范本 B：濒死式力量消失（最极端的无力分解）** `[成品样例: other10.md:1622-1633]`
> 她已经没有刚才猛烈挣扎的力量。眼睛半睁半闭。视线完全失焦。面部因为严重缺氧出现不受控制的轻微抽搐。嘴唇颤动。下颌偶尔短促抽动。她还想本能吸气，却只能从嘴里吐出一串越来越少的气泡。胸口出现最后几次无效的呼吸动作。一只手缓慢向上抬了一点。没有力量继续。最终手臂重新垂下。身体继续向深处沉去。

配套纪律句 `[other10.md:1643]`：「要表现真实的严重缺氧、意识模糊、力量快速消失。」

**可复用结构**：**意图→失败的落差**是本条的核心（"还想本能吸气，却只能吐出越来越少的气泡"、"抬了一点。没有力量继续。最终手臂重新垂下"）——写"想做什么但做不到"比写"虚弱"强得多。

**范本 C：脱力后的松懈 + 强撑安慰** `[成品样例: other10.md:1429-1435]`
> 她先一只手撑在自己的膝盖上。另一只手紧抱孩子。连续喘几口粗气。胸口起伏明显。然后直起一点身体。用手背快速擦掉脸上的雨水。动作很粗，不是整理妆容。

末句「动作很粗，不是整理妆容」是**表演注（不是X而是Y）**的典型用法——机制见 prompt-rules.md 骨架A 表演注节，本处只是样例。

### 二、慌乱中的强撑（受限移动 + 重心不稳）

`[成品样例: other10.md:1371-1382]`
> 少妇此时进入近乎冲刺状态。但因为桥体猛烈晃动，她不能真正奔跑。她会连续快走两三步。桥突然一晃。她立即停半步稳住重心。空着的一只手快速伸向桥边抓一下竹杆。稳住后马上继续。她的脚步越来越急。上半身始终包住孩子。头越来越低。下巴几乎贴着襁褓。她不再看水面，只盯着前方泥岸。

**可复用结构**：**"想X但不能X"**（进入近乎冲刺状态 / 不能真正奔跑）+ 被打断的节奏（走三步→一晃→停半步→抓扶→继续）+ 视线收窄（不再看水面，只盯着前方）——慌乱感来自节奏被打断，不是来自写"很慌乱"。

> 上胸出现一次很小的吸气尝试；呼吸在中途短促卡住；眉间只出现轻微而瞬时的收紧；下颌和颈侧肌肉略微绷紧；手指在大腿上骤然蜷紧，压住裤料；手掌仍停留在大腿上，不抬起，不抓扶手。
> 肩线只有极小幅度的紧张；目光仍朝前方，却开始难以重新聚焦；手指继续压住裤料，但不进一步用力；嘴唇可以极轻微分开一次，不能张大；不发声。

**可复用结构（强撑的三层）**：①**表面层**声明平静/面无表情/故作镇定 ②**泄露层**给 1-3 处微小生理证据（鱼尾纹、喉结滚动、手指蜷紧、肩线极小幅度紧张）③**限度层**明确"不做什么"（不抬起、不抓扶手、不能张大、不发声）——泄露要小到"观众看得见但剧中人假装没有"。

> **力度分级词库**（从范本提炼，全部有原文出处）：`极小幅度` / `轻微而瞬时` / `略微绷紧` / `一点点收紧` / `骤然蜷紧` / `看似紧抿实则极力压抑`。强度档对照见本文件"表演强度分级"节。

**使用纪律**：
1. **生理反应是加分项不是承重墙**——一场戏选 1-2 处最关键的，不全堆（对照 prompt-rules.md 校验「Restraint Test」精神）
2. **要有因果**：粟粒因"羞愤与应激本能"、颤抖因"肾上腺素还没退"——写出成因，不是凭空长反应（联动 emotion-craft.md 第二节"光线因果"同源逻辑）
3. **镜头距离决定能不能写**：粟粒、鱼尾纹、喉结这类只在**近景/特写**可见；全景里写粟粒=拍不到（见本文件"镜头距离→细节可见度联动"节）
4. **面部与身体要配**：生理反应多发生在躯干（胸膛、肩、手），与上方身体姿态库合并使用，不要只写脸

## 情绪反向索引（查表失败时的入口）

> **解决什么**：剧本不会写"表现弱小无助"这种关键词，只写**行为**。本表是"行为 → 情绪 → 去哪找写法"的反向入口，避免执行者因"对照表里没有这个情绪名"而卡住。

| 剧本里的行为证据 | 可推的情绪 | 去哪找写法 |
| --- | --- | --- |
| 退到墙角 / 被围住 / 无处可逃 | 弱小、被压制 | 身体姿态库一 + 摄像机档"压迫" |
| 说了三次"我没事"但手在抖 | 强撑、故作镇定 | 身体姿态库四（微泄露三层） |
| 别人都站着，只有他坐着/跪着 | 弱势、卑微 | ⚠ 姿态写法缺（见覆盖边界表）；机位用俯拍（cinematography 机位语义表） |
| 镜头外传来脚步声，他抬头四下看 | 失控、惊慌 | 身体姿态库二 + 生理反应库（呼吸/喉结） |
| 低着头不说话 | **歧义**——无助 / 隐忍 / 蓄谋 / 冷漠 | **不选定**，按 screenwriting-craft.md 一·七节列入待决问题问用户 |
| 全程不动、不哭、不抱紧 | 受惊静止、创伤性麻木 | 身体姿态库三 |
| 抬了一下手又垂下 | 无力、放弃 | 身体姿态库一（范本B 意图→失败落差） |

**三条纪律**（本表的使用边界）：
1. **有行为证据才推**——推断必须写明支撑它的剧本原文（screenwriting-craft.md 一·七节 Interpretations 层要求）
2. **歧义不替用户选**——同一行为能推出两种以上情绪时，保留歧义并列入 GATE1.5 待决问题，**禁止自行脑补**（SKILL.md GATE0 对齐义务）
3. **表里没有的行为，不硬套**——回到方法层五步法，从"这个情绪在身体上会造成什么不可控的变化"重新推，并把结果标 `[待验证]` 交用户实测
