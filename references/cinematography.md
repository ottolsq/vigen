# 运镜 · 转场 · 景别 · 光影知识库

> 设计分镜时读本文件。目标：运镜不重复、转场有设计、景别有节奏、光影有依据——用专业判断让画面"像电影"，且避开 AI 视频的崩坏区。
> **效果库不许落灰（SKILL.md 硬规则 11，别按编号查——17 条要点+指针表）**：本库 40 种运镜 + 8 种生成端转场 + 5 种剪辑端转场 + 张力四法，按剧情需要主动选用。**判据见一节"运镜多样性判据"：运镜选择与场景语义脱节才叫呆板，不是"种类数少"就叫呆板**——对话戏全程固定+硬切是合规的。01 校验记录里有自检项。
> **不因怕翻车砍表现力**：生成难度是走可生成性改写阶梯（prompt-rules.md 0.7）的触发器，不是回避表现力的理由；强调手段（慢镜/冲击重复/短促推近/定格/闪白）是稀缺品，只花在已点名峰值上（见「峰值与强调手段」节）；降级只作生成失败后的回退兜底（SKILL.md 回退阶梯），不预先降级、不在 GATE1 二选一。

## 运镜功能决策表（先查此表定功能，再进运镜库选具体写法）

[drama-skills: shot-craft.md#SHT-04]

每镜的「运镜」按**本镜在做什么**选，不按情绪词选（情绪命名模糊，功能判据可判定）。先问这一镜里观众的注意要不要移动、往哪里移，从上往下对照，命中第一行即停：

| 行号 | 本镜在做什么 | 运镜 |
|---|---|---|
| R1 | 人物移动本身是这一镜的事：冲、追、逼近、爬上高处 | 跟拍或横移，让他在画面里的位置保持住 |
| R2 | 新信息从画外或画面一侧进来 | 摇、俯仰或后拉，停在新信息上 |
| R3 | 一句台词或一个认识正压到某人身上（对白镜里说话者与听者都算） | 缓推或前移，停在承受者的脸或手上；拉开则是关系变远 |
| R4 | 两人的关系或处境在原地被重新评估：绕过去才看得到的另一面、被围住 | 环绕 |
| R5 | 高度本身有意义：升起交出全局或结局，落下把观众接进人物所在的高度 | 升降；不为"开场要大气"而升降 |
| R6 | 情绪爆发、重大反转 | 短促推近；定格、闪白最终效果由剪辑完成，本镜写触发画面并注明落在哪一拍（04 若出现"闪白"字样须带峰值标注） |
| R7 | 观察、等待、紧张、仪式、受困；插入镜；对白镜里这句台词不带来压力或处境变化 | 固定 |

**三条咬人条款**：

- **固定（R7）是这张表的最后一行，不是起点**：前面几行都不成立时才固定
- **只写「运镜：固定」说不出是上表哪一行，等于没有选**——写法强制为「运镜：<行为>，<从什么时候开始、停在哪里>；<为什么>」，固定写「运镜：固定；<为什么>」
- 运镜行空着，动不动就改由视频提示词阶段替你选（长出一个没人要过的推近或环绕）

例句（逐字）：`运镜：缓推，他说出『这单我接了』时开始，停在眼睛；这是他第一次把赌注压在自己身上`｜`运镜：固定；插入镜只要看清数字`｜`运镜：固定；这句话没有落到谁身上`。

> **口诀的输入是情绪词（模糊），决策表的输入是本镜功能（可判定）——先功能（R1-R7）后情绪**。下面的"情绪映射口诀"是选定功能行后、在运镜库里挑具体写法时的二次参考，不是选择入口。运镜动机写进 01 分镜表须符合 CT1 格式（`五类词(R行号)：一句展开`，见 prompt-rules 校验 A12）。

### 运镜动机五类封闭词表（01 分镜表"运镜动机"列专用）

[drama-skills: camera-audio-continuity.md#L22-28]

摄影机行为必须回答"观众注意为什么在此刻改变"，动机归为五类——**封闭词表，自由文本动机（"氛围需要""更有电影感"）不过 A12**：

| 动机词 | 含义 |
| --- | --- |
| reveal | 新信息进视野（对应决策表 R2） |
| pressure | 距离收紧、压力增大（R3/R6） |
| alignment | 从旁观转向贴近某角色立场（R3/R4） |
| relationship | 重组两人距离与权力（R4/R5） |
| transition | 把注意交给终点/收束（R1/R7） |

**CT1 格式**：`<五类词>(R<行号>)：<一句展开>`

示例：`pressure(R3)：台词正压到她身上，缓推停在她脸上`｜`reveal(R2)：门开处新人物入画，摇过去停在门口`｜`transition(R7)：交锋已尽，固定让她说完`。

## 一、运镜库（40 种 = 基础 20 + 扩展 20）

使用规则：**贴合场景优先，多样其次**（用户实测裁定：运镜不是越多越好，是每处都要服务于该镜的叙事功能）。选择依据=情绪效果（见情绪映射），每个运镜的英文表达可直接嵌入提示词。

> **运镜多样性判据（可判定口径——已由功能决策表 + A12 条件触发门接管）**：
> - 选择入口是上面的**功能决策表 R1-R7**（每镜写"在做什么"→命中行号）；判"单调/呆板"的标准是**运镜与本镜功能脱节**——某镜的运镜没有服务该镜的叙事功能（移动/揭示/压力/关系/峰值），只是机械重复
> - **对话戏正反打全程固定机位 + 硬切 = 合规**（R7 的正当情形；固定族单列为 1 族，占比最高但合理）——但每镜仍须写 (R7) 与理由，"说不出是哪一行=没有选"
> - **该用运动运镜表达张力却用固定 = 违规**：剧本有奔跑/追逐→跟拍族（R1）必须出现；有信息揭示→摇/后拉族（R2）；有【峰】→强调手段（R6）。条件触发回读见 prompt-rules 校验 A12
> - 计数口径（辅助自检，非判据）：按"族"归并，同族算 1 种记次数；同一运镜连用 3 次**且三处功能行号相同**才判模板感，行号不同（一镜 R1 定场、一镜 R3 反应、一镜 R7 收束）不算

| 运镜 | 英文表达 | 大白话 | 情绪效果 | 经典案例 |
| --- | --- | --- | --- | --- |
| 推 | camera pushes in / dolly in | 镜头整体凑近 | 聚焦、紧张渐强、"此刻重要" | 《小丑》 |
| 拉 | camera pulls back / dolly out | 镜头整体退远 | 孤独、抽离、收尾余韵 | — |
| 希区柯克变焦 | dolly zoom / vertigo effect | 后退同时变焦推近，背景被拉伸 | 眩晕、现实扭曲、重大心理冲击 | 《迷魂记》《大白鲨》 |
| 摇 | pan left/right | 机位不动转头 | 快摇=活力；慢摇=悬念；突摇=意外 | 《慕尼黑》 |
| 横移 | tracking / trucking shot | 与主体并排走 | 沉浸、生活质感、消化情绪 | 《老男孩》 |
| 跟 | camera follows behind the subject | 跟在主体后/侧 | 行动沉浸、空间连续 | 《好家伙》一镜 |

| 手持 | handheld camera, natural shake | 肩扛自然晃动 | 纪实真实感、混乱、亲密 | 现代动作片 |

| 长镜头 | one continuous take, no cuts, seamless shot | 一镜到底 | 沉浸无中断、时间真实 | 《赎罪》敦刻尔克 |

| 变焦点 | rack focus from A to B | 焦点从A移到B | 无剪辑的信息转移、埋伏笔 | — |

### 扩展运镜（提示词写法直接可用）

| 运镜 | 提示词写法 | 情绪效果 |
| --- | --- | --- |
| 呼吸感微推 | 镜头以极慢的速度向前微微推进，幅度很小，几乎难以察觉，像人在不自觉地屏息靠近 | 悄悄进入内心、凝视感 |
| 急推/撞击推 | 镜头在极短时间内猛然推近到主体面部，速度极快，带强烈冲击 | 惊吓、强调、喜剧重拍 |
| 急拉揭示 | 镜头从特写瞬间拉远到全景，快速揭示主体所处的真实环境 | 反转、处境揭示 |
| 前景遮挡揭示 | 镜头缓慢横移，让前景的遮挡物（门框、人影、树叶）滑开，露出后方的主体 | 悬念解开、窥视转呈现 |
| 摇镜落幅定人 | 镜头横向摇过去，最终稳稳停在某人或某物上并定住 | 指认、"就是他" |
| 前置倒退跟拍 | 镜头在主体前方一边后退一边拍摄，正对主体的表情和步伐 | 压迫式对视、情绪迎面而来 |
| 载具跟拍 | 镜头固定在车辆或载具上，随载具一起高速移动拍摄 | 速度感、公路片质感 |
| 螺旋上升环绕 | 镜头环绕主体的同时持续升高，形成螺旋上升的运动轨迹 | 升华、眩晕的浪漫 |
| 低角度贴地环绕 | 镜头贴近地面，以极低的角度围绕主体旋转 | 压迫、兽性视角 |
| FPV 穿越 | 镜头像穿越机一样高速飞行，穿过狭窄空间后豁然展开 | 空间揭示、游戏感 |
| 镜面反射视角 | 镜头不直接拍主体，而是拍摄镜面、水面或玻璃中的倒影 | 疏离、双重性、窥视 |
| 摇臂俯冲 | 镜头从高空快速俯冲下降，直奔地面的人物而去 | 命运降临、锁定目标 |
| 推近锁定 | 镜头快速推近到主体后猛然定住，画面瞬间稳定 | 决心、惊吓后凝固 |
| 螺旋推进 | 镜头一边旋转一边向前推进，形成螺旋钻入的运动轨迹 | 卷入感、失控 |
| 抽离式拉远 | 镜头持续拉远，主体在画面中越来越小，最终被环境完全吞没 | 孤独、渺小、宿命收尾 |
| 穿物转场（运镜式） | 镜头穿过某个物体表面（水面、镜面、屏幕、洞口），进入另一个空间 | 时空切换、梦境入口 |
| 电梯视角 | 镜头在狭小的垂直空间中随电梯一起上升或下降 | 密闭压迫、阶层隐喻 |
| 门缝窥视 | 镜头透过半开的门缝或窗框向室内拍摄，画面被边框强烈限制 | 偷窥、悬疑、限制信息 |
| 子弹时间 | 镜头围绕处于慢动作中的主体环绕，时间与运动形成强烈反差 | 高光时刻凝固 |
| 运动模糊慢门 | 画面带有明显的运动拖影和拖尾，像是慢门拍摄 | 时间流逝、迷离 |

**情绪映射口诀**：情绪上扬→推/升/环绕；情绪下坠→拉/降/慢摇；紧张→手持/快切；抒怀→固定+浅景深；史诗→航拍/大远景；幽默→急推变焦；转折→甩镜/变焦点；揭示→前景遮挡揭示/急拉揭示/FPV穿越；指认→摇镜落幅定人；宿命→抽离式拉远/摇臂俯冲。

### 物理参数级运镜例句（Seedance 2.5 成品标准——运镜五要素：起点锚/终点锚/高度/角度/同步对象）

> ✗ 动词级（模型自由发挥）："环绕镜头"、"贴地跟拍"
> ✓ 参数级（没有发挥空间）：以下 13 条直接可用（源自 other5 成品资料）：

| 运镜 | 物理参数级写法 | 功能（大白话） |
| --- | --- | --- |
| 贴地跟随 | 低机位斯坦尼康贴地侧跟，**高度距离地面10-15厘米**，保持**与脚步同步**侧向平移 | 速度感贴脸，脚步就是节奏器 |
| 环绕上升 | 镜头**从左脚边**向身后画面右侧**180度环绕并上升**，**经过人物背面、右面、斜前方，升到腰胸高度**转到正面中景 | 一镜交代全角度，落在正面=指认 |
| 反跟 | 摄影机**在两人前方倒退跟拍**，人物保持朝向镜头，**与镜头同步后退，不切、不变焦、不摇空** | 压迫式对视，情绪迎面而来 |
| 下摇 | 画面开始是高杆上被风吹动的布旗，人物从画面右侧走进来，镜头缓缓向下摇，**停在客栈门口** | 先交代环境再带出人物 |
| 背后跟拍 | 从背后拍她，她掀开布帘跨进门不停步往里走，镜头**跟在她身后三步远**，一起进屋 | 观众跟她一起走进去（代入） |
| 横摇 | 从门口看向大堂，镜头**从左向右匀速横摇，扫过一桌桌客人，停在最里面的角落** | 像人转头看一圈，屋里有谁一目了然 |
| 快速变焦 | 镜头位置不动，用快速变焦，**一秒之内**画面猛地放大，**停在他的脸部近景** | 一秒推到脸上（邵氏式惊吓/强调） |
| 缓推 | 镜头从中景**缓缓推到近景，只推近一点点，慢到几乎察觉不到** | 情绪一点点压上来 |
| 固定 | 侧面全景，固定镜头，完全不动，**两人一左一右隔着大堂对视** | 看清两人谁在哪 |
| 半圈环绕 | 镜头**从A背后出发，沿弧线绕到两人侧面，停在B背后** | 交代对峙关系 |
| 手持跟拍 | 手持摄影，镜头**跟着两人的动作左右晃动、追着人跑** | 打斗临场感 |
| 甩镜 | 一剑刺出，镜头**快速向右甩**，画面糊成横向拖影，**停在对手格挡的画面** | 节奏瞬间加快 |
| 升镜俯拍 | 镜头**从腰部高度向上升，变成从屋顶往下看的俯拍**，两人在画面中央变小 | 交代结局，人一下就变小了（宿命感） |
| 后拉 | 镜头**在人物身后一路向后退，画面越来越宽**，她的背影越走越小 | 故事收尾（抽离） |

| 虫视 | 贴近地面上仰 | 人物夸张强势 |
| 仰拍 | 机位低向上 | 正面形象、高大威严、决绝 |
| 平拍 | 人眼高度 | 中立、真实、岁月静好 |
| 俯拍 | 机位高向下 | 人物弱小、无助、处境 |
| 鸟瞰 | 垂直高空 | 宏大环境、命运感 |
| 荷兰角 | 画面倾斜 | 混乱、不安 |

**机位数值化（硬要求——方向性词只做辅助）**：提示词里的机位必须写到**角度/高度/方向**三要素可执行，不许只留方向性形容词（实测教训："微仰拍"没量化导致返工两轮重新明确；"平视"第一版被模型画成仰视）。写法对照：

| 只写方向词（✗ 会被模型随机取值） | 数值化写法（✓） |
| --- | --- |
| 微仰拍 | 机位低于人物胸口高度，镜头向上倾约 10-15° |
| 平视 | 机位与人物眼睛同高，镜头水平 0°（不俯不仰） |
| 俯拍 | 机位高于人物头顶约 1 米，镜头向下倾约 30° |
| 过肩 | 机位在{角色A}左肩后约半米，越过肩线拍{角色B}正面，肩线占画面右下约 1/5 |

**用户口语歧义清单（转写提示词前必须先消歧——实测三例返工）**：用户的口头机位词与专业语义常不一致，**拿不准就用一句话复述你理解的构图让用户确认**（低成本，远低于生成后返工）：

| 用户口语 | 常见歧义 | 消歧问法/默认裁决 |
| --- | --- | --- |
| "正脸" | 全脸（正面全部五官）还是脸部正面特写（头占画面 6 成）？ | 复述："我理解是正面近景、头占画面约六成、五官完整可见——对吗？" |
| "侧面" | 全侧（90°）还是四分之三侧（45°）？ | 默认四分之三侧（全侧会丢表情信息），有疑复述确认 |
| "仰拍/俯拍" | 角度不明（10° 微仰和 45° 大仰是两个画面） | 必给角度数，参照上表 |
| "扫视/环视" | 扫视路径与终点不明 | 写"从{起点}扫到{终点}，停在{落点}"，参照运镜五要素 |
| "拉远/推近" | 起终点景别不明 | 写"从{起始景别}推到{终止景别}"，如"从中景推到近景" |

## 二·零、转场库（生成端 8 种 + 剪辑端 5 种——01 分镜表"转场"列强制选型）

> 每种转场 = 生成端写法（写进视频提示词）+ 剪辑端手法（写进 06）+ 适用剧情时机。选择依据 = 前后镜头的视觉/动作/逻辑关系，不是随机配。

| 转场 | 生成端写法 | 剪辑端手法 | 适用时机 |
| --- | --- | --- | --- |
| 硬切 HARD CUT | 镜头块之间直接标 HARD CUT | 无处理直接拼接 | 默认；对话正反打、节奏推进 |
| 相似动作转场 | 上一镜动作进行到一半收尾（抬脚/挥手/转身），下一镜从对应动作的另一半开始（落脚/挥手落定/转身完成），前后姿态、方向、幅度、主体大小和画面位置对应 | 在动作进行到一半时切，删掉起步前和结束后的停顿 | 换装、换景、时间流逝但动作连续 |
| 前景遮挡转场 | 让前景物体（书本/衣摆/路人/墙柱/披帛）贴近镜头完全遮满画面，遮挡瞬间收束 | 在画面完全被挡时切换；遮挡物沿原方向继续移出，速度动作连贯 | 场景切换的丝滑伪装；结尾"披帛扫镜遮满画面"式收束 |
| 形状匹配转场 | 前后两镜主体轮廓/大小/位置/朝向尽量对应（红灯笼接伞面、书本接窗户） | 找到共同视觉元素→对齐位置大小方向→在最相似的一帧切换→可配合音乐节拍 | 意象关联、诗意的段落衔接 |
| 甩镜转场 | 前后镜头向同一方向快速甩动，速度接近 | 在运动模糊最强处切，必要时补少量方向模糊+呼啸音效盖切点 | 时空切换、喜剧节奏、能量爆发 |
| 闪白转场 | 让场景中的强光迅速将画面照至全白，全白时收束 | 下一镜从同样全白开始逐渐恢复曝光；全白短暂、不频闪 | 高光时刻/强冲击的回忆入口（普通回忆入口用叠化） |
| 视线衔接（视觉转场） | 上一镜人物先看向某处（视线方向明确），下一镜展示所看内容或对方的回应 | 在转头接近完成、视线落定时切，下一镜迅速呈现视觉重点 | "她在看什么"的信息传递；对话反应 |
| 匹配剪辑 MATCH CUT | 前后镜构图/动作/主题精确对应（上台阶动作接室内推进） | 对应帧对齐切换 | 空间跨越、命运呼应 |

**转场选型口诀**：动作连续用相似动作；空间跨越用遮挡/穿物；意象关联用形状匹配；能量爆发用甩镜；回忆梦境用闪白；信息传递用视线衔接；默认硬切。转场同样**贴合场景优先，多样其次**——对话正反打全程硬切是合规（硬切就是对话戏的语义），但动作戏/情绪爆点该用甩镜/匹配剪辑表达冲击却用硬切，才是"转场没设计"。判据见一节"运镜多样性判据"。

**转场分两类（口径必须先定，防把后期效果写进生成端）**：
- **生成端转场**（上表 8 种）：04 视频提示词里可写前后镜动作/构图对应的拍法，模型能靠镜头内容实现。
- **剪辑端转场**（下表 5 种）：AI 模型不生成叠化/淡入淡出/缩放这类后期效果——01 分镜表可选，**04 在该切点按硬切写（或写"直接切换"），06 用剪映实现；逐切点映射，不影响同段其他生成端转场**。把"叠化"写进 04 = 模型自由发挥，必翻车。

**剪辑端转场补充菜单（只写进 06 实现；04 该切点写硬切）**

| 转场 | 剪映实现 | 适用时机 | 情绪作用 |
| --- | --- | --- | --- |
| 叠化 Dissolve | 叠化转场 | 时间流逝、回忆闪回、情绪过渡、场景柔转 | 柔和、舒缓、伤感、梦幻 |
| 淡入淡出 Fade | 淡入/淡出 | 段落头尾、章节切换、重大时空跳转 | 正式、分隔、仪式感 |
| 闪黑 Flash to Black | 闪黑 | 重击、晕倒、记忆断点、系统触发 | 冲击、眩晕、瞬间切换 |
| 缩放 Zoom | 缩放转场 | 快节奏蒙太奇、爽点切换 | 动感、活力、短视频感 |
| 划像 Wipe | 线性擦除 | 老式回忆、分屏叙事、复古风格 | 复古、分隔感 |

**选用铁则**：同一集成片混用不超过 **3 种**转场；常规剧情硬切为主，情绪节点叠化，高光节点闪白。
**闪白/定格与 K5**：两者都属强调手段——04 写"闪白/定格"时 K5 会检查峰值标注，必须带 `←峰值：…`；只在 06 实现的同样不受机检但受本节纪律，只用于峰值/高光节点。非峰值的时间过渡用叠化（剪辑端）或硬切，不要用闪白。

**匹配剪辑五条黄金规则**（上表生成端转场的判定细则，不另立转场类型；生成端设计前后镜、剪辑端对齐切点都用）：
1. **动作匹配**：上一镜的动作方向/动势与下一镜连续——上镜人物向右转头，下镜接另一人向右转头。
2. **视线匹配**：上镜人物看向画面右侧，下镜所视物出现在画面右侧，空间逻辑不反。
3. **形状匹配**：圆形/方形/线条在前后镜相似衔接（车轮→钟表、眼睛→月亮）——即上表"形状匹配转场"。
4. **颜色匹配**：前后镜主色调一致，不冷暖硬跳；要跳色必须有叙事动机。
5. **声音匹配**：转场前后音效/台词连贯，**声音先于画面切入**（J-cut，见 06 音频层）。

## 二、AI 视频运镜避坑

> 强调手段与高难度运镜的管理走「峰值与强调手段」节——生成难度是走可生成性改写阶梯（prompt-rules 0.7）的触发器，不是回避表现力的理由；降级只作生成失败后的回退兜底（SKILL.md 回退阶梯），不预先降级、不在 GATE1 让用户二选一（裁定 R3）。

**通用规律（参数事实）**：运动越快、运镜越复合、时长越长，崩坏概率越高。一切复合运镜（dolly+zoom、orbit+push）拆成单运动。

**微幅二级调整合法（单运动规则的边界，other7 成品实证）**：主运镜之上允许一个**幅度小到不产生第二个视觉运动主体**的二级调整——"边退边微微上抬"（主=倒退跟拍，二级=镜头轻微上抬）、"急推后骤停锁定"（主=推，二级=停）、"固定机位+极微幅下移"。判据：二级调整能否用"微微/极微幅/随后停住"描述且不改变画面主体关系——能=合法，不能（边推边变焦/边环绕边升降=双主运动）→ 拆段。

**高难度运镜的写法与崩坏点（避坑知识，非"预先降级二选一"）**：下表"理想写法"就是主方案（要什么写什么，生成难度不改戏剧结果）；"崩坏点"是它为什么难生成——难生成时走 prompt-rules 0.7 改写阶梯改**实现方式**，只有真实生成失败后才走 SKILL.md 回退阶梯。

| 高难度运镜 | 理想写法（主方案） | 崩坏点（为什么要改写阶梯） |
| --- | --- | --- |
| dolly zoom | 镜头向前推进的同时反向变焦，主体大小不变背景急剧拉伸 | 双主运动+变焦，模型难同时保持主体大小恒定 |
| 360° 环绕 | 镜头围绕主体匀速平稳环绕360度，依次拍到侧脸、背影、另一侧脸颊 | 长弧环绕易在背面丢失人物一致性 |
| 长距离跟拍 | 一镜到底跟拍全程 | 超时长易漂；改写阶梯②拆到相邻镜+尾帧续接 |
| 高速甩镜 | 极速横甩带强烈运动模糊，落幅锁定新主体 | 落幅主体易糊/错位 |
| crash zoom | 极短时间猛然推近，带强烈冲击 | 猛推易畸变；属强调手段，只花在峰值（R6） |
| 手持+快动作 | handheld camera, natural shake + 完整动作 | 抖动+动作双重高频，易糊 |
| snorricam | 机绑身上背景飞转 | 背景飞转与人物一致性冲突 |

## 二·五、运动运镜的平滑规则（V1.4 实测反馈新增）

**问题**：含运动的运镜（推/拉/移/跟/环绕）在 AI 视频中容易画面抖动——模型逐帧重渲染相机位置时引入帧间高频抖动（真实摄影机有物理惯性+稳定器，AI 没有惯性概念，每帧位置都是独立采样）。

**三层防御（写提示词时全用）**：

1. **运镜限定词**：任何运动运镜必须带"缓慢/缓慢匀速"限定，且补平滑锚定词——中文"镜头缓慢匀速平滑移动"，英文 `slow smooth dolly movement` / `smooth gimbal-like motion`。禁止裸写"推近/拉远/横移"（无速度词=模型随机选速度，常选快=抖）
2. **运镜短语模板**（i2v 运镜槽直接用）：
   - 推：`镜头缓慢匀速平滑推近（slow smooth dolly in）`
   - 拉：`镜头缓慢匀速平滑拉远（slow smooth dolly out）`
   - 横移：`镜头缓慢匀速平滑横移（slow smooth tracking shot）`
   - 跟拍：`镜头如稳定器般平滑跟随（smooth steadicam follow）`
   - 环绕：`镜头以缓慢平滑的弧线环绕（slow smooth arc）`
3. **单运动叠加约束**：运镜与主体运动**不要同时高速**——双重高速=双重抖动源叠加。镜头动则主体动作放缓（或静止）；主体高速运动则镜头运动让位或降速+平滑参数（本节三层防御）。**"让位"指降低镜头运动幅度/速度，不等于"选固定机位"**——选哪种运镜仍由功能决策表（R1-R7）定，固定是最后一行不是避风港

**剪辑兜底**（写进 06 剪辑清单）：素材仍抖时——剪映"视频防抖"（推荐档位）；或该段降速 80-90%（慢速掩盖抖动）；最狠的是整段套轻微放大裁切（1.05-1.1x）+ 稳定。

**分镜层面的抖动控制**：抖动敏感的场景（特写、人脸、文字画面）里，运动运镜的抖动视觉权重高——若功能决策表（R1-R7）在本镜选中了运动运镜，按本节三层防御写平滑参数+收紧运动幅度，或让主体微动承担画面变化；**不是"这类场景一律选固定"**——固定仍须是决策表 R7 的结果，抖动只是收紧运动幅度的理由，不是回避运动的理由。运动幅度大的运镜在中远景视觉权重低，可按决策表正常使用。

**防 AI 乱切镜**：提示词加 `Continuous, seamless shot`（或中文"一镜到底无切换"）；要完全静止加 `The locked-off camera remains perfectly still`。

## 三、景别表（避免连续 3 个同景别）

> **正反打豁免条款**：对话戏正反打成对出现（连续 2 个同景别过肩/近景）是惯例而非违规——"避免连续 3 个同景别"从正反打对之后的下一镜算起（正打+反打+第三镜换景别即合规）。**景别口径**：过肩（OTS）与近景（CU）在景别表中是两个景别，正反打通常就是"过肩↔过肩"或"过肩↔近景"成对——判"连续同景别"时按景别表原名判，不把过肩和近景混为一谈。
> **正反打配对四条** [drama-skills: blocking-playbooks.md#L124-133]：①**屏幕方向必须互补**——A 镜甲在画左看画右，B 镜乙就必须在画右看画左；两镜都望同侧，观众读成两人在看第三个画外者 ②**视线高度按实际身高差匹配**——A 俯 B 仰要对应；双平视抹平身高差，"逼近"就失去压迫感 ③过肩镜写明**前景是谁的肩、占画多少**（肩的归属决定这镜属于谁的视角）④**A/B 对称是主动选择**——对称=势均力敌，不对称=权力倾斜；选了不对称要写理由。与 prompt-rules"正反打画面占位"衔接：占位管单人怎么摆，本四条管两人怎么配对。
> **破节奏是软建议不是硬门**：正反打超过 2 对连续不切景别时，**建议**中间插反应镜头/道具特写/空镜破节奏（防视觉疲劳），但不插不判违规——30s 短对话戏全程 4 对正反打是正常的。此条不阻塞交付。

| 中文 | 英文 | 用途 |
| --- | --- | --- |
| 大远景 | extreme wide shot (EWS) | 定场、史诗、孤独 |
| 远景 | wide shot (WS) | 环境+人物关系、开场 |
| 全景 | full shot (FS) | 全身+动作/舞蹈 |
| 中全景 | cowboy shot | 膝上、对峙感、身体动作 |
| 中景 | medium shot (MS) | 腰上、对话默认 |
| 中近景 | medium close-up (MCU) | 胸上、情绪与语言并重 |
| 近景 | close-up (CU) | 颈肩上、情绪主体 |
| 大特写 | extreme close-up (ECU) | 眼/嘴/手局部、最大冲击 |
| 过肩 | over-the-shoulder (OTS) | 对话正反打 |
| 定场 | establishing shot | 交代时间地点 |

**景深默认**：特写/近景=浅景深（奶油散景隔离主体）；全景/远景=深焦（多层信息）。

**景别节奏**：宽→窄→宽的呼吸感；开场可用"景别跳跃"抓人（大远景直切大特写）。

### 三·五、对白场默认切法

[drama-skills: shot-craft.md#SHT-29]

对话戏镜头单调的最大单一原因是"两人干讲"（screenwriting-craft 漏洞 7 的镜头层）。默认切法六条：

- **一句台词一个镜头**：说话者的镜头承载这一句；一句话里有转折时，可以在转折处切
- **默认给听者**：重要的一句落下时，**切到听的人**，让观众看见它打中了谁（承受者反应，见「峰值与强调手段」节⑥）
- **来回交锋用正反打**：两人交锋保持摄影机在同一轴线工作侧，对切相向的说话者与听者，过肩或单人都可以
- **景别顺序**：先给一个带着人物和动作的**交代镜**，对话落到**中景/中近景**，**特写只给要落地的那句台词**（不是每句情绪台词都上大特写——"情绪升级=景别收紧"是条件反射病）
- **删空镜**：既没有台词也没有动作的镜头删掉
- **插入镜是便宜的节奏工具**：手机屏幕、手、戒指、证件这类插入镜不需要表演，可以插在长台词或等待中间，也可以把一句话拆开

这是起步默认。一场戏有意用不切的双人镜施压、或让群像同时反应更清楚时，说明理由即可改（与三·六工作景别配合）。

> **分工**：prompt-rules 的"正反打画面占位"管**怎么摆**（谁在画面哪侧露什么），本节管**何时切给谁**；与漏洞 7 的道具互动（剧本层）形成上下游——剧本给手上的活，本节给镜头的切法。

### 三·六、工作景别与切镜理由

[drama-skills: production-shot-grammar.md#五节]

**工作景别机制**：一场通常比它真正要演的景别**先开宽一档**，第二镜就落到本场的**工作景别**，之后多数切镜在这一档上下一格来回；宽景和特写是**离开工作景别的标记事件**，用过就回来。一路单调收紧的场次到中段就没有余量了。

> 例（客厅摊牌）：第 1 镜全景交代谁堵门口 → 第 2 镜落中景（本场工作景别）→ 之后中景↔中近景对切 → 只有信封推过茶几时切一次特写 → 随即回中近景 → 场尾退回中景。

**切镜必须带来可见变化**（硬规则）：只有注意或关系发生变化时才改变景别和角度；场面声音变大不等于镜头必须从全景推到大特写。反过来——**已经切镜：新镜必须在景别、机位角度或人物关系里至少改变一项**。相邻两镜景别相同、角度相同、关系也没变时，这个切点没有存在理由，应当改变收放或并回一镜（修法：沿阶梯相邻一格一收一放，中景↔中近景↔近景↔特写）。

> 与 B2"无连续 3 个同景别"的关系：B2 保留为**快速口径**，本条是**结构判据**（B2 数连续同景别，本条要求每次切镜至少变一项）；正反打豁免条款（本节开头）继续有效。

## 四、机位角度

**角度三栏分写**（水平角度/机位高度/焦段意图各是一栏，不许混写）[drama-skills: production-shot-grammar.md#角度三栏]：写"俯拍"时其实想要的是"从她背后越过肩膀"——那是**水平角度**，不是高度；下游按字面给了一个从上往下的机位，权力关系当场反了。

**水平角度词表**（回答"观众被允许读到多少表情、站在谁的一侧"）：

| 水平角度 | 效果 |
| --- | --- |
| 正面 | 全部表情可读，直面观众/对手 |
| 斜侧四分之三 | 默认叙事角度，表情与纵深兼得 |
| 正侧 | 对峙剪影感，双方对等 |
| 后斜侧 | 半旁观半贴近，跟随感 |
| 背面 | 表情不可读——藏情绪、留悬念、拒绝对视 |

**机位高度**（心理含义）：

| 中文 | 英文 | 心理效果 |
| --- | --- | --- |
| 平视 | eye level | 平等、真实、中性——**平视是主动表示势均力敌，不是"没选"** |
| 仰拍 | low angle | 权力、威慑、英雄化 |
| 俯拍 | high angle | 弱小、可怜 |
| 正顶视 | bird's eye view | 孤独、抽象 |
| 荷兰角 | dutch angle | 失衡、不安 |
| 主观视角 | POV | 观众即角色 |

**焦段意图**：广角（空间关系/压迫变形）/标准（中性叙事）/长焦（压缩距离——长焦拍全景会把"隔半个房间对峙"拍成"面对面"，选焦段先问距离感要不要保留）。与机位数值化三要素（高度/俯仰角/朝向）互补：数值化管几何，本表管语义选型。

## 五、光影选型库（先选光位与光质，再按参数级落笔）

> 用法：本节管**选型**——这场戏该用什么光位、什么光质、什么情绪。选定后落笔必须写方向+落点+色温/强度（"从画面左上 45 度、约 5600K 冷月光切入，照亮发丝与颧骨"），参数级配方与多光源编号见 cinema-grade-params 第五节。**禁止只写术语名**（写"伦勃朗光"却不写光从哪来、照亮哪 = 空话，命中硬规则 2）。项目 02 已冻结光线锚/色彩基调时以项目值为准；本节只是未定时的选型起点。**白底/版式/0a-0d 锚定参考图不套本节光影风格**，按 consistency「按画面类型裁剪」走。`[社区方法论]`

## 六、短视频节奏模板（15/30/60s）

**通用**：常规叙事镜头成片 1.5-3 秒（按镜头类型的裁切基准见下表；特写/插入在快节奏段可短至 0.3-1s）；**单镜成片超过 3s 必须写明"这 X 秒观众看到什么在变"，答不出就拆镜**（V3.16 实测：镜头过长→观感平淡）；动作戏单镜 1-2s（太长=模型自由发挥，太短=没有过程只有结尾——判据见下方动作容量缩放）（**动作容量随时长缩放**——5s=1 节拍，10s=1动作+1反应，15s≤3 节拍，判据见 prompt-rules 校验 B2，不是固定数）；AI 生成 5s 素材头尾各剪 0.5s（首尾帧质量最差）。**一段视频默认多镜头**（骨架 A，段内 HARD CUT/特殊转场切换）——"一段一镜"是需要理由的特例（fl2va / 一镜到底张力 / 复杂场景拆成多个单镜片段供剪辑拼接），在 01 分镜表标注理由。

### 单镜剪辑时长基准（**分镜时间分配 / 单镜片段裁切目标——不是段内重切依据**）

> 用途分两种：①**分镜时给每镜分配成片时长**（骨架 A 段内多镜的切点由生成端按 04 镜头时间分配烘进片段，**段内不裁中间**，见 01 模板「两套时间轴换算」）②**骨架 B / 单独生成的单镜片段**在 06 裁到目标时长。生成端按段长分档与模型上限生成（段长见「峰值与强调手段」③；单镜片段常见 5s/10s）。
> **不要把生成时长设成 0.5-1s**——模型需要过程才演得出来；单镜片段可以剪短，多镜段落不能靠后期重切。
> **优先级**：本表优先于上方通用"常规叙事镜头 1.5-3 秒"的粗口径；「时长-密度匹配」是自检（这 X 秒在变什么），不另立数字标准——冲突时以本表为默认、以"观众看到什么在变"为最终判据。
> **填写位置**：本表用于 01「成片时段」与 06 裁切目标；01「生成时长」列按骨架 A 段内时间分配 / 骨架 B 单镜生成档位填，**不要照抄本表的 0.3-0.8s 短镜值**（平均生成时长低于模型原生下限会触发 K11 ②）。

| 镜头类型 | 常规 | 快节奏 | 慢节奏/情绪 |
| --- | --- | --- | --- |
| 定场大远景 | 3-4s | 2s | 5-8s |
| 全景/中全景 | 2-3s | 1-1.5s | 4-6s |
| 中景/对话 | 1.5-2.5s | 1s | 3-4s |
| 近景/表情 | 1-2s | 0.5-1s | 3-5s |
| 特写/插入 | 0.5-1.5s | 0.3-0.8s | 2-3s |
| 空镜/情绪 | 2-4s | — | 5-10s |

**竖屏短剧修正**（`[社区方法论]` 启发式，非硬门）：单镜平均比电影短 20%-30%；爽点/打脸镜再短约 30%——用"缩短 + 景别拉近"制造冲击，不靠堆慢镜。

**台词镜头例外（硬口径）**：台词镜头时长不得短于台词朗读时长（**4 字/秒，标点算时间，向上取整**）——25 字单气口按 `ceil(25/4)=7s` 排镜（K2 用 ceil 估算，不能按 6.25s/6.3s 凑），按台词实际时长排，**不套上表的常规/慢节奏档**（否则 K2 报"朗读时长 > 镜头时长"）。上表是无台词/短台词镜头的参考，不是所有镜头的上限。

### 节奏控制五法

1. **情绪递进=时长递减**：冲突升级时单镜逐步缩短、景别逐步拉近（与峰值节配合，不提前透支）。
2. **高潮后留白**：大爽点/大情绪爆发后接 1-2 个慢节奏镜——**优先空镜/反应镜，不是再上慢动作**（慢镜配额仍 ≤2 处/段）。
3. **呼吸点**：每 15-20 秒插一个节奏缓冲（空镜/反应镜/环境细节），防全程快切视觉疲劳；电影化项目按场次呼吸，不强套 15-20s。
4. **信息密度**：信息量大的镜头给足时长，信息单一的镜头缩短——与「时长-密度匹配（反 PPT 检查）」同一条纪律。
5. **音乐对齐**：切点尽量对齐 BGM 鼓点/重拍（写进 06；生成端无法预知配乐，不写进 04）。

### 漫剧/竖屏短剧剪辑准则（写进 06）

1. **竖屏短剧：开场第 1 秒必须有信息增量或钩子预兆**——定场镜可保留，但要同时带信息（人物/异常/威胁/声音），不能是纯环境空镜；钩子拍位置仍由 01 节拍表定（前 3 拍，K14），首秒只要求与钩子同向，不要求钩子已完整发生。**电影化项目不受此条限制。**
2. 每 3-5 个镜头至少一个信息点或情绪点（启发式，不设机检）。
3. 系统弹窗/字幕信息单独留 0.5-1s 停留（贴片层，见第七节）。
4. 竖屏关键信息避开顶部 10%/底部 15%（字幕、UI 遮挡）。
5. 单条台词仍守 **25 字单气口上限**；时长按上「台词镜头例外」的 4 字/秒向上取整排（25 字=7s）——**不存在"25 字配 1.5-2 秒"**（资料原文算术不成立，已剔除）。

### 峰值与强调手段（强调手段=稀缺品，只花在已点名峰值上）

> **本节是强调手段规则的唯一家**（B3/C6/F3 都指向这里）。范式：稀缺逻辑让人想用，危险逻辑让人躲着走——强调手段不是"高危品"要回避，是"奢侈品"要花在刀刃上（裁定 R3）。

**① 强调手段家族登记**：慢镜/Time Ramp、冲击重复、短促推近、定格、闪白共用「只花在已点名峰值」这一条纪律，但**只有慢镜/升格受「每段 ≤2 处」配额约束**；冲击重复/定格/闪白/短促推近各自需要峰值标注，不占慢镜配额（否则 ⑥ 的 2-3 角度冲击重复无法落地）。跟随动作的跟拍、揭示信息的摇、压力落下时的缓推**不是**强调手段——它们由功能决策表（R1-R7）正常管辖，任何一场都按表使用。

**② 先点名峰值，再花手段**：

- 打斗峰值 = 交手账里点名的胜负手（结果改变最大的那一拍，标 ★，见 action-combat.md 第 0 节）
- 文戏峰值 = 01 情节点清单标【峰】的情绪爆发/重大反转/打脸拍
- **每处强调手段必须标注峰值来源（CT2 格式）**：`←峰值：情节点<N>` 或 `←峰值：交手账R<N>`（示例：`慢动作 0.4s ←峰值：交手账R3`）——无标注的强调手段不过 K5 门

**③ 段长分档**（拆条时套用，不默认顶满 15s）：

- **追逐/交手紧凑段：6-9s**——紧凑感来自信息密度，不是快剪；超过 9s 的追逐段几乎必然拖
- 对峙/氛围/文戏段：10-14s
- **舒适区 8-12s**；任何段超过 12s 必须回答"多出来的这几秒在演什么"——答不出=砍
- 实测教训：默认按上限拆条，用户逐段砍到 6-9s——**先按紧凑预算拆，宁短勿拖**

**④ 慢镜配额（仅慢动作/升格）**：只给决定性动作与决定性特写（胜负手/情绪爆点的 0.3-1s）；**每段 ≤2 处**，全片追逐戏里最多 1-2 个特写慢镜，其余全部显式写"正常速度"；非决定性动作用慢镜=拖沓感的直接来源；慢镜段配帧率声明（"24fps 快门 1/48，仅此一镜 Time Ramp"——防模型把整段升格）

**⑤ "决定性动作"操作判据**（无判据=每招都像胜负手，预算形同虚设——实测教训）[drama-skills 改写: shot-craft.md#SHT-04/SHT-08]：

- 打斗段：先在交手账里点名胜负手（结果改变最大的那一拍，标 ★，见 action-combat.md 第 0 节）——**只有胜负手、缴械、逆转可配慢镜**，普通命中一律正常速度
- 文戏段：只有情节点清单标【峰】的情绪爆发/重大反转/打脸拍可配强调手段
- **一场里处处慢镜，就没有哪一下是冲击**——配额（≤2 处/段）是上限不是任务，没用完不欠
- 慢镜处必须写明从哪一刻开始、到哪一刻结束（如"腾空顶点 0.3-0.5s"），其余变速留给剪辑

**⑥ 承受者反应与冲击重复** [drama-skills: shot-craft.md#SHT-27/SHT-08]：

- **承受者反应**：打击、否定或翻盘需要观众理解其后果时，分镜应安排**可读的承受者反应**——独立反应镜/双人镜调度/群像反应均可（对白场「默认给听者」的切法是三·五节的事，此处不重复）
- **冲击重复**：情绪爆发、打脸或重大反转的那一下，可以把同一个关键动作**从两三个角度各给一次**，让观众连看几遍——**只用在峰值。一集里处处重复，就没有哪一下是冲击了**
- 状态纪律：每个重复镜都从**同一动作前状态**走到**同一动作后状态**，第二遍不能在第一遍的结果上再做一次（状态只改变一次）；重复镜之间起止不衔接

**⑦ 生成难度不是回避理由**（裁定 R3）：峰值镜头难生成 → 走 prompt-rules 0.7 改写阶梯改**实现方式**（换承担者/拆相邻镜/换停留/交声音），不改戏剧结果；降级只作**生成失败后**的回退兜底（SKILL.md 回退阶梯），不预先降级、不在 GATE1 二选一。GATE1 呈现的是**峰值-强调手段分配表**（templates 01），用户确认/否决/加峰。

**时长-密度匹配（反 PPT 检查）**：写完每镜自问"这 X 秒里观众看到什么在变"——决定性动作 1-2s（长了=人物不知道做什么，视频像 PPT）/过程动作 2-3s /反应与氛围 2.5-4s；答不出内容变化的镜头=砍时长或加动作/环境变化。镜头切换由**人物动作、视线或道具运动**衔接（动接动——切点选动作进行中，不选完成后），"动作在镜头结尾保持未完成趋势，为下一镜留下明确运动方向"，避免空镜和无效停顿——防定格动画感。

### 15s（单点爆破，3-4 镜）
0-2s 强视觉钩子（大特写/顶视/景别跳跃）→ 2-12s 主体 1-2 个动作 → 12-15s 记忆点定格/卡点。
禁忌：缓慢长镜（观众 3 秒无信息增量即划走）。

### 30s（微叙事，5-6 镜）
0-3s 钩子（冲突/悬念/最美一帧前置）→ 3-8s 建立（定场）→ 8-22s 发展（3-4 镜渐快）→ 22-30s 高潮+收口。
运镜搭配：开场景别跳跃抓人；发展段横移/跟拍维持流动；高潮前慢推蓄力；落点甩镜/急变焦卡重拍；结尾拉远留余韵。

### 60s（完整三幕，8-10 镜为基准——文戏/多对白项目可到 16 镜，镜多但短）
钩子(0-5s) → 建立(5-20s) → 升级(20-45s，峰值在 35-45s) → 反转/回落(45-55s) → 收尾记忆点(55-60s)。
**能量曲线编排运镜**：低能量=固定+慢摇；爬坡=跟拍+横移；峰值=快切+甩镜+手持；回落=慢拉+航拍；结尾=静态或推入特写锚定记忆。
> **8-10 镜是节奏基准不是硬上限**：对话戏正反打需要更多短镜（16 镜×1.5-3s 常见），按"每镜 1.5-3s"折算实际镜数，不硬压到 10 镜内。

**5 种运镜组合模式**：定锚式（主体不动镜头动）/ 递进式（推→跟→锁定）/ 对比式（A动B锁定）/ 揭示式（缓推先藏后露）/ 跟随式（稳定器同速跟拍）。

## 七、竖屏构图与安全区（画幅 9:16 时必读）

> 竖屏不是"横屏裁掉两边"——构图逻辑相反：横向留白变少，纵向分层承担信息。`[社区方法论]` 平台 UI 尺寸随版本变化，下表按红果/抖音常见布局给默认值；项目可调，但核心区不得侵入顶/底避让区。

**四条构图原则**：

1. **中心聚焦**：核心人物/关键信息/情绪重点放在画面垂直中轴；左右留白只做环境。
2. **上下分层**：上层环境/顶部 UI、中层人物主体、下部字幕/底部 UI——信息按层分配。
3. **纵向延伸**：用竖屏高度强调身高/建筑高度/纵深通道；少拍横向大场面。
4. **人物优先**：单人镜头人物占画面高度 60%-70%，以中近景/近景/特写为主，减少大全景。

**安全区（默认值）**：

| 区域 | 位置 | 规则 |
| --- | --- | --- |
| 核心安全区 | 画面中间 60% 高度 | 人物面部、关键道具、核心信息必须在此 |
| 顶部避让区 | 最上方 10% | 禁放关键面部/台词（平台状态栏、UI） |
| 底部避让区 | 最下方 15% | 禁放关键信息（字幕条、互动按钮） |
| 左右边缘 | 左右各 5% | 不放重要细节（圆角/曲面裁切） |

**景别/站位适配**：

| 景别 | 竖屏适配 | 用途 |
| --- | --- | --- |
| 近景/特写 | 面部居中、头顶少量留白 | 表情、台词、情绪高光 |
| 中景 | 腰部以上、头顶留 1/10 | 常规对话、单人动作 |
| 全景 | 全身、上下留空均匀 | 全身亮相、完整动作 |
| 大远景 | 纵向展示空间高度、人物缩小居中 | 定场、宏大环境 |
| 双人 | **上下/前后站位优先，避免默认横向并排** | 对话、互动、对峙 |

**运镜适配**：优先上下摇（tilt）、纵向推拉；环绕/大范围横移缩短时长、收小幅度；跟拍人物优先纵向前后走；推镜优先向面部推。横摇不是禁用，而是"横向信息在竖屏里更贵"——按功能决策表选，选了就写清横向落点。

**系统 UI/弹窗**（系统流/漫剧项目）：

- 属性面板/系统弹窗/任务列表属于**后期贴片**，不在 04 生成端写 UI 文字（AI 生成文字不可控，见 realism 文字物理化）；提示词只预留位置（"人物偏左，画面右侧留出干净负空间"）。
- 布局：顶部横幅式、左右 1/4 侧边悬浮式、底部安全区上方弹出式、重大公告居中半透明覆盖式；**任何 UI 不遮人物眼睛/面部核心区**。
- 成片停留 0.5-1s，保证读完（写进 06）。

## 八、场景镜头序列库（7 类高频场景的参考骨架）

> **性质：参考骨架，不是模板。** 序列给的是"这类场戏通常需要哪几种功能镜头"，不是"必须 6 镜、必须这个顺序"。实际镜数与节拍以 01 情节点/场次节拍表为准；功能重复的删，缺的功能补。`[社区方法论]`（用户提供的漫剧高频场景整理，未见成品实测出处）
>
> **四条让位规则 + 执行提醒（先读，再抄表）**：
> 1. **打斗序列让位 action-combat**：第 7 类只给镜头顺序；真正排镜先走 action-combat 第 0 节交手账（回合三格+点名胜负手），攻防状态机七段是打斗镜头块的写法。
> 2. **慢镜/升格/冲击重复只在峰值；环绕不是强调手段**：表里的"慢动作"默认改成正常速度；"环绕"按功能决策表 R4 正常选（不因未标【峰】而删），只有写成"慢动作环绕"时慢镜部分才受配额（每段 ≤2 处）。
> 3. **竖屏项目改站位**：双人镜头优先上下/前后站位（第七节），不照抄"横向并排"；横向并排只在需要平权/宽阔空间时用，并说明理由。
> 4. **竖屏短剧开场**：8.1/8.4/8.6 的首镜定场在竖屏短剧里要带信息增量（空镜里已有异常、人物已入画或声音先入），纯空镜定场只用于电影化或非开场位置（与六节第 1 条剪辑准则一致）。

> **表中"固定"不豁免 R7**：固定须 `(R7)+理由`；序列只给场景功能，不给免检理由。
> **强调手段用 K5 识别词**：在 04 里把"急推/快速推镜"作强调手段时，统一写"短促推近"并标峰值（K5 只认"短促推近"）；运镜库的"急推/撞击推"仍是合法运镜名，但不能替代峰值标注。
