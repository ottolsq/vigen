# UGC 真实感（自拍风 / vlog / 网红质感 / 韩系街拍）

> **何时读**：手机自拍风、UGC/vlog、抖音网红质感、韩系街拍类项目。这类风格的核心是**刻意保留拍摄缺陷**（与"完美画质"相反）——缺陷本身是真实感的证据。
> 源：社区实战资料（2026-10），含两条完整自拍视频范式 + 韩系随拍提示词 + 方法论。

## 一、UGC 画质哲学：缺陷保留清单

真实手机视频 ≠ 干净高清成片。以下"缺陷"要**主动写进提示词**（正向表述为主，负面清单按 knowledge-index.md 适配规则处理）：

| 缺陷类型 | 提示词写法 |
| --- | --- |
| 动态拖影 | 拿起放下、怼脸、拨发时出现明确动态拖影 |
| 短暂失焦 | 一次短暂失焦后重新咬上焦；对焦呼吸 |
| 滚动快门 | 滚动快门果冻感（快速移动时） |
| 曝光波动 | 曝光白平衡泵动，随脸部移动小幅波动 |
| 压缩感 | 降噪涂抹、平台压缩块；细小随机颗粒与少量彩噪 |
| 分辨率 | 720p（不要 4K 感） |
| 美颜滤镜 | 抖音网红美颜滤镜质感：柔和提亮肤色但暗部保留颗粒 |

**画质硬约束段**（可直接拼入视频提示词，按模型轨道调整位置）：
> 抖音网红美颜滤镜的真实手机前置视频质感，不是干净死板的高清成片。美颜柔和提亮肤色，但中间调与暗部仍保留细小随机颗粒和少量彩噪；拿起放下、怼脸、拨发时出现明确动态拖影和短暂失焦；对焦呼吸、滚动快门、曝光白平衡泵动、降噪涂抹、平台压缩块全部保留。五官可辨但不处处锐利。720p。

原负面清单（保留备用，适配规则见 knowledge-index.md）：禁止文字水印、无噪点、全程锐利、HDR、影棚精修、稳定器平滑。
- H3 轨道 → 并入 ban list：`Avoid text, watermarks, noise-free clean footage,全程锐利 look, HDR, studio polish, stabilizer-smooth motion.`（英文化）
- gpt-image → 转正向："720p 手机前置质感，保留细小颗粒与彩噪，动态拖影"（缺陷即正向描述）
- happyhorse → 约束槽只留"画面严禁出现任何字幕/水印"，其余靠正向缺陷描述
- **支持负面提示词的模型（即梦/SD 系等）→ 原清单直接可用**

## 二、手持自拍视频范式（镜头互动逻辑）

**关键认知**：自拍风**不是单一平滑一镜到底**——镜头由人物手持，有明显的"镜头互动与切换感"：

- 手机可以突然放下（画面短暂落到胸口/腰腹/大腿中近景，构图晃一下）再突然拿起怼到脸前
- 贴脸特写与稍远中近景之间硬切或快速跳切
- 每一次拿起都让观众感觉离她非常近
- 全程不用稳定器：手持随机晃动
- 无台词、无口型（自拍风通常纯画面+音乐）

**画面段落结构**（30s 自拍视频参考）：
1. 开场中景：腰腹到上半身，人物左右摆动重心、甩手，手机可能先放低拍身体律动
2. 拿起怼脸：前摄瞬间贴到眼睛、鼻尖、嘴唇，妆容充满画面；表情在娇羞与撩人之间切换——先垂眼，再抬眼锁镜头，轻歪头、轻眨眼、嘴角温柔的笑
3. 放下或稍退：回到胸以上，拨发、侧头；下一拍又拿起怼脸
4. 收尾：停在贴脸近景，暧昧对视与呼吸起伏

## 三、完整范例：夜晚路灯下自拍（分镜式写法，可作 04 模板参考）

**参考图锚定**：图像1 保留参考图中的面部特征、精致妆容（粉珊瑚唇、淡眼线）、碎发与整体外貌。

**人物初始站位与空间关系**：夜晚路灯下，她站在街边一盏路灯正下方偏前的位置，手持手机以真实前置摄像头自拍视角拍摄，画面从胸以上的中近景开始，镜头随她的手持动作运动。头顶路灯洒下柔和的暖白光池，从上方偏正前照亮她的脸——额头、鼻梁、颧骨受光，鼻下与眼窝投下朝下的柔影，发顶和颊边碎发被灯光勾出一圈暖色轮廓光；背景是深暗的夜街，树木与远处零星灯光虚化成暗色散景，明暗对比大，面部阴影部微微偏冷青。

**环境音**：真实大街的嘈杂背景音——持续的车流声、偶尔驶过的汽车引擎与胎噪、远处模糊的人声与喇叭声、风吹树叶的沙沙声；前景保留她轻浅的呼吸声、发丝摩擦声、手指握住手机的细微声响。

**镜头1 · 拿起怼脸（约1.5s）**：她手腕一翻把手机猛地举到面前，画面从中近景瞬间怼到脸部极近景——眼睛、鼻尖、嘴唇充满画面，过程中出现明确的动态拖影和一次短暂失焦后重新咬上焦；头顶路灯的暖光在鼻尖与颧骨上形成小块高光，表情先垂眼抿嘴，露出娇羞。

**镜头2 · 抬眼锁定（约1s）**：同一连续自拍机位，她缓缓抬眼直视镜头，轻轻歪头、快速眨一次眼，嘴角浮起若有若无的笑；暖白灯光照亮双眼，瞳仁里映出一点路灯的光点，对焦轻微呼吸，曝光随脸部移动小幅泵动。

**镜头3 · 退下拨发（约1s）**：她手腕稍沉把手机放下几厘米，画面退回胸以上中近景。随后她抬手做一次完整明确的撩发动作：手指张开伸进颊边的碎发，把头发完整地拨到耳后，发丝随动作轻扬，发顶被路灯照出一片暖亮光泽；动作清晰可辨、不可省略，带出短暂的动态拖影和滚动快门果冻感。

**镜头4 · 再怼脸与收尾（约1.5s）**：下一拍她又猛地拿起手机，下半脸与嘴唇稍微靠近镜头，随即回稳在贴脸近景；暖光在唇峰上留下一点高光，她与镜头暧昧对视，胸口随呼吸轻微起伏；收尾时她再稍微歪头，笑意含蓄，画面在她歪头凝视镜头中自然收住。

> 注意：此范例是**一个生成段落内的 4 个"伪镜头"**（同一机位的拿起放下构成节奏感），不是 4 次独立生成——写进单条视频提示词时用 At 时间点（H3）或连续叙述（happyhorse）表达。每段 1-1.5s 的快速节奏是自拍风的特征，与常规"5s=1节拍"不同（自拍风允许更碎的节奏，因为"镜头"是手机拿起放下而非真实切镜）。

## 四、韩系随拍方法论（图片端）

**提示词顺序**：先写人物特征和状态 → 穿搭、动作、场景与构图 → 最后补拍摄设备和光线。**设备选择明显影响质感**：

| 场景 | 设备写法 |
| --- | --- |
| 室外街拍 | 手机 + 闪光灯为主，写清拍摄角度、光线方向、抓拍状态 |
| 室内场景 | 手机或 CCD，按氛围决定是否用闪光 |
| 自拍 | 直接写手机前置镜头；脸部提亮只针对自拍，保留自然肤质 |

**完整范例**（韩系街头随拍）：
```
一张韩系随拍街头照片，由朋友在近处以轻微俯拍角度拍摄。使用现代 iPhone 后置 1 倍主摄、标准照片模式，并开启内置 LED 闪光灯作为轻柔的日间补光，完整拍到她蹲下的身影和身后的街道。
一位二十多岁的成年东亚女性，小巧的椭圆脸，脸颊柔和饱满，眉形纤细，鼻梁秀气挺直，唇色柔和粉嫩。她闭着眼睛开怀大笑，脸颊扬起，露出上排牙齿。妆容轻透，带有粉色腮红。她的栗棕色长发从蓬松的侧分发根自然垂落在肩头，几缕发丝被风吹到额前。
她穿着宽松的浅灰鼠尾草绿拉链外套，内搭白色上衣，下穿象牙白花卉蕾丝半身裙，脚穿奶油色与浅棕色运动鞋。外套下方垂着两根浅黄绿色抽绳。她低身蹲着，双膝弯曲，身体微微前倾，抬头看向朋友。一只手在膝边松松地拿着一部银边手机，红色挂绳垂向地面；旁边放着一个弧形白色手提包和一个装有小黄物件的透明袋子。
她蹲在磨损的黄白色道路标线上，周围是灰色沥青路面、排水沟、路缘和黑色金属栏杆。明亮的阳光从左上方照来，温暖地勾亮她发丝的边缘，并在路面投下栏杆的斜向影子。手机闪光灯柔和地补亮她的脸部和外套前侧。
```

范例拆解（可套用到其他 UGC 图片）：
1. **拍摄情境句**："由朋友在近处以轻微俯拍角度拍摄"——定义随拍关系（不是摆拍）
2. **设备句**：iPhone 后置 1 倍主摄 + LED 闪光灯日间补光——设备具体到模式
3. **人物段**：脸型五官→妆容→发型（风吹动的发丝=瑕疵感）
4. **穿搭段**：具体到颜色名（鼠尾草绿/象牙白/奶油色）与配饰细节（抽绳/挂绳/透明袋）
5. **动作段**：蹲姿+身体前倾+抬头看朋友（与拍摄者的互动感）
6. **环境段**：磨损的道路标线、排水沟——环境瑕疵感
7. **光线段**：阳光方向（左上）+ 闪光灯补光位置（脸部和外套前侧）——双光源写实

> 与 realism.md 的关系：realism.md 的"拍摄媒介句库"偏电影/胶片质感；本文件补手机/CCD/闪光灯类 UGC 设备句。两者按项目风格选用，不混用（电影项目不写 iPhone，UGC 项目不写 medium-format）。
