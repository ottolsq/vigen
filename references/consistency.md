# 一致性锚定机制（角色 / 场景 / 色调 / 音色）

> 建 02_锚定表时读本文件。原理：**参考图 > 文字锚定 > 无锚定**，双保险 = 锚定短语逐字复用（文字层）+ 参考图多图输入（图像层）。

## 一、锚定表结构（02_锚定表.md 的规则依据）

### 目标模型（表头节——续作与换轨的依据）

| 字段 | 说明 |
| --- | --- |
| 生图模型 | 如 gpt-image-2.5；阶段2-4 提示词按其档案写 |
| 视频模型 | 如 happyhorse-1.1-i2v / MiniMax-H3；**阶段5 按此选轨道**（A 轨中文/B 轨英文结构化），fl2va 项目在此注明 |
| 语音模型 | 如 cosyvoice-v3.5-flash；05 台词表按其档案写 |

### 角色锚定（每个角色）
| 字段 | 说明 |
| --- | --- |
| 锚定短语 | 一段固定文字：{年龄/性别/体型/脸型/发型发色/服饰/标志性特征}。**生成后冻结，逐字复用到所有图/视频提示词开头** |
| 参考图路径 | **三层资产**：①视觉锚定层（给 AI）：白底三视图 + 面部特写锚定图 + 按需 ≤2 张补充锚 ②文字规则层：锚定短语（02 表内） ③人工参考层：拼贴设定卡（自看，不喂 AI） |
| 音色绑定 | cosyvoice voice_id（或参考音频路径）+ 音色描述句（逐字复用，如"[林晚，普通话，温柔低沉的青年女声]"） |
| 微动作习惯 | 可选：该角色的小习惯（紧张时摩挲袖口），跨镜复用增强人物真实感 |

### 场景锚定（每个场景）
| 字段 | 说明 |
| --- | --- |
| 场景描述锚 | {空间结构/主要道具/材质}固定文字 |
| 光线锚 | {时段+方向+色温}——情景图与视频提示词必须引用同一条 |
| 参考图路径 | 场景参考图，多图参考的 image 2 |

### 风格圣经（全局唯一）
从 styles.md 选定后逐字冻结，追加到每条图片提示词末尾；视频端由首帧图承载。

## 二、锚定短语写作规则

1. **具体到可指认**：`28岁女性，齐肩黑色短发微卷，左眉角一颗小痣，米白色针织衫配浅灰阔腿裤，清瘦`✓；`一个年轻女性`✗
2. **顺序固定**：年龄性别→体型脸型→发型发色→五官特征→服饰→配饰。跨镜复用时顺序都不变（顺序也是模型识别锚的一部分）
3. **7-9 个视觉要素**：太少不够锚定，太多稀释重点
4. **英文版同步冻结**：如走英文提示词路线，英文锚定短语同样逐字复用（不许每次重新翻译）

## 三、跨镜一致性操作规则

### 图片端（gpt-image 多图参考）
- **角色资产 = 三层分工**（参考图的底层逻辑：AI 只识别像素/轮廓/五官比例，不读图中文字）：
  - **视觉锚定层（给 AI）**：白底三视图为主锚（无背景干扰、信息精准单一、全身权重均匀——多角度运镜稳定性最高的公认方案）+ 面部特写锚定图（三视图脸部占比小，特写镜头需独立锁脸锚）+ 按需 ≤2 张补充锚（表情板/服装细节）
  - **文字规则层（给 AI）**：锚定短语逐字进每条提示词——图上写"身高170""左脸有痣"AI 不读取，这类信息只有放提示词才生效
  - **人工参考层（给用户）**：拼贴式设定卡（含分区/色卡/文字说明）作为制作规范手册核对全片人设，**绝不整卡上传给 AI**——分割线/网格/文字会被当特征学习，表情格小脸占比太小还会串脸
- **参考图按镜头机位动态组配**：正面镜头 → 三视图（或裁出的正面图）+ 场景图；侧/背镜头 → **必须加对应视图图**；特写/近景 → **必须加面部特写锚定图**。每张图的用途声明逐图写明
- **绝不"编辑已生成的图"来换场景/姿势**——每次编辑累积伪影（第3代起明显）
- 多人场景：身份保持差于单人，宁可拆镜（每镜 ≤2 人同框为佳）；多人参考图可合成一张
- 长会话（12+ 张）后参考图"失忆"——分批新开会话/独立请求，每次重传参考图

### 视频端（happyhorse）
- **i2v 路线**：一致性靠首帧（情景图）承载，提示词不重复外观描述
- **r2v 路线**（跨镜一致性要求高时）：`[Image 1]` 人物锚定图 + `[Image 2]` 场景锚定图（注意 [Image 1] 带空格），四段式结构见 prompt-rules.md
- 多段连续叙事：段首加"延续上段：{站位/手部/光线/道具状态}"
- 光线连续性：上一段结尾的光 = 下一段开头的光（不能上段黄昏下段正午）

### 色调端（双端分工——V1.1 修订）
- 图片端：风格圣经**全量**逐字后缀（色调+质感+光线全套）
- 视频端：风格圣经**压缩为质感锚定行**进入每条视频提示词（介质质感+主体表面纹理（人物=自然皮肤纹理，物体/动物=对应材质）+自然运动模糊三项，从风格圣经同族压缩——见 prompt-rules.md）。原因：视频模型不保留首帧像素而是逐帧重渲染，仅靠首帧图锁不住质感，实测视频端会出现图片端没有的"AI 油腻感"（油光脸/数字锐化/逐帧清晰的 CG 感）
- 注意区分：这**不违反**"i2v 不重复外观"规则——外观（身份/服装/背景）不写，质感（渲染质量方向）必写
- 兜底：剪映统一调色/LUT + 胶片颗粒叠加（见 06_剪辑清单"去油腻后期"节）——对最终像素操作，最可靠

## 四、音色一致性（05_语音台词表）

**推荐架构**：视频模型只出画面+环境音（BGM 显式关闭），人物语音统一用 cosyvoice 批量生成、剪映对轨。理由：音频不跨片段连续，每段独立生成必漂移；TTS 统一生成是最稳路径。

- 每角色在项目开始时创建/选定复刻音色，**voice_id 存入 02_锚定表**，全项目所有台词走同一 voice_id
- 固定 seed + 固定 pitch/rate 参数提升跨次复现性
- 长台词拆句逐句合成（每句同一参考音频），比一次长文本更稳
- **备选**（坚持视频模型直出台词时）：音色描述句逐字复用同一句；台词 ≤15 字；锁定中近景+嘴部动作小+无头部转动；接受跨段音色轻微漂移

## 五、失效传播

锚定表（02）变更时：
1. 在 03/04/05 文件头部插入标记：`> ⚠ 上游锚定已变更（变更日期），本文件待重新生成`
2. 聊天中明确告知用户哪些文件失效、需要重做哪些提示词
3. 未重新生成前，旧提示词与新锚定混用 = 一致性必然崩坏
