# 一致性锚定机制（角色 / 服装 / 场景 / 道具 / 色调 / 音色 / 剧情记忆）

> 建 02_锚定表时读本文件。原理：**参考图 > 文字锚定 > 无锚定**，双保险 = 锚定短语逐字复用（文字层）+ 参考图多图输入（图像层）。

## 〇、锁定清单（先判"锁什么"，再建 02——V3.9）

> 不是所有东西都锁。判据：**可识别 + 跨镜出现/有身份/会漂移** → 必须锁；一次性环境纹理不锁。锁定 = 有参考图或有显式锁定句，二者必居其一；**两头空=停**。

| 锁定对象 | 触发条件 | 必须产出的锁定物 | 提示词必须写 | 详细规则 |
| --- | --- | --- | --- | --- |
| 角色身份 | 任何跨镜角色 | 0a 三视图 + 0b 面部特写 | 锚定短语逐字 + 脸部参考 | 一·角色锚定 |
| 服装 | 换装/多套/剧情关键/颜色易漂/已漂移 | **专属服装图（默认）**；单套且四视图清晰才可四视图锁定 | "服装以 Image N 为准"+短锚；或"服装由 Image N 锁定"+短锚 | 一·服装锁定三档 |
| 道具 | 命中六条任一；或跨镜反复出现且有颜色/材质/形状身份 | 道具图 + 状态图 | 锚定短语+状态+位置账+引用 | 一·道具锚定 / prompt-rules 道具判定 |
| 场景 | 同场景 ≥2 镜或有正反打 | 场景母版；**≥3 镜或正反打 → 四视图** | 3-5 锚点+光线锚+LOCATION MAP+"环境以 Image N 为准" | 一·场景锚定 |
| 场景持续物 | 观众/器械/垫子/横杆/看台/广告牌/光色等跨镜存在 | 02"持续在场要素"字段（颜色色号+位置+数量） | "始终在场，不得忽有忽无"+色号；不出现则"全程不出现" | 一·场景锚定 |
| 风格 | 项目级 | 风格圣经 + 色彩基调 | 叙事画面逐字含风格圣经+色号+身份句（0a-0d 豁免） | styles 使用方法 |
| 尺度 | 尺寸影响识别/动作 | 比例锚（身体部位/参照物） | 数字+身体比例+反例 | prompt-rules 尺度节 |
| 动作 | 反先验/技术动作 | 真赛参考图 + 情景图锁姿 | "是X不是Y"+阶段+"只取动作结构" | prompt-rules 技术动作节 |
| 声音 | 跨段角色发声 | 音色参考（模型支持时） | 音色描述+参考音频 | 四节 |

**五条执行纪律**：

1. **先登记后生成**：锁定清单 → 02 锚定表 → 03 资产矩阵 → 提示词。没有登记的对象不写进画面；零引用资产不生成。
2. **两头空=停**：角色没有服装图也没有四视图锁定句、场景没有母版也没有锚点、道具没有图也没有显式排除——停在 GATE1，不靠形容词硬写。
3. **入画即登记**：每镜画面里可识别的道具/场景大件（有名字/颜色/材质/剧情功能）必须在 **01 分镜表「入画道具」列**写资产 ID，且 03 矩阵有该 ID；矩阵没有 → 补资产或从画面删掉。纯环境纹理（墙面污渍/地砖缝）不登记。
4. **反复出现=持续物**：跨镜反复出现且有颜色/形状身份的东西（垫子/横杆/看台/广告牌）即使不触碰、不变状态，也按"场景持续物"锁定颜色色号+位置；会位移/被触碰的再加道具条目。**实测：垫子一镜蓝一镜红=没有持续物锁定，不是模型记性差。**
5. **项目风格隔离**：每个项目的风格圣经/色板/锚定只属于该项目；禁止把另一项目的提示词/风格句/锚定复制过来。共用画布时先清空旧项目节点或分区；切项目后重新冻结风格圣经。

| 适用镜头 | {镜号；换装前后的镜头归属} |
| 参考图路径 | assets/{角色名}_{服装名}.png（换装新锚按 0a/0b 标准重出） |

**服装锁定三档（V3.7——解决"只挂四视图、不写服装，模型只能猜"的漂移）**：服装必须由**图**或**文**明确锁定，二者必居其一，不许两头空。

| 情况 | 提示词必须写 |
| --- | --- |
| 有专属服装图（任何情况） | 挂该图 + `服装以 Image N 为准` + **短锚**（款式名 + 主色十六进制色号），不复述材质/配饰/磨损 |
| 换装/多套/剧情关键/颜色易漂/已漂移（尚无专属图） | **先补专属服装图**（0a 同规格白底全身），再按上一行写——不得靠四视图或全量文字硬撑 |
| 单套且四视图清晰（四视图穿的就是这套） | 四视图用途声明**必须写明** `服装由 Image N 锁定` + 短锚——只写"参照人物四视图"不合格 |
| 两者都没有 | **不合格=停**：先补专属图（或至少四视图）；全量逐字只能作经用户同意的临时兜底，不默认使用 |

> 与硬规则 4 的关系：服装锚定短语不再要求全量逐字；**有专属图=锁定句+短锚；单套且四视图清晰=四视图锁定句+短锚；两者都没有=停（补图）**。角色锚定短语仍不含服装（身份级要素），两者不重复。
> **默认策略（V3.9 实测）**：凡换装/多套/剧情关键，默认走专属服装图；不要等"已经漂移了"才补——用户实测"服装全没有直接锁定参考，提示词也没说明"，等发现时整段已返工。

### 场景锚定（每个场景）
| 字段 | 说明 |
| --- | --- |
| 场景描述锚 | {空间结构/主要道具/材质}固定文字 |
| 场景设计意图 | {这个空间为哪场戏存在/讲什么故事——一句设计意图，不写户型说明} |
| 一致性锚点（3-5） | {逐条：名称+位置+特征；判据：可画、可认、可核对——"补丁船篷"✓，"陈旧的氛围"✗} |
| **场景母版（多镜场景必写）** | 场景母版 ID（SC01）+ **四向锚**：以镜头为参照系，左/右/中央/远后方各登记一个固定物（"左侧固定为翻倒燃烧公交车，右侧固定为燃烧广告牌，中央固定为破损隔离带，远后方固定为破碎高楼与高架桥"）——跨镜空间感靠方向+固定物，不靠复述全场景 |
| 光照状态清单 | {从分集反推：本场景实际经历的时段/天气；每个状态一条完整光线锚；用不上的状态不登记} |
| 光线锚 | {时段+方向+色温}；多光源场景登记编号光源表（L01/L02/L03=来源+方向+色温K+强度%+硬软+动态行为+落点，写法见 cinema-grade-params.md）；**同场景异时段**：登记基准锚 + 变体锚（如黄昏 L01/L02、深夜 L01'/L02'），情景图按所属时段逐字引用对应变体，空间仍由场景母版锁（基准参考法） |
| LOCATION MAP | 多角色场景必写：各角色/关键道具的固定位置、朝向、相互距离（防跨镜瞬移）；单角色场景可省。**距离常数**：关键空间关系写死成常数并逐镜复述——对峙距离（"两人相距十步约六米"，一步≈0.6米）/追逐距离（"前后相距八步约五米"）/贴身距离（"不到半臂"）——实测教训：不写死，模型每镜自取距离，用户连改三次；04 每镜画面行必须复述该镜适用的距离常数 |
| **持续在场要素** | {观众（人数/位置/服装基调）/ 器械与场景大件（垫子/横杆/起跳架/看台/广告牌）/ 光色 / 背景大件：逐项写颜色十六进制色号+位置+数量；每镜复述"始终在场，不得忽有忽无"} |
| **开场走位句** | 每场第一条视频生成前必写（见下方"开场走位机制"），分镜该场第一段的 SCENE CONTEXT 照抄 |
| 参考图路径 | 场景参考图；被 ≥3 镜使用或有正反打对话 → 四视图全套（母版/对向回望/45°斜角/垂直俯拍，见 extended-views.md）全部登记 |

> **场景三件套纪律**：①设计意图回答"为哪场戏存在"，不写户型；②一致性锚点 3-5 个，可画/可认/可核对；③光照状态从分集反推，只登记实际用到的时段/天气，每个状态一条完整光线锚。场景图生成后逐一核对 3-5 个锚点是否在主视角可见；缺一个就重生成或补图（拿图四扫第一项"同世界"扩写为"同世界 + 3-5 锚点齐"）。
> **场景锁定三件套（每镜必写，V3.9）**：①挂场景母版/参考图 Image N ②3-5 一致性锚点短句 ③光线锚；多角色加 LOCATION MAP。三者缺一=该镜不可交付。场景大件（垫子/横杆/看台/广告牌）的颜色色号进"持续在场要素"，每镜复述，不重新发明。
> **"不可见"不是省略指令**：要省略的细节直接删掉不提；必须保留的例外写"画面中唯一不出现的是X"（写法见 prompt-rules 0.7）。

### 开场走位机制（每场第一段的地基——防"每段视频长出一个新世界"）

1. **从场景图认家具，不从提示词认**：场景参考图生成后，从**图里实际可见**的物件中登记 4-20 件能站/能坐/能倚的东西——提示词里写了但图上没有的家具**不许用于站位**（实测事故：让人坐在图上不存在的高台，每段视频模型各自发明一个高台，段段不一样）。**prompt-only 顺序**：本 skill 交付提示词时，站位物件先标"规划/OPEN"；场景图实际生成后由用户回填确认，再定情景图站位——与"从场景图认家具，不从提示词认"同一纪律，不得把图上没有的物件当可用站位
2. **每人一条走位记录**：在哪件东西的哪一侧 + 沿该侧多远 + 坐/站/倚 + 八方位朝向（面朝北/面朝门口）。位置写"哪一侧"，**不写坐标**（语义绑定第一层：模型没有坐标系）
3. **走位句由记录生成**，一句自然语言（"沈知微站在岸端土坡上面朝北，林枫坐在渡口条凳东端；其余座位空着，没有其他人"）——该场第一段的 SCENE CONTEXT 逐字照抄，后续段延续
4. **群演默认 0**：剧本没写有别人，走位句就显式写"没有其他人/其余座位空着"——不写这句，视频模型会把空位画成有脸的陌生人（背景围观群众是最常见的画面污染）。**边界**："默认 0"只排除**未被剧本/用户授权**的背景人物；用户或剧本显式要求出场的角色（哪怕"剧本没写但他必须出现"）计入在场声明——走位句写法："除了她与柱子另一侧的{授权角色}，再没有其他人"
5. **同地点连场不挪位**：无剧情驱动的连续场次，人物位置不变，只允许改朝向/坐站——每次重新生成都是重新掷骰子，位置不动骰子就少掷一次

### 走位的戏剧语义（距离与移动携带权力含义，不只是防瞬移）

[drama-skills: shot-craft.md#场面调度, blocking-playbooks.md]

上面的走位机制管**几何连续**（谁在哪、不瞬移）；本节管**戏剧语义**——同一个走位同时携带权力含义，LOCATION MAP 的距离常数因此不只是数字：

- **靠近**可以施压或寻求结盟；**转身**可以拒绝；**占住出口**可以控制；**碰触证据**可以暴露知情
- 距离常数携带权力含义：六米=对峙（谁先动谁冒险）、半臂=贴身（控制或被控制）、背对门口=把退路交给对方
- **不要只为增加运动而让人物无理由走动**；不要为了"画面丰富"让人物轮流起身、倒水、看窗——单房戏的运动来自：说话或沉默的策略 → 对方怎样接住 → 物件、目光或空间发生什么 → 谁暂时掌权

### 道具锚定（每个命中判定规则的道具）

**哪些道具入本节**：命中六条判定规则任一即入表——判定全文见 **prompt-rules.md 一节·骨架 0（角色视觉锚定资产）的道具判定规则**（唯一的家）。要点：跨镜出现、触碰变状态、会位移、剧情承载、镜头要对焦、角色强关联随身物。
**补充（V3.9 实测）**：跨镜反复出现且有颜色/材质/形状身份的场景大件（垫子/横杆/看台/广告牌）即使不触碰、不变状态，也按"场景持续物"登记颜色色号+位置；会位移/被触碰的再加道具条目。道具尺寸写"数字 + 身体比例 + 反例"（"约 1.2 米，约等于一条腿长，不是短棍"）。

| 字段 | 说明 |
| --- | --- |
| 道具锚定短语 | {名称/材质/颜色（含十六进制色号）/尺寸/磨损痕迹/标志性细节}固定文字，逐字冻结 |
| 状态清单 | 该道具在剧中出现的所有状态（收起/打开、旋紧/旋开、完整/破碎）——**同一张合图并列生成后裁切成单张**（生成端合图、参考端单张，见 prompt-rules.md 一节·骨架 0d）；**可分离组合道具每部分单独裁一张**；状态间**互参声明**（"破碎态=完整态被击碎的碎片，同一物件"） |
| **持械手/鞘位** | 武器类必填三要素：**持械手**（右手持刀/已脱手）+ **鞘位**（空鞘挂左腰侧/收入背后）+ **双手占用**（另一只手空着/抓着桥栏）——同一道具同一时刻只有一个状态（防"腰间入鞘+手中出鞘并存"），转换过程显式写（"从腰间鞘中拔出，鞘留在腰上"）。**无鞘武器（骨矛/短棍/石斧）写"无鞘"，另填收纳位**（靠墙/挂腰/随身/斜靠石台），不虚构一个鞘 |
| **携带位置账（非武器道具）** | 每镜写死：**在身上哪个位置**（背在背上/挎左肩/挂腰间/别在腰带右侧/拎在右手）或在谁手里，还是已离身放在哪里；**动作结束后在哪**（放下/递出/掉落/收回）。V3.7 实测：前后镜头"一个背着、一个没背"，就是位置账断档 |
| 参考图路径 | assets/{道具名}_{状态}.png（白底道具图，配方见 prompt-rules.md 骨架 0d）；**多状态合图生成后裁切成单张**（生成端合图、参考端裁切，见 0d）；**图案类道具**用图案特写锚定图（纯色底、图案占画面 70%+、平铺无透视变形） |
| 连续性规则 | 该道具跨镜/跨段的状态延续说明（"沿用上一条已在桌上的那枚银锭，不重新变出新的"） |
| 链接镜头 | 该道具入画的镜头号——04 对应段落的 ACTIVE REFERENCES 必须链接其参考图（防"道具在视频里凭空变了样子"） |

### 风格圣经（全局唯一）
从 styles.md 选定后逐字冻结，追加到每条图片提示词末尾；视频端由首帧图+FORMAT 节质感锚定行承载。

**多世界/双场景项目的词条适配（逐字冻结的唯一例外通道）**：全片含语义差异极大的多个世界（现实站台 vs 回忆院子）时，某条风格词条在另一世界语义不成立（"霓虹倒影"进夏夜院子）——处理规则：①冻结时即登记**场景变体**（02 风格圣经节按场景分列变体词条，如"院子世界：檐下灯泡的微弱暖光在湿石板上拉出短倒影"——保持同一视觉语法关系、替换载体物）②每条提示词只逐字使用**所属世界的变体**，不硬塞不成立的词条 ③变体登记后同等冻结，中途不改；未登记变体而自行改词 = 违反逐字规则。单世界项目不适用本节，仍全片一条圣经。

**按画面类型裁剪（V3.7——白底/高调图必须剥离暗调词条）**：通用 cinematic 词条里的曝光/光比词（`holy light bloom` / `volumetric light shafts` / `deep blue-green shadows` / `low key` / `deep shadows` / `film noir` 等）在**白底、高调、过曝、面板/信息图、VFX 参考图**上会把画面拖成黑底暗场（实测：S14/P05 白底图折腾两轮才发现根因是风格后缀）。处理规则：

1. **判定画面类型**：渲染主体是"白底/纯色底/高调过曝/版式面板/VFX 元素展示"→ 进入裁剪分支；正常叙事场景图/情景图仍用全量圣经。
2. **剥离冲突词条**，只保留与画面不 conflict 的视觉语法（材质处理/颗粒/清晰度），并把该画面的曝光目标写成正向句（"主体均匀高调照明，背景纯白，暗部干净不压黑"）。
3. **登记高调变体**：02 风格圣经节与"多世界变体"同一通道，登记 `高调/白底变体：{裁剪后的词条}`，逐字冻结。
4. **NO/约束节**写正向排除：`不要暗场、不要压暗背景、不要体积光遮住白色背景`。
5. 未登记变体而直接把暗调词条贴到白底图上 = 违反本规则。

> 白色/灰色底参考图另有**底色隔离句**：`参考图底色仅为中性展示底，不带入生成画面`——防灰底把场景拖灰（见三节参考图唯一权威）。

## 二、锚定短语写作规则

**锁定优先级三级链（冲突时的裁决顺序）**：`USER-LOCKED > 参考图/风格提取的既定裁决 > 系统默认补全`
- **USER-LOCKED**：用户在 GATE0/GATE1/GATE1.5 显式选择或修改过的项（锚定短语/色板/风格/峰值-强调手段分配）——**永不被系统覆盖**，要改必须回到对应 GATE 重新确认
- **OPEN**：skill 按主题补全的默认值——可被用户参考图的迁移裁决填充，也可被用户随时改
- 02 锚定表各字段默认视为 USER-LOCKED（因为经过 GATE1 确认）；GATE1 之前的草稿期标 OPEN
- 候选写进提示词 ≠ 用户已接受——GATE1/GATE1.5 呈现过的才是接受

1. **具体到可指认**：`28岁女性，清瘦，鹅蛋脸，齐肩黑色短发微卷，左眉角一颗小痣`✓；`一个年轻女性`✗（服装不进角色锚定，见服装锚定表）
2. **顺序固定**：年龄性别→体型脸型→发型发色→五官特征→标志性特征。跨镜复用时顺序不变；服装/配饰移入服装锚定表
3. **7-9 个视觉要素**：太少不够锚定，太多稀释重点
4. **道具同理**：材质/颜色/尺寸/磨损逐项具体，`一把长柄黑伞，伞面有轻微使用褶皱，木质伞柄`✓
5. **着装状态逐部位列明"有/无"（V2.9——实测教训：锚定写"上身无衣物"，生成时模型仍给角色加了肩带披挂）**：单一否定句锁不住着装——模型对"无衣物"的先验会自动补配饰/遮挡物。角色处于非常规着装状态（裸露/半裸/破损/泳装/盔甲卸下）时，锚定短语与受影响镜头的提示词必须**逐部位列有/无**：`肩带无/披挂无/护臂无/腰带无/腰间兽皮裙有/腕部藤蔓环扣有`——与 02 锚定表逐字对齐，跨镜逐字复用。常规着装（完整现代/古代服饰）不需要此清单，写全服饰要素即可
6. **年轻人物皮肤状态标准句（基础句 + 微笑追加句，逐字复用）**：
   - **基础句（所有年轻人物画面逐字插入）**：`年轻紧致、表面平滑细腻，面颊与额头饱满平整，眼周与口周皮肤舒展，保留真实毛孔。`
   - **微笑追加句（仅表情为微笑/含笑的画面插入）**：`微笑时苹果肌自然隆起，面颊轮廓圆润连贯。`
   - 说明：与质感槽的 `natural skin texture, visible pores` 并存；非微笑画面只插基础句，避免"微笑"描述把中性/对峙表情带偏。**年轻人物微笑描述**：用苹果肌隆起/嘴角上扬/下眼睑轻收，不写"法令纹加深/皱纹挤出"（与基础句的"平滑/舒展"冲突）

## 三、跨镜一致性操作规则

### 图片端（多图参考）
- **参考图六条硬标准 + 数量上限**：全文见 **prompt-rules.md 0.5 节**（唯一的家）。本处只留判定要点——一张图只回答一个问题，脸和身子分开，3-5 张最优 ≤8（超 10=噪声），禁九宫格拼贴设定卡
- **角色资产 = 三层分工**（AI 只识别像素/轮廓/五官比例，不读图中文字）：视觉锚定层（三视图主锚+面部特写+按需补充锚）/ 文字规则层（锚定短语进提示词）/ 人工参考层（拼贴卡自看，绝不整卡上传）
- **头身分离必须落到出图动作上**（实测教训：规则写了，实际生成时没分开——一张图同时画全身和脸，脸只占两三成，一致性当场失效）：03 的人物参考图节**按 templates 0a/0b 分两张出图**——0a 白底三视图（只管比例/服装/轮廓，脸裁掉或转过去）+ 0b 面部特写（脸占画面 6 成以上）。**不许合成一张"设定图"交差**（**唯一例外**：动漫/国漫设定项目可用 cinema-grade-params 二节的四视图配方合出，脸区占足像素）
- **互挂参考（人物↔场景↔情景三向引用）**：三类资产不是各自孤立出图，而是相互挂参考——
  - **情景图必挂**：该镜的角色锚定图（三视图+近景加面部特写）**＋** 所在场景图（母版）→ 人物与空间同时锁住
  - **场景图可挂**：已有定稿场景图作母版基准（同场景异状态/异机位时）；道具入画的场景挂道具图防串戏（prompt-rules 0.6）
  - **人物图之间**：同角色多状态图互为参考（服装改版时挂上一版防漂回旧设定）；角色同框时挂各自锚定图，**受"一张图一张脸"限制——合成图仅作身形/服装参考，脸另给特写**
  - 每张挂入的图写**双向作用域声明**（锁什么+不锁什么），角色路由规则见 prompt-rules 一节
- **基准参考法（同场景异状态镜头的有效手段）**：一张已定稿的成图可作为后续镜头的**基准参考**——同场景不同状态（"A31 定场全景作 S3d 动作情景基准"）、同场景异机位、同角色异动作。做法：基准图挂入 ACTIVE REFERENCES 并声明"只锁空间布局/光线方向/主体比例，不锁姿势与表情"。**价值**：省去重新描述整个场景，且空间关系天然一致。与"定稿标记"配套（防基准图被重生成污染）。**场景大件（门/窗/招牌/固定家具）优先用同场景已定稿成图裁出的权威局部，不用场景母版重新推导**——母版重推=大件被重新设计（V3.7 实测：S12 门体）
- **参考图按镜头机位动态组配**：正面镜头 → 三视图（或裁出正面图）+ 场景图；侧/背镜头 → 必须加对应视图；特写/近景 → 必须加面部特写锚定图；**道具入画的镜头 → 加道具对应状态图**
- **参考图角色路由（每张图只有一个权威维度）**：常见权威维度=角色身份/服装/道具/场景空间/构图/光线/色彩/材质/风格语法；**显式排除收窄角色**（"只参考灯光不参考构图"→ 排除句写进用途声明）；多参考图矛盾时按维度分工各取所长，**禁止"综合一下"**（平均=谁也不是）；**风格参考图的迁移范围三档**：强继承（色彩结构/材质处理/媒介质感/曝光行为）→ 条件继承（机位/构图/尺度/光向，逐项标 Preserve/Adapt/Release）→ 默认不迁移（人物身份/服装/道具/文字/品牌）。提取方法见 styles.md 风格提取（解梦卡）
- **同一对象唯一权威参考（V3.7——图片端与视频端通用，多图冲突的裁决铁律）**：一条提示词里，**同一个物理对象**（门/窗/家具/道具/服装/场景大件）只允许**一张权威参考图**。其余含该对象的图必须显式降级：用途声明写"只参考{光线/构图/材质/比例}，**其中{对象}的样式不作为本镜依据**"。**不适用于角色身份**——脸与三视图分属不同权威维度，按角色路由各挂各的（面部特写锁脸、三视图锁身形/服装）。规则：
  1. **先认对象**：列出本镜参考图里重复出现的对象（"Image 2 与 Image 6 都含那扇铁门"）。
  2. **留一张权威**：选与当前镜头视角/状态最接近的一张；无法判断时**裁出唯一权威参考**——从某张图里裁掉其余对象/背景，只留该对象，作为新 Image 挂入；原图撤下或降级。
  3. **禁止两张含同一对象的图并列**：模型会各取一半自由混合（实测：S12 同时喂 SC01 母版与情景图，两扇门的样式互相打架，门体被重新设计）。
  4. **白底/灰底隔离**：白底/灰底参考图必须写 `参考图底色仅为中性展示底，不带入生成画面`——否则灰底会把场景拖灰。
  5. **数量不增加**：裁出的单张是 1:1 替换合图；按镜头只挂当前机位/状态需要的那一张，不把四视图/多状态图全部挂上。参考图总数仍按 3-5 张最优、≤8（H3 Ref2VA ≤9）执行。
- **绝不"编辑已生成的图"来换场景/姿势**——每次编辑累积伪影
- 多人场景：宁可拆镜（每镜 ≤2 人同框为佳）
- 长会话（12+ 张）后参考图"失忆"——分批新开会话/独立请求，每次重传参考图
- **资产引用矩阵先行**（03 文件头）：零引用资产不生成，防浪费

### 图片端文图分工（参考图驱动生成——换装/换姿势/换表情/角色与场景合成）

> 核心原理：**生图模型读参考图的像素，文本模型读参考图的语义摘要**——两者之间有天然信息差。提示词要善用图，不要与图打架。
> **为什么"绝不文图矛盾"（社区经验）**：模型默认文本权重高于参考图——文字缺少强约束或与参考图冲突时，会按文本生成，参考特征丢失。因此参考图负责"长什么样"，文本只写差异项与身份锁定句；发现矛盾先修锚定/参考图，不在提示词里叠形容词对抗。

| 信息 | 权威来源 | 提示词怎么写 |
| --- | --- | --- |
| 身份（脸型/五官/发型/标志性特征） | 面部特写参考图 | 只写身份锁定句（"SAME face as reference"）+ 锚定短语中的身份要素 |
| 服装（款式/颜色/材质/配饰/磨损） | 服装参考图 | 按上文**服装锁定三档**：有专属图写"服装以 Image N 为准"+短锚；无专属图必须写"服装由 Image N 锁定"+短锚；不复述材质/配饰/磨损细节。换装时使用对应版本，不沿用旧版 |
| 身材/体型 | 全身/三视图参考图 | 只写"体型以 Image N 为准"；锚定短语中的体型描述必须与参考图一致，不一致时改锚定，不在提示词里二选一 |
| 姿势/动作 | 文本 | 明确写目标姿势；参考图声明"不复刻其站姿/姿势" |
| 表情 | 文本（FACS 物理化） | 用面部特写锚 + 物理化表情描述；不要额外喂表情参考图与中性锚同时出现且不分工 |
| 构图/机位/景深 | 文本 | 明确写；参考图声明"不复刻其构图/背景" |
| 光线/色调/场景 | 场景参考图 + 文本色板 | 写"环境与光线以 Image N 为准"，色调槽用十六进制色板 |

**三条禁令**：
1. **不许转述图**：文本模型不得把参考图"转写"成细节描述（识图是降采样语义级，转述必失真，写下的细节是猜的）。参考图里已有的外观信息，一律用"以 Image N 为准"承接。
2. **不许文图矛盾**：提示词里任何与参考图冲突的描述（旧服装词、旧发色、体型形容）都会被模型平均或随机选边——发现冲突先修锚定/参考图，不要在提示词里叠形容词对抗。
3. **不许堆词**：参考图承担外观后，提示词只写差异项（姿势/构图/表情/光线/场景），形容词堆叠会稀释参考图信号。

**事实继承原则（V3.7——"前面说了、后面又不说"是漂移的常见来源）**：任一提示词中已经声明的事实（道具在手/背上/离身、服饰状态、伤口、人物在场、场景大件），在后续**相关**镜头中必须二选一：**逐字继承**，或**显式写变化**（"他把背包从背上卸下，放在脚边"）。禁止静默省略——省略不等于"保持不变"，模型会自行重掷。判据：删除某句后，模型是否需要"猜"这个事实的当前状态？需要猜，就必须写。

**参考图角色声明（每张必写，双向）**：`Image N = {素材}。锁定 {身份/体型/服装/场景结构/光线}；不复刻 {其站姿/姿势/构图/背景/景别}`。多张参考图必须按维度分工（脸/服装/场景各管一维），互相矛盾时各取所长，禁止"综合一下"（平均=谁也不是）。

**浅层/深层特征（社区经验）**：颜色、毛发、轮廓易保留；脸型结构、五官比例、姿态骨架、配饰位置易变形——深层结构必须靠图分工+文字强约束。精细特征（斑纹数量/虎牙颗数/挑染位置）用精确计数与单侧描述（"一颗，不是两颗"）。

> **官方换装范式（OpenAI Cookbook 原文，可逐字复用）**：Do not change her face, facial features, skin tone, body shape, pose, or identity in any way. Preserve her exact likeness, expression, hairstyle, and proportions. Replace only the clothing, fitting the garments naturally to her existing pose and body geometry with realistic fabric behavior. Match lighting, shadows, and color temperature to the original photo so the outfit integrates photorealistically, without looking pasted on. Do not change the background, camera angle, framing, or image quality, and do not add accessories, text, logos, or watermarks.
> （中文一句：不改脸/五官/肤色/体型/姿势/身份，只换服装并让面料自然贴合现有姿态与身体几何，光线阴影色温匹配原图，不改背景/机位/构图/画质，不加配饰文字 logo 水印。）
>
> **角色锚工作流（官方 6.4）**：先建角色锚图；后续 edit 逐项列"相同项"（同款服装/同五官/同比例/同配色）并写 `do not redesign the character`。

**两步生成法（换装/多状态角色的标准链路）**：
1. **先出新锚**：基础面部特写锚 + 目标服装参考 → 生成"该服装版本的角色锚定图"（白底/均光/中性表情，按 0a/0b 标准）。
2. **再用新锚铺量**：后续镜头只挂新锚 + 场景，不再同时挂旧锚——避免新旧设定在同一提示词里竞争（换装镜头可用目标服装的 0a 同规格全身锚替代旧三视图，见 prompt-rules A6）。
3. 新锚登记进 02（服装锚定表 + 参考图路径），作为该服装版本的基准参考图复用。

| 场景 | 参考图组配 | 文本职责 | 常见翻车点 |
| --- | --- | --- | --- |
| 换装 | 新服装锚 + 面部特写（+场景） | 姿势/构图/表情/光线 + "服装以 Image N 为准" | 沿用旧服装锚定短语 → 衣服回漂；挂旧版三视图 → 混搭 |
| 换姿势 | 面部特写 + 三视图（+场景） | 目标姿势写具体（FACS/身体序列），参考图声明不复刻站姿 | 未声明不复刻 → 出正立站姿；姿势描述用"自然放松"式空话 |
| 换表情 | 面部特写 + 场景 | 表情按 FACS 物理化（肌肉/瞳孔/注视），不用情绪标签 | 喂表情参考图又与中性锚冲突；只写"生气的表情"→ 表情不到位 |

### 单锚派生链（可选路径——高脸漂/多视图项目）

> 何时用：角色脸在派生图之间漂移明显，或同一角色要出侧面/背面/细节多视图。**默认仍走 0a 三视图 + 0b 面部特写（分两张）**；本路径是可选替代，不替换默认架构。

1. **锚点唯一**：先出一张**正面全身锚点**（不是三视图板；脸要清楚、白底、均光、中性）。它是一组图里唯一的文生图。
2. **其余全部从锚点派生**：面部特写、90° 侧面、背面、细节图都用"锚点 + 一句改图指令"；**派生图之间不再互相参考**——链式会累积漂移，且单张重出不会牵连一串。
3. **改图第一句写构图变更**：`Zoom in to an extreme close-up head-and-shoulders portrait...` / `Rotate the camera 180 degrees around her...`；一致性清单只写该视图需要的层（大头照只写脸/发/上装）。
4. **模型可混用**：锚点用 A 模型、派生用 B 模型可以衔接——一致性来自同一张锚点，不来自同一个模型；每张记录自己的模型。
5. **锚点确认停点**：锚点是全组的根，出完先给用户看；锚点不对，派生全白出。
6. **与默认路径的关系**：写实项目默认仍走 0a 三视图 + 0b 面部特写；本路径只在"脸漂"或"多视图"项目启用。动漫/国漫四视图合图例外不受影响。

### 同批角色区分度（B 级人工检查——不做机械门）

同批角色两两对比锚定短语与形象提示词，**遮住名字读一遍——分得清谁是谁吗？** 区分度必须落在**个体描述**（脸型/五官比例/体态/服装材质与磨损/一处只属于他的特征），不能靠"真实感样板"（毛孔/皮肤纹理/模板光位）撑长度。两条都中 = 重写个体描述。

> 为什么不做硬门：中文锚定短语的字符 bigram 雷同度在真实项目里很低（实测两个明显不同的角色 6.83%），英文词级 75% 阈值不能直接迁移；等真实样本足够再标定阈值。

### 视频端
- **首帧模式（i2v/i2va）**：一致性靠首帧（情景图）承载，提示词不重复外观描述（信息分工：图管"长什么样"，文管"怎么动"）
- **多镜头段落（骨架 A）**：ACTIVE REFERENCES 每素材一行**双向声明**（锁什么+不锁什么，见 prompt-rules 参考图作用域）；CONTINUITY RULE 写道具连续性与站位延续（含武器三要素：持械手/鞘位/双手占用）；**尾帧续接**：上一条 ENDING FRAME 的明确尾点 = 下一条 SCENE CONTEXT 的衔接锚点（描述上一尾帧的人物姿态/表情余韵/视线方向/光线/镜头高度，声明"必须从这个尾帧自然续上"）
- **角色最小参考集铁律**：角色出镜的段落必挂三视图，近景/面部可见必挂面部特写，主角最小集优先于场景视图——实测：只挂首帧→脸漂，只挂三视图→画成兜帽
- **画外角色显式管理**：角色在场但本镜不该入画时，显式写"她位于画外，画面中不出现其身体/倒影/轮廓/虚化人影——只通过对方眼神方向表现其存在"——不写则模型会把她画进背景
- **多媒体参考能用尽用**（组配策略见 prompt-rules.md 骨架 A）：角色图/道具图/场景图/首尾帧/上一段尾帧截图，在上限内全部链接进来，不是只放一两张——**但同一对象先按本节「同一对象唯一权威参考」裁决：含同一对象的图不能并列全挂**；缺素材回 03 补生成，不硬凑；**视频参考/音频参考仅限有该能力的模型（H3 / Seedance·即梦系，能力分档见 models.md）**，happyhorse 无此输入位；**体型悬殊/尺度易漂的项目加挂尺度对比图**
- **反先验动作必须先锁关键帧**：训练数据没见过的姿势/接触类动作，纯提示词改多少遍都出不来（模型把"用腿蹬弓"拉回"手握弓"）——首帧图直接给出该姿势，视频提示词只写后续运动；崩坏半秒可用剪辑特效遮（成品也这么做）
- **fl2va**：起点图+终点图两张（终点图独立新生成，配方见 prompt-rules.md）
- 光线连续性：上一段结尾的光 = 下一段开头的光；光线变化必须有因果（随动作/调度自然产生，不突然变光）
- 人物位置变化由摄影机取景完成，人物脚下位置保持连续（防瞬移）

### 色调端（三层分工）
- 图片端：风格圣经**全量**逐字后缀 + **色彩基调色板**（十六进制色号+颜色落在哪里）进色调槽
- 视频端：风格圣经**压缩为质感锚定行**进入每条视频提示词（介质质感+主体表面纹理（人物=自然皮肤纹理，物体/动物=对应材质）+自然运动模糊三项，同族压缩）。原因：视频模型不保留首帧像素而是逐帧重渲染，仅靠首帧图锁不住质感——用户实测（V1.1）视频端会出现图片端没有的"AI 油腻感"
- 质感锚定**不违反**"i2v 不重复外观"规则——外观（身份/服装/背景）不写，质感（渲染质量方向）必写
- 兜底：剪映统一调色/LUT + 胶片颗粒叠加（见 06"去油腻后期"节）

## 四、语音一致性（05_语音台词表）

**语音路线按视频模型的能力选（先查 models.md 音频参考能力分档，不套默认）**：
- **happyhorse 项目**：模型自带语音与口型同步，但**无独立音频 API 参数**——不能传音频参考。音色一致靠**发声描述公式逐字复用**（文字层），无音色参考自提取法
- **H3 / Seedance·即梦系 项目（有音频参考能力）**：可走**音色参考自提取法**（见下）
- **需要严格音色一致 / 模型直出不满意**：cosyvoice 对轨（见下）

**路线一：视频模型自带语音（happyhorse 默认；H3 / Seedance·即梦系 亦可用）**
- 台词直接写进视频提示词，绑定说话人与发声描述公式（逐字复用）
- 发声描述公式：**前置身份两段（音色型/态度串）+ 六参数（音量/语速/停顿/句尾语调/气息/咬字）**——全文与模板见 **prompt-rules.md 三·五节**（唯一的家）。要点：`"生气的说"✗` → `"声线低沉克制，藏压抑怒火，说话时呼吸加重带动鼻翼轻微起伏，语气带着压抑的气愤与委屈"✓`
- happyhorse 项目：此路线就是终点，**不要写音频参考**（无此输入位）
- 无台词角色显式声明闭口；说话时只有说话人产生口型（SPEAKER LOCK）

**路线二：音色参考自提取法（H3 与 Seedance·即梦系——需音频参考能力，能力分档见 models.md）**
- **前置检查（V2.9）**：项目/画布内已有该角色的音色参考资产（05 音色参考资产表或画布存量）→ **直接复用，跳过下面的试音段流程**；音色参考合计时长 ≤15s 的预算约束见 models.md
- ①先生成一段带该角色台词的视频片段（试音段，可短）②在剪映中分离/提取该片段的音频 ③把这段音频作为该角色的**音色参考素材**，在后续所有片段生成时通过 ACTIVE REFERENCES 传入（"{{Ref N}} 音频为角色X的音色参考"）④音频参考路径登记进 02 角色锚定的音色字段。H3 音频参考 ≤3 段——多角色时按戏份优先级分配
- **试音段时序规则（解决"首次生成时音色参考尚不存在"的鸡生蛋问题）**：角色台词最早出现在段 N，则该段就是他的试音段——
  - **段 N（首次发声段）**：ACTIVE REFERENCES 不列该角色音色参考（尚无此物），只靠发声描述公式；生成满意后剪映分离音频存 `assets/{角色}_voice_ref.wav`，登记 05 音色参考资产表与 02
  - **段 N+1 起**：该角色所有台词段传入此音色参考
  - **可选：单独段0 试音**（不愿让正片段兼试音、怕首段音色不理想时）：生成一句台词的极短片仅为提取音色，不进成片——04 文件头注明"段0 为试音段不计入成片"
  - **画外音角色同理**：画外音首次出现的段=其音色来源段。发声描述公式逐字复用不变（文字层双保险）

**路线三：cosyvoice TTS 对轨**（音色自提取仍不稳、或需要精细控制每句时）
- 视频模型只出画面+环境音（BGM 显式关闭），人物语音统一 cosyvoice 生成、剪映对轨
- 每角色创建复刻音色，voice_id 存入 02，全项目所有台词走同一 voice_id；固定 seed + pitch/rate
- 长台词拆句逐句合成（每句同参考音频）

**无声出片分支（V3.7——供应商音频能力不稳定时的兜底）**：能力字段可能"一日两变"（实测：moma H3 的 audio 能力 true→消失→setConfig 报错），不能按一次探测作长期假设。处理：

1. **每批生成前复探**当前供应商的关键能力（音频直出/参考图数/时长），结果与日期记入 01/02；变了就切路线，**不反复重试已判定不支持的能力**。
2. **视频端只出画面+环境音**：BGM 关闭；台词**不写进视频提示词**（写了也不会出声，反而可能触发口型生成）；环境声/动作声照常写。
3. **无台词段不接音色参考**——没有发声需求时挂音频参考只占素材位，H3 音频参考 ≤3 段/合计 ≤15s 的预算要留给真正需要的段。
4. **口型兜底设计**：TTS 后期对轨时，视频里若生成"张嘴说话"会对不上口型。分镜阶段就为无声路线做准备——台词镜头优先写**背身/侧脸/手部特写/画外音/闭唇**（"她背对镜头说话"/"画外音是她的声音"/"说完后嘴唇闭合"），**不要设计正面大特写长时间说话**；必须正脸说话时，接受后期对口型或改分镜。
5. 台词文本仍逐字保存在 05，TTS 生成后对轨；语音路线在 02 标注"无声出片+TTS"。

## 五、系列/多集记忆机制（00_剧情状态.md）

多集项目防遗忘的**强制步骤**：

1. **每集全部完成后更新 00**（阶段6 之后，不可跳过）：
   - 本集剧情摘要（3-8 行，按情节点）
   - 角色状态变化（外观/服装/情绪/关系/位置——下集开场状态）
   - 道具状态变化（银锭到了谁手里/伞是开是收/信拆没拆）
   - 本集尾帧描述（下集 SCENE CONTEXT 的衔接锚点）
   - 未回收伏笔与待办（下集要接的线）
2. **下一集开工顺序**：先读 00 → 再读本集剧本 → 阶段1 分镜时对照 00 核对角色/道具/场景状态延续
3. 00 变更 → 后续各集全部核对（失效传播）
4. 单集项目不需要 00；但单条视频拆多条连续段落生成时，段间衔接同样用"尾帧描述→SCENE CONTEXT"机制

## 六、失效传播

锚定表（02）变更时：
1. 在 03/04/05 文件头部插入标记：`> ⚠ 上游锚定已变更（变更日期），本文件待重新生成`
2. 聊天中明确告知用户哪些文件失效、需要重做哪些提示词
3. 未重新生成前，旧提示词与新锚定混用 = 一致性必然崩坏
