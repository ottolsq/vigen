# 一致性锚定机制（角色 / 场景 / 道具 / 色调 / 音色 / 剧情记忆）

> 建 02_锚定表时读本文件。原理：**参考图 > 文字锚定 > 无锚定**，双保险 = 锚定短语逐字复用（文字层）+ 参考图多图输入（图像层）。

## 一、锚定表结构（02_锚定表.md 的规则依据）

### 目标模型（表头节——续作与换轨依据）

| 字段 | 说明 |
| --- | --- |
| 生图模型 | 如 gpt-image-2.5 |
| 视频模型 | 如 happyhorse-1.1-i2v / MiniMax-H3——决定时长上限与生成模式（fl2va 项目注明） |
| 语音路线 | 默认=视频模型自带语音（台词写进视频提示词）；备选=cosyvoice TTS 对轨（用户要求时） |

### 角色锚定（每个角色）
| 字段 | 说明 |
| --- | --- |
| 锚定短语 | 一段固定文字：{年龄/性别/体型/脸型/发型发色/服饰/标志性特征}。**生成后冻结，逐字复用到所有图/视频提示词** |
| 参考图路径 | **三层资产**：①视觉锚定层（给 AI）：白底三视图 + 面部特写锚定图 + 按需 ≤2 张补充锚 ②文字规则层：锚定短语（02 表内） ③人工参考层：拼贴设定卡（自看，不喂 AI） |
| 音色/发声描述 | 默认路线：发声方式描述句（逐字复用，如"声线低沉克制，藏压抑怒火，说话时呼吸加重"——情绪表达=音量+语速+停顿节点+句尾语调）；cosyvoice 路线：voice_id + 参考音频路径 |
| 微动作习惯 | 可选：该角色的小习惯（紧张时摩挲袖口），跨镜复用增强真实感 |

### 场景锚定（每个场景）
| 字段 | 说明 |
| --- | --- |
| 场景描述锚 | {空间结构/主要道具/材质}固定文字 |
| **场景母版（多镜场景必写）** | 场景母版 ID（SC01）+ **四向锚**：以镜头为参照系，左/右/中央/远后方各登记一个固定物（"左侧固定为翻倒燃烧公交车，右侧固定为燃烧广告牌，中央固定为破损隔离带，远后方固定为破碎高楼与高架桥"）——跨镜空间感靠方向+固定物，不靠复述全场景 |
| 光线锚 | {时段+方向+色温}；多光源场景登记编号光源表（L01/L02/L03=来源+方向+色温K+强度%+硬软+动态行为+落点，写法见 cinema-grade-params.md） |
| LOCATION MAP | 多角色场景必写：各角色/关键道具的固定位置、朝向、相互距离（防跨镜瞬移）；单角色场景可省 |
| **开场走位句** | 每场第一条视频生成前必写（见下方"开场走位机制"），分镜该场第一段的 SCENE CONTEXT 照抄 |
| 参考图路径 | 场景参考图；被 ≥3 镜使用或有正反打对话 → 四视图全套（母版/对向回望/45°斜角/垂直俯拍，见 extended-views.md）全部登记 |

### 开场走位机制（每场第一段的地基——防"每段视频长出一个新世界"）

1. **从场景图认家具，不从提示词认**：场景参考图生成后，从**图里实际可见**的物件中登记 4-20 件能站/能坐/能倚的东西——提示词里写了但图上没有的家具**不许用于站位**（实测事故：让人坐在图上不存在的高台，每段视频模型各自发明一个高台，段段不一样）
2. **每人一条走位记录**：在哪件东西的哪一侧 + 沿该侧多远 + 坐/站/倚 + 八方位朝向（面朝北/面朝门口）。位置写"哪一侧"，**不写坐标**（语义绑定第一层：模型没有坐标系）
3. **走位句由记录生成**，一句自然语言（"沈知微站在岸端土坡上面朝北，林枫坐在渡口条凳东端；其余座位空着，没有其他人"）——该场第一段的 SCENE CONTEXT 逐字照抄，后续段延续
4. **群演默认 0**：剧本没写有别人，走位句就显式写"没有其他人/其余座位空着"——不写这句，视频模型会把空位画成有脸的陌生人（背景围观群众是最常见的画面污染）
5. **同地点连场不挪位**：无剧情驱动的连续场次，人物位置不变，只允许改朝向/坐站——每次重新生成都是重新掷骰子，位置不动骰子就少掷一次

### 道具锚定（每个命中判定规则的道具）

**道具判定规则（任一命中即入本节）**：①≥2 镜出现 ②被触碰后改变状态（雨伞收开/杯盖旋开/信拆封/灯点亮）③会运动位移（被推的银锭/驶来的卡车）④剧情承载（定钱/信物/凶器）⑤**需要镜头对焦到的物品或图案**（特写落点/rack focus 焦点对象/微距对象；服装上的标志性图案/印花/徽章/旗帜纹样/招牌字样）⑥**与角色强关联的随身物**（相机/武器/包/眼镜/手表——即使状态不变，跨镜出现就要锁外观）。

| 字段 | 说明 |
| --- | --- |
| 道具锚定短语 | {名称/材质/颜色（含十六进制色号）/尺寸/磨损痕迹/标志性细节}固定文字，逐字冻结 |
| 状态清单 | 该道具在剧中出现的所有状态（收起/打开、旋紧/旋开、完整/破碎）——**每个状态一张参考图** |
| 参考图路径 | assets/{道具名}_{状态}.png（白底道具图，配方见 prompt-rules.md 骨架 0d）；**图案类道具**用图案特写锚定图（纯色底、图案占画面 70%+、平铺无透视变形） |
| 连续性规则 | 该道具跨镜/跨段的状态延续说明（"沿用上一条已在桌上的那枚银锭，不重新变出新的"） |
| 链接镜头 | 该道具入画的镜头号——04 对应段落的 ACTIVE REFERENCES 必须链接其参考图（防"道具在视频里凭空变了样子"） |

### 风格圣经（全局唯一）
从 styles.md 选定后逐字冻结，追加到每条图片提示词末尾；视频端由首帧图+FORMAT 节质感锚定行承载。

### 色彩基调（全局唯一，十六进制色板——先于生成任何场景图定）

| 字段 | 面积 | 说明 |
| --- | --- | --- |
| 环境底色 | 约 60% | 空间主色（墙面/天空/地面），定调 |
| 中间调 | 约 25% | 家具/服装/道具主色 |
| 点缀色 | 约 10% | **只给特定物体**（打火机/花/招牌），不铺满 |
| 肤色基准 | — | 人物皮肤；冷环境里保留血色才真实 |
| 暗部色 | — | 阴影带色相，不是纯黑 |

进图片提示词色调槽的形式 = **色号 + 颜色落在哪里**（不只列色号，更不写"暖色调/低饱和"倾向词）。选定后与风格圣经同等逐字冻结；分段色调一致靠色板锚定，剪映调色兜底。推荐色板见 styles.md 色彩基调节。

## 二、锚定短语写作规则

1. **具体到可指认**：`28岁女性，齐肩黑色短发微卷，左眉角一颗小痣，米白色针织衫配浅灰阔腿裤，清瘦`✓；`一个年轻女性`✗
2. **顺序固定**：年龄性别→体型脸型→发型发色→五官特征→服饰→配饰。跨镜复用时顺序不变
3. **7-9 个视觉要素**：太少不够锚定，太多稀释重点
4. **道具同理**：材质/颜色/尺寸/磨损逐项具体，`一把长柄黑伞，伞面有轻微使用褶皱，木质伞柄`✓

## 三、跨镜一致性操作规则

### 图片端（多图参考）
- **参考图六条硬标准**（喂给模型的图必须过六关，违反=一致性崩坏）：①短边 ≥1024（越高越好）②纯色背景（中性灰或白，不要场景——场景会被一起读进去污染后续每镜）③所有参考图**同一套光**（均匀柔光无强方向性阴影；一张侧光一张顶光=模型造出两个人）④表情中性（大笑让肌肉形变，中性识别精度高一大截）⑤画面里**只能有一张脸**（多人同框模型会平均出"谁也不是"的第三人）⑥**脸和身子分开**——全身图只管比例/服装/轮廓，脸单独一张大特写占画面 6 成以上。**一张图只回答一个问题**：问"穿什么"答得好，再问"这张脸是谁"它只能编
- **数量**：3-5 张最优，8 张上限，超过 10 张=噪声（不是信息）。反模式=九宫格拼贴设定卡（1024 图切 9 格每格仅 300px、脸占不到 20%，模型只能猜，猜出来的眼间距/眉形/下颌线每帧都不一样）
- **角色资产 = 三层分工**（AI 只识别像素/轮廓/五官比例，不读图中文字）：视觉锚定层（三视图主锚+面部特写+按需补充锚）/ 文字规则层（锚定短语进提示词）/ 人工参考层（拼贴卡自看，绝不整卡上传）
- **参考图按镜头机位动态组配**：正面镜头 → 三视图（或裁出正面图）+ 场景图；侧/背镜头 → 必须加对应视图；特写/近景 → 必须加面部特写锚定图；**道具入画的镜头 → 加道具对应状态图**。每张图的用途声明逐图写明
- **参考图角色路由（用途声明的升级——每张图只有一个权威维度）**：
  - 常见权威维度：角色身份 / 服装 / 道具 / 场景空间 / 构图 / 光线 / 色彩 / 材质 / 风格语法。**每张参考图指派一个主维度**，用途声明只写它权威的那部分（"image 2 只锁定空间布局与窗光"）
  - **显式排除收窄角色**：用户/项目声明"只参考它的灯光，不参考构图"→ 光迁移、构图权威被拒——排除句写进用途声明
  - 多参考图矛盾时不平均：按维度分工各取所长（A 图取身份、B 图取光），**禁止"综合一下"**（平均=谁也不是，同"一张图一张脸"原理）
  - **风格参考图的迁移范围三档**：强继承（色彩结构/材质处理/媒介质感/曝光行为）→ 条件继承（机位/构图/尺度/光向——逐项标 Preserve/Adapt/Release）→ 默认不迁移（人物身份/服装/道具/文字/品牌）。提取方法见 styles.md 风格提取（解梦卡）
- **绝不"编辑已生成的图"来换场景/姿势**——每次编辑累积伪影
- 多人场景：宁可拆镜（每镜 ≤2 人同框为佳）；多人参考图可合成一张（但受"一张脸"标准限制——合成图仅作身形/服装参考，脸部另给特写）
- 长会话（12+ 张）后参考图"失忆"——分批新开会话/独立请求，每次重传参考图
- **资产引用矩阵先行**（03 文件头）：零引用资产不生成，防浪费

### 视频端
- **首帧模式（i2v/i2va）**：一致性靠首帧（情景图）承载，提示词不重复外观描述（信息分工：图管"长什么样"，文管"怎么动"）
- **多镜头段落（骨架 A）**：ACTIVE REFERENCES 每素材一行用途声明；CONTINUITY RULE 写道具连续性与站位延续；**尾帧续接**：上一条 ENDING FRAME 的明确尾点 = 下一条 SCENE CONTEXT 的衔接锚点（描述上一尾帧的人物姿态/表情余韵/视线方向/光线/镜头高度，声明"必须从这个尾帧自然续上"）
- **多媒体参考能用尽用**（组配策略见 prompt-rules.md 骨架 A）：角色图/道具图/场景图/首尾帧/上一段尾帧截图/视频参考/音频参考，在上限内（图 ≤9、总数 ≤12）全部链接进来，不是只放一两张——缺素材回 03 补生成，不硬凑
- **反先验动作必须先锁关键帧**：训练数据没见过的姿势/接触类动作，纯提示词改多少遍都出不来（模型把"用腿蹬弓"拉回"手握弓"）——首帧图直接给出该姿势，视频提示词只写后续运动；崩坏半秒可用剪辑特效遮（成品也这么做）
- **fl2va**：起点图+终点图两张（终点图独立新生成，配方见 prompt-rules.md）
- 光线连续性：上一段结尾的光 = 下一段开头的光；光线变化必须有因果（随动作/调度自然产生，不突然变光）
- 人物位置变化由摄影机取景完成，人物脚下位置保持连续（防瞬移）

### 色调端（三层分工）
- 图片端：风格圣经**全量**逐字后缀 + **色彩基调色板**（十六进制色号+颜色落在哪里）进色调槽
- 视频端：风格圣经**压缩为质感锚定行**进入每条视频提示词（介质质感+主体表面纹理（人物=自然皮肤纹理，物体/动物=对应材质）+自然运动模糊三项，同族压缩）。原因：视频模型不保留首帧像素而是逐帧重渲染，仅靠首帧图锁不住质感——用户实测（V1.1）视频端会出现图片端没有的"AI 油腻感"
- 质感锚定**不违反**"i2v 不重复外观"规则——外观（身份/服装/背景）不写，质感（渲染质量方向）必写
- 兜底：剪映统一调色/LUT + 胶片颗粒叠加（见 06"去油腻后期"节）

## 四、语音一致性（05_语音台词表）

**默认路线：视频模型自带语音 + 音色参考自提取（用户实测方案）**
- 台词直接写进视频提示词，绑定说话人与发声方式描述句（逐字复用）
- 发声方式描述公式：**情绪表达 = 音量大小 + 语速快慢 + 停顿节点 + 句尾语调**（"声线低沉克制，藏压抑怒火，说话时呼吸加重带动鼻翼轻微起伏，语气带着压抑的气愤与委屈"✓；"生气的说"✗）
- **跨片段音色一致（音色参考自提取法）**：①先生成一段带该角色台词的视频片段（试音段，可短）②在剪映中分离/提取该片段的音频 ③把这段音频作为该角色的**音色参考素材**，在后续所有片段生成时通过 ACTIVE REFERENCES 传入（"{{Ref N}} 音频为角色X的音色参考"）④音频参考路径登记进 02 角色锚定的音色字段。H3 音频参考 ≤3 段——多角色时按戏份优先级分配
- **试音段时序规则（解决"首次生成时音色参考尚不存在"的鸡生蛋问题）**：角色台词最早出现在段 N，则该段就是他的试音段——
  - **段 N（首次发声段）**：ACTIVE REFERENCES 不列该角色音色参考（尚无此物），只靠发声方式描述句；生成满意后剪映分离音频存 `assets/{角色}_voice_ref.wav`，登记 05 音色参考资产表与 02
  - **段 N+1 起**：该角色所有台词段传入此音色参考
  - **可选：单独段0 试音**（不愿让正片段兼试音、怕首段音色不理想时）：生成一句台词的极短片仅为提取音色，不进成片——04 文件头注明"段0 为试音段不计入成片"
  - **画外音角色同理**：画外音首次出现的段=其音色来源段；此前已在别段发声过的角色直接复用其音色参考。发声方式描述句逐字复用不变（文字层双保险）
- 无台词角色显式声明闭口（"富商、伴舞全部保持自然闭口状态"）；说话时只有说话人产生口型（SPEAKER LOCK）

**备选路线：cosyvoice TTS 对轨**（音色参考自提取仍不稳、或需要精细控制每句时）
- 视频模型只出画面+环境音（BGM 显式关闭），人物语音统一 cosyvoice 生成、剪映对轨
- 每角色创建复刻音色，voice_id 存入 02，全项目所有台词走同一 voice_id；固定 seed + pitch/rate
- 长台词拆句逐句合成（每句同参考音频）

## 五、系列/多集记忆机制（00_剧情状态.md）

多集项目防遗忘的**强制步骤**：

1. **每集全部完成后更新 00**（阶段6 之后，不可跳过）：
   - 本集剧情摘要（3-8 行，按情节点）
   - 角色状态变化（外观/服装/情绪/关系/位置——下集开场状态）
   - 道具状态变化（银锭到了谁手里/伞是开是收/信拆没拆）
   - 本集尾帧描述（下集 SCENE CONTEXT 的衔接锚点）
   - 未回收伏笔与待办（下集要接的线）
2. **下一集开工顺序**：先读 00 → 再读本集剧本 → 阶段1 分镜时对照 00 核对角色/道具/场景状态延续
3. 00 变更 → 后续各集全部核对（失效传播）
4. 单集项目不需要 00；但单条视频拆多条连续段落生成时，段间衔接同样用"尾帧描述→SCENE CONTEXT"机制

## 六、失效传播

锚定表（02）变更时：
1. 在 03/04/05 文件头部插入标记：`> ⚠ 上游锚定已变更（变更日期），本文件待重新生成`
2. 聊天中明确告知用户哪些文件失效、需要重做哪些提示词
3. 未重新生成前，旧提示词与新锚定混用 = 一致性必然崩坏
