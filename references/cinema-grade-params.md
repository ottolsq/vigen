# 电影级参数块（专业质感强化 · 动漫风角色四视图）

> **何时读**：①项目要求"顶级剧集/电影质感"（韩剧情感戏、电影大片感），需要把质感描述从泛泛的"电影感"升级为专业参数级写法 → 用第一节参数块；②动漫/国漫风格角色需要参考图 → 用第二节四视图配方。
> 源：用户提供的成品提示词资料（other4.md 风格4 / other3.md，2026-10-24）。
> 用法：参数块**按需取节**拼进图片提示词（媒介句位置）或视频提示词 FORMAT 节，不必全堆——每节的"何时用"列决定取舍。

## 一、电影级参数块（五节，按需拼装）

### 1. 摄影机块（定"这是什么机器拍的"）

```
ARRI ALEXA LF，ARRIRAW 4.5K Open Gate，搭配 ARRI Signature Prime 定焦镜头组。
```

- 何时用：真人电影感/顶级剧集项目的媒介句升级版（替代 realism.md 的通用媒介句）
- 原理：具体到机身+录制格式+镜头组的写法给模型一个完整的"设备概念包"（语义绑定第三层——绑先验概念包）
- 变体：纪录片感改 `ARRI ALEXA Mini，手持肩扛`；复古改 `ARRI ALEXA LF 搭配 Cooke S4/i 球面定焦`（末日/巨兽大片成品用法）；**剧集情感戏/人像特写**改 `SonyVenice摄影机，85mm人像镜头，极浅景深`（other5 成品用法——配"背景大量散景光斑，温暖柔和色调，真实皮肤质感"）

### 2. 胶片色彩块（定"色彩科学怎么走"）

```
Kodak VISION3 250D 5207 胶片色彩模拟；ARRIRAW LogC3 进入 ACEScct 色彩流程，
并叠加轻度 Kodak 2383 Print Film Emulation。保留自然胶片颗粒、温润亚洲肤色、柔和高光滚降。
```

- 何时用：需要胶片质感但"film grain"单词不够分时——色彩科学链路（拍摄胶片→Log 色彩空间→调色流程→印片模拟）是完整的先验概念包
- 肤色关键词：**温润亚洲肤色**（东亚人物项目必带，防默认欧美肤色处理）；**柔和高光滚降**（防高光死白）

### 3. 帧率快门块（定"运动怎么呈现"）

```
24fps，快门 1/48。全程正常速度，禁止慢动作、升格、抽帧、加速台词和速度渐变。
```

- 何时用：需要"正常实拍速度"的项目（防模型自作主张加慢动作）；动作戏需要 Time Ramp 时**不写此块**，改为在具体镜头块标注慢动作区间
- 24fps+快门1/48=电影标准运动模糊量（180 度快门角）——这是"电影感"的物理来源，比写"cinematic"精确一万倍
- H3 官方输出即 24 FPS（models.md），与此块天然一致

### 4. 画质保留块（定"皮肤和材质要多真"）

```
顶级韩剧大制作情感戏质感。保留真实皮肤毛孔、眼下轻微纹理、睫毛、细碎发丝、唇纹、
颈侧皮肤、衣料纹理和沙发布料质感。
```

- 何时用：人物特写多的情感戏——把"natural skin texture"升级为**部位级清单**（毛孔/眼下纹理/睫毛/发丝/唇纹/颈侧）
- 对应的画面类禁止项按正向引导改写进描述（不写"禁止塑料皮肤"，写"皮肤保留真实毛孔与微小瑕疵"）；字幕/BGM 类禁令仍进 NO 节
- 风格锚词："顶级韩剧大制作情感戏"本身是高密度概念包（=毛孔级皮肤+柔光+浅景深+情感表演密度）

### 5. 光线布光块（定"灯怎么打"——参数级布光，替代"柔和光线"式泛写）

**自然光主导型（月光/日光场景）**：

```
主光约 5600K 冷银色月光，从左侧斜上方切入，重点照亮人物的发丝、额角、睫毛、鼻梁、
颧骨和唇峰。光源方向明确，面部左亮右暗，明暗过渡干净。发丝边缘被月光勾出一层
冷白色的细边，鼻梁和颧骨上有一道清晰的窄光，眼窝和下颌线保留自然的暗部层次。
整体光比偏大，氛围冷、安静。
```

**人工布光三件套（情感戏人物光，与自然光叠加）**：

```
头部侧后方隐藏式 4800K 窄幅条形柔光灯，勾出发丝、耳廓、颈侧轮廓；
正前方低位白色反光板 + 4300K 低强度柔光灯，补亮眼窝、虹膜纹理和面部暗部；
背窗侧负补光，吸掉多余反射，避免脸发黄发平。
```

- 何时用：人物情感特写——**色温 K 值 + 灯位 + 每盏灯管什么**三要素齐才是参数级布光
- 面部效果清单（写"脸必须显得"）：发丝通透 / 睫毛边缘有柔和描光 / 鼻梁与唇峰有细腻高光 / 阴影柔和但立体 / 脸颊不过曝 / 面部轮廓干净温柔
- 负补光概念：不是加灯而是**吸光**（黑旗/吸光板），防反射光把脸打平——写实感的关键细节
- 铁律：**禁止画面中出现任何摄影及灯光器材**（这条属画面内容禁令，按正向写法："画面中只有人物与环境，无任何器材入画"；或直接进 NO 节——器材入画属"画面内容"类，NO 节写一条可接受）
- 暖光变体：午后阳光把 5600K 月光换成 `4600K 暖金色午后阳光`（成品案例B用法），其余结构不变

**多光源编号布光（动态场景/多光源环境的写法，other7 成品实证）**——场景内每盏灯独立编号成行，七要素齐全：

```
光源 L01=左后方翻倒公交车爆炸火光，来源于画面左后方，向右前方斜切，色温2200K，
强度70%，硬光，持续不规则闪烁，在主角左侧身体和湿路面形成跳动橙红高光。
光源 L02=右侧燃烧广告牌火光，来源于画面右侧，向中央车道斜射，色温2400K，
强度45%，硬光，稳定燃烧并轻微抖动，在主角右侧轮廓和烟尘边缘形成暖色反光。
光源 L03=远处冷蓝警报光，来源于破碎高楼和高架桥方向，色温5200K，强度30%，
每1.5秒闪烁一次，从后方扫过人群和主角背部，形成冷暖交错的轮廓光。
```

- 七要素：**编号 + 物理来源 + 方向 + 色温K + 强度% + 硬软质 + 动态行为**（不规则闪烁/每1.5秒闪一次/稳定微抖）+ 落点（照在哪形成什么）
- 何时用：≥2 个光源、或光源有动态行为（火光/警灯/闪电）的场景——编号后镜头块可引用（"L03 扫过背部的瞬间他转身"），光成为叙事参与者
- 多光源冷暖对撞是电影感的物理来源：2200K 橙红火光 × 5200K 冷蓝警报灯——色温差本身就是画面张力（联动 realism.md 张力四法的"过曝欠曝分区"）
- 登记位置：02 场景锚定"光线锚"字段（逐字冻结），04 各段 LIGHTING 节逐字引用
- **动作-光影互动**（编号布光之上的一层）：身体/道具遮挡光束时，写明影子落在哪个具体表面——"手掌滑过半露胸腔时遮挡部分下落光线，在腹肌与堆叠的深灰布料褶皱上投下一抹修长指影"。这是 emotion-craft"光线因果跟随动作"的物理级实例：光随动作变，影子有具体落点

## 二、3D 半写实国漫角色四视图（动漫风项目专用配方）

> 何时用：动漫/国漫风格项目的角色参考图（替代写实项目的"白底三视图+面部特写"组合）。布局=**左侧大幅正脸特写 + 右侧全身三视图**，一张图同时回答"脸是谁"和"身形服装是什么"（比纯三视图多锁一张脸，比九宫格拼贴干净——仍是单角色、纯色底、统一光）。

**骨架**（横版 16:9）：

```
生成高精度3D半写实国漫{角色类型}角色设定图，{气质定调：如 BJD 人偶精致五官感+东方少年清透气质}，全年龄向。

【人物】{年龄}岁{人种/性别}，{头身比例：如小头高颅顶，约6至6.5头身修长比例}，
脸型{形状+下颌线+下巴+颧骨}，眉毛{形状/颜色/浓淡}，
眼睛{眼型/眼尾走向/单双眼皮/睫毛/瞳孔颜色与质感：如"微上翘细长猫眼，内双，浅色长睫毛，
通透浅蓝灰色湿润玻璃瞳"}，鼻子{鼻梁/鼻尖/鼻翼}，嘴唇{厚薄/唇峰/唇色/开合状态}，
神态{安静/冷峻/温柔——一个词}，素颜无妆感，皮肤{色调+质感：如"冷调透白，细腻自然，
保留真实皮肤层次"}；

【发型】{颜色+层次：如"浅白金色蓬松短发，发根香槟金向发梢过渡"}，头顶{蓬松度/空气感}，
额前{刘海形态}，两侧{鬓发与耳朵关系}，后颈{发尾处理}，{整体意象：如"像被海风吹过般自然蓬松"}，
真实细密三维发丝，柔亮通透；

【配饰】{耳饰/项链/挂件逐项：材质+颜色+尺寸+佩戴位置}；

【服饰】以{3-4个核心配色}为核心配色，上身{款式/颜色/材质/穿法/细节：袖口滚边/拉链/口袋}，
内搭{…}，胸前{图案描述，无文字}，下装{款式/颜色/长度/细节：卷边/飘带}，
鞋子{款式/配色/鞋带/袜子}，{随身物：包/挂件}；

【整体气质】{一句话：如"清爽、通透、夏日海风感的少年气质"}；

【版式】人物4视图角色设定图，横版16:9构图：左侧为同一人物的大幅正脸面部特写，
头部端正平视前方，不低头、不仰头、不偏头，完整展示五官、发型、耳饰、项链与肩颈上胸部，
比例自然，无广角畸变；右侧并列展示同一人物全身三视图——正面全身、标准90度侧面全身、
背面全身，三视图脸部一比一还原左侧特写，五官、肤色、瞳色、发型、服装、鞋袜与配饰完全一致；
正面双手自然垂落身体两侧，双脚平行直立，不交叉腿、不屈膝；侧面标准90度站立；
背面展示{背面要点：帽子/后脑发型层次/飘带/鞋跟}；

【渲染】高精度3D半写实国漫CG渲染，真实PBR材质，高清布料纹理，
明亮柔和影棚布光，85mm人像镜头，柔和主光加轻微轮廓光，避免过曝，
浅灰色纯色影棚背景，轻微接触阴影，画面干净，服装完整得体，无文字、无水印。
```

**要点**：
- 五官逐项写到**形状+走向+颜色+质感**四级（"微上翘的细长猫眼，眼尾略上扬，内双眼皮，浅色长睫毛，通透浅蓝灰色湿润玻璃瞳"）——这是防"塑料硅胶脸模板"的分层描述法在动漫风的应用
- **"三视图脸部一比一还原左侧特写"**是关键一致性句——左侧特写就是这张图内的"面部锚定图"
- 体型锚定写头身数（6-6.5 头身）+ 三个体型关键词，防 Q 版化/成人化
- 图案类服饰元素（胸前印花）写"抽象几何小图案，无文字"——需要具体图案时按道具锚定走图案特写锚定图
- 背景**浅灰纯色影棚**（不是纯白）——3D 渲染风在白底上容易过曝失去轮廓，浅灰给接触阴影留位置
- 此图仍受参考图六条硬标准约束（一张图一个角色、统一光、无文字标注）；生成后如需拆用，左侧特写区可裁作面部锚定图
