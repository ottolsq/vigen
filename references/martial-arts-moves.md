## 一、徒手拳法

### 1. 太极（八法+化劲）

| 招式 | 动作要点 | 用途 |
| --- | --- | --- |
| 掤 | 前臂向前上方撑出如球膨胀，弹开来力 | 接劲，所有化劲起点 |
| 捋 | 双手沿来臂方向顺势后引，把力引向身侧空处 | 引化，对方因惯性前扑 |
| 挤 | 前臂贴身向前挤出，后手按前臂内侧助力 | 化后最直接的反击 |
| 按 | 双掌从胸前向前下方推出，力从脚底贯到掌根 | 推击 |
| 采 | 抓住手腕/前臂向外下方猛拉 | 破坏重心 |
| 挒 | 前臂横向外翻转拧开来臂 | 横向破开 |
| 肘 | 曲肘以肘尖向前/横向击出 | 近身重击 |
| 靠 | 肩/背向对方身体挤靠撞击 | 贴身最重 |
| 云手 | 双手在胸前画弧，将来力裹缠引开 | 连续化劲 |
| 揽雀尾 | 掌心迎拳逐层荡开卸力 | 连续格挡 |
| 搬拦捶 | 反手拳背轻敲还击 | 防守反击 |
| 如封似闭 | 双手前推封住攻击线路 | 防守即攻击 |
| 野马分鬃 | 双手一上一下分开对方桥手 | 开线 |
| 海底针 | 俯身下采，破坏对方重心 | 低位引化 |
| 闪通臂 | 侧闪同时前臂横撑 | 闪化+反击 |
| 倒撵猴 | 后退步中双手交替后引 | 退中化、化中打 |
| 上步七星 | 前脚上步同时双掌前推 | 上步+推击一体 |
| 分脚/蹬脚 | 提膝后脚掌直线蹬出 | 中远距截断 |

**化劲四类**：掤手接劲（弹开）→ 捋手引化（顺力引走）→ 采手引偏（抓腕下拉）→ 倒撵猴退化（退中化打）。

| 招式 | 动作要点 | 用途 |
| --- | --- | --- |
| 摊手 | 二字钳羊马，前臂沿中线上扬外摊，肘贴肋 | 化开正面直拳 |
| 伏手 | 掌心朝下，前臂沿中线垂直下压 | 压住高位桥手 |
| 膀手 | 手肘外拱成弧形桥，前臂横向顶开侧拳 | 侧面卸力 |
| 窒手 | 手掌向前下方短促压截，瞬间截停发力 | 打断连拳 |
| 标指 | 双指并拢沿中线平直穿刺，肘不离肋 | 刺咽喉/心口/眼 |
| 日字冲拳 | 双拳收于胸侧，拳眼朝上，沿中线左右交替打出 | 主战压制 |
| 拦手 | 前臂横向短拦截住来臂 | 封中线入口 |
| 耕手 | 双臂一上一下斜向分开对方桥手 | 开出中线缝隙 |
| 捆手 | 双臂交叉螺旋缠住对方整条手臂 | 封控上肢 |

**典型连招**：摊手→日字冲拳；伏手→拍手→日字冲拳；膀手→窒手→标指；耕手→捆手→寸劲冲拳；低踢→日字冲拳连压。

### 3. 八极（六大开+部位）

| 六大开 | 动作要点 | 破防方式 |
| --- | --- | --- |
| 顶 | 肘尖短促爆发前撞，脚下跺地 | 正面硬撞 |
| 抱 | 双臂如铁箍环抱对方身体/双臂 | 抱控锁臂 |
| 单 | 单臂从外向内横扫 | 扫开一侧格挡 |
| 提 | 手臂从下向上提挑格挡臂 | 挑起下方空当 |
| 胯 | 胯部横向撞入对方胯/腰 | 破重心 |
| 缠 | 手臂缠绕来臂拧转控制 | 缠住无法撤回 |

**常用动作**：崩拳（拧腰转胯交替爆发直拳）、顶肘（肘尖前撞）、盘肘（肘尖横向盘旋）、反背肘（回旋肘击）、铁山靠（肩背整体前撞）、挤靠（弯肘化解+肩撞）、撑锤（前后对拉同时爆发）、硬开门（双臂横向拉开+中门直入）、跺地/行步连冲（每步震地）。

**十字整劲**：前后对拉（前手打出+后手猛拉）/ 左右横拉（双臂如开门，中门直入）。

**典型连招**：劈→钻→崩；炮→横→马形；猴→鹞→虎；燕→钻→崩。

### 2. 传统剑招词表（按套路风格）

**武当/太极剑（圆转、慢蓄快发）**：三环套月（三层圆弧剑花逐层收窄后点刺）、退步穿林（后撤中高低点刺肩/肋）、回锋点星（大幅横斩后回折点刺）、云卷长空（原地旋转剑花收缩后长刺）。
**华山/正统剑（干净锐利、直刺横斩）**：白虹贯日（大步突进双手平直长刺）、天马行空（大步飞跃垂直劈砸）、直刺咽喉（碎步近身短促长线突刺）、青龙出海（弓步前冲自下向上斜挑）、紫燕穿林（碎步侧滑短促点刺肩/肋）。
**峨眉/子午剑（短距爆发、点穴锁喉）**：子午穿心（侧身闪步贴近短距突刺心口）、闪步突刺（左右碎步变向直刺咽喉）、旋腕点目（手腕高速翻转剑尖点眼）、金蛇出洞（藏剑后腰碎步前冲短距刺胸腹）、纵步翻刺（纵跳侧翻斜刺侧腰，落地补刺小腿）、跃步穿心（大跨度腾空长线直刺心口）。
**青龙/大开大合**：平地起雷（小幅腾空垂直下劈，落地补刺）、穿林刺喉（碎步穿插长短交替后突刺咽喉）。
**通用连招**：缠剑锁械（剑贴敌械螺旋缠绕勾拉后割腕）、碎星点刺（高频震颤连续点眼/肩/肋）、环身缠打（小半径旋转剑光环身点空档）、滚身扫剑（侧滚贴地水平低扫，起身直刺）、翻身崩剑（180°翻身崩弹剑脊撞械，上挑咽喉）、锁喉横斩（滑步近身高位水平横斩咽喉锁骨）。

## 四、使用入口（细则以 action-combat 为准）

1. **先选风格，再选 3-5 招**：主战风格 1 套 + 破招/身法 0-1 套（action-combat §9）。
2. **招式链写法见 action-combat §6.5**：招式+落点+防守反馈，不堆招式名、不写抽象频率。
3. **招式名可改写**：按角色文化背景换成同义动作（"日字冲拳"→"中线连环立拳"），避免直接使用知名 IP 的专有招式名。
4. **不冒充门派传承**：本文件是动作词表，不是武术教学；写实项目优先用该流派最常见、最可读的动作，不追求冷门招式。
5. **兵器与特效**：兵器合法动作/接触反馈见 action-combat §2、§6；光效形态走 vfx-effects.md 与 action-combat §5，本文件只给动作。
