## 关键教训（V3.0 首版的问题，已修）

首版试跑记录只统计了**误拦数**（35→0），没统计**分母**（管辖覆盖率），导致两个虚假的"干净"结论：

- K5/K3 按字面量 `## 段落` 切块，而真实 04 的标题是 `## 段1a（…）` / `## 镜头N` → **门从未执行**，却报 0 findings。
- K1 为压误拦把排除词表加到 ~20 项整行匹配，**只有 25% 的已确认台词落在管辖内**。

现在每个门在「文档存在但找不到可检查单位」时报 `警告：…未执行`——**「门没跑」与「门跑过且通过」是两种不同输出**。

### 误拦修复对照（V3.0 → V3.0.1）

| 误拦模式 | 处置 |
| --- | --- |
| 技术说明/表演注/自检行里的引号被当台词 | **放弃关键词黑名单**，改结构判据：引号紧跟 `：` 或整行以引号开头；跳过 `>`/`#`/`|` 行与含 `→` 的行；AUDIO/PERFORMANCE LOCK/FACE LOCK/出场人物/NO/LIGHTING 按**小节作用域**整体跳过 |
| 01 两行式台词（`青衫客（…）：` 换行 `"借过。"`） | 支持两行式；说话人白名单取 02 角色锚定表（去掉兵器括注，如「帷帽客（刀）」→「帷帽客」） |
| 点缀色/肤色/瞬时光效被要求每段出现 | K3 白名单：只校验「环境底色/中间调/暗部色」 |
| 正文「高速甩镜360度」被当镜号 | K4 只扫镜头块首行/标题行 |
| 同一 PLAN id 多段共用被判重复 | 删除该检查（E2 的正常形态就是一张缺图一个 PLAN、多段引用） |
| 模型上限 `4s-15s` 解析成 4s | 取单元格内时长最大值 |
